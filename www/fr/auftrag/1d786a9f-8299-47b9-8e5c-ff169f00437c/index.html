Motivation de l'adjudicateur

Bei der Wirtschaftlichkeit erhielt die Firma Aveniq AG nahezu gleich viele Punkte wie das günstigste Angebot. Sie hat schlussendlich aber das beste Preis-Leistungs-Verhältnis erreicht, wenn alle Faktoren wie Qualität der angebotenen Leistung, Qualität der Referenzen und Qualität der Angebotspräsentation berücksichtigt werden. Die Firma Aveniq AG hat somit das insgesamt vor-teilhafteste Angebot offeriert, weshalb ihr der Zuschlag zu erteilen ist.

Description

Gesucht wird eine Dienstleisterin für die Unterstützung in Betrieb und Weiterentwicklung von Systemen mit Open Source Server Betriebssystemen (beispielsweise Ubuntu, Debian, RedHat). Ebenfalls soll die operative Security der entsprechenden Systeme gewährleistet und weiterentwickelt werden, und der Betrieb automatisiert werden.
