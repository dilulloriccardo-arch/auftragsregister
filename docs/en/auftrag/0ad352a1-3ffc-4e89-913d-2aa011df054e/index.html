Description

Lot 1

Das Coaching ist geprägt von einer funktionierenden Beziehung zwischen Coach und Coachee und findet im unmittelbaren persönlichen Kontakt, im Normalfall vor Ort in Bern, statt. Ein virtuelles Coaching kann in speziellen Fällen, in gegenseitigem Einverständnis, vereinbart werden. Das Einzelcoaching setzt sich zusammen aus einem Coachee und einem Coach. Auf die Verfügbarkeit der Coachees ist Rücksicht zu nehmen. Die Coachingperson muss auf der Liste der zwischen Anbieter und Bedarfsstelle vereinbarten Coaches aufgeführt sein (Schlüsselpersonen).

Mit dem Angebot ist ein Coaching-Konzept gem. Anforderungen (Anhang 7) einzureichen, welches geeignete Coachingverfahren sowie das Vorgehen für die Umsetzung (Prozess, Örtlichkeiten und Zuständigkeiten) enthält.

Lot 2

Ein Assessment für Kaderpositionen umfasst einen ganzen Tag. Ein halbtägiges Assessment wird für Fachspezialisten durchgeführt. Assessments werden von 2 Assessoren / Assessorinnen durchgeführt. Dabei müssen beide Assessoren / Assessorinnen auf der Liste der zwischen Anbieter und Bedarfsstelle vereinbarten Assessoren / Assessorinnen aufgeführt sein (Schlüsselpersonen). Als Grundlage für das Assessment wird das Kompetenzmodell der Bundesverwaltung verwendet (Anhang 10).

Mit dem Angebot ist ein Assessment-Konzept gem. Anforderungen (Anhang 7) einzureichen, welches geeignete Assessmentverfahren sowie das Vorgehen für die Umsetzung (Prozess, Örtlichkeiten und Zuständigkeiten) enthält.

Lot 3

Es geht um die Rekrutierung oder das Headhunting von Fachspezialisten (Revisoren / Revisorinnen, Auditoren / Auditorinnen) und Kaderpositionen. Fachspezialisten befinden sich in den Lohnklassen 23-27 mit oder ohne Führungsverantwortung. Kaderpositionen befinden sich in der Lohnklasse 25-34. Die Rekrutierung oder das Headhunting darf offenlegen, dass es die EFK betrifft. Die Rekrutierung
/ das Headhunting dauert so lange, bis ein geeigneter Kandidat, eine geeignete Kandidatin gefunden
ist. Der Anbieter ist bereit, eine Erfolgsgarantie mit Rückzahlungsverpflichtung einzugehen, falls eine Anstellung innerhalb der Probezeit beendet wird. Die Person, welche die Rekrutierung / das Headhunting durchführt, muss auf der Liste der der zwischen Anbieter und Bedarfsstelle vereinbarten Personen aufgeführt sein (Schlüsselpersonen).

Mit dem Angebot ist ein Rekrutierungs-Konzept gem. Anforderungen (Anhang 7) einzureichen, welches geeignete Rekrutierungsverfahren sowie das Vorgehen für die Umsetzung (Prozess, Örtlichkeiten und Zuständigkeiten) enthält.
