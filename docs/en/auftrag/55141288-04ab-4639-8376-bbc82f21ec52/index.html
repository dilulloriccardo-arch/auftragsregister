Description

At the Zumikon Municipal Administration, technical support for the local IT infrastructure is provided by an external IT service provider. The main tasks include the maintenance and upkeep of the hardware and network, as well as ensuring security compliance. This procurement is intended to achieve the following objectives: - Replacement of hardware and software for the IT infrastructure and client devices (laptops) - Procurement of services for support, maintenance, and operation for the next 5 years
