Description

Cet appel d’offres concerne la fourniture d’un appareillage MT, double jeu de barres, sous enveloppe métallique isolé à l’air avec disjoncteurs à structure débrochable (ou fixe, option) dont les principales caractéristiques sont les suivantes : - Courant nominal : 1250 A - Courant de court-circuit : 25 kA - Tension nominale : 24 kV - Tension d’exploitation : 21 kV - Nombre de cellules : 17 (± selon fournisseur) VOé souhaite que le banc de cellules offerts puisse être installés dans le local prévue dans le cadre du projet global du poste électrique. Le fournisseur doit prendre en compte le transport et le choix d’implémentation prévu sur site.
