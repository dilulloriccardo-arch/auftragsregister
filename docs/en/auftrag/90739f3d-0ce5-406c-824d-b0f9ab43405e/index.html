Description

Die Rhätischen Bahn AG (RhB) wechselt das Betriebssystem von Windows 10 zu Windows 11. Dazu sind 350 neue Notebooks aufzusetzen und an die Benutzer auf dem Netz der RhB zu verteilen. Gleichzeitig werden die alten Notebooks der betroffenen Nutzer eingesammelt und der Wiederverwertung zugeführt.

Prarallel sind ca. 370 Arbeitsstationen (Multi User Geräte) neu aufzusetzen und vor Ort auszutauschen.
