Description

Anzubieten sind die Bereitstellung, Konfiguration und Inbetriebsetzung eines intelligenten Messsystems (iMS) als ASP-Dienstleistung.
iMS bestehend aus:
- intelligenten Messgeräten (iMG) => Lieferung
- allfälligen Gateways => Lieferung
- allfällige Datenkonzentratoren => Lieferung
- einem Zählerdatenverarbeitungssystem (KMS, HES) inkl. Schnittstellen zu den Umsystemen => als ASP-Dienstleistung
- einem allfälligen Gateway Management => als ASP-Dienstleistung
