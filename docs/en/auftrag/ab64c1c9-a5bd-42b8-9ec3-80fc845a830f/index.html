Gesamtsanierung St. Josefsgasse 7a, 4500 Solothurn - Betreutes Wohnen im Alter

Description

Die Eigentümerin beabsichtigt, die Liegenschaft St. Josefsgasse 7a im unbewohnten Zustand umfassend zu sanieren und strukturell auf die Bedürfnisse des begleiteten Wohnens im Alter auszurichten. Es sollen attraktive, hindernisarme und wirtschaftlich betreibbare Wohnungen, welche für ältere Menschen ein selbstbestimmtes Leben mit bedarfsgerechten Unterstützungsleistungen ermöglichen, geschaffen werden.

Für den detaillierten Projektbeschrieb wird auf die Ausschreibung (Belage 01) verwiesen.
