Contracting authority's reasons

L'adjudicataire a fourni l’offre la plus compétitive, respectant entièrement le cahier des charges technique. Il a démontré qu'il possède toutes les compétences nécessaires à l’exécution du marché.

Description

Cet appel d’offres concerne la fourniture d’un appareillage MT, simple jeu de barres, sous enveloppe métallique isolé à l’air avec disjoncteurs à structure débrochable dont les principales caractéristiques sont les suivantes : - Courant nominal : 1250 A - Courant de court-circuit : 25 kA - Tension nominale : 24 kV - Tension d’exploitation : 21 kV - Nombre de cellules : 11 (± selon fournisseur) Romande Energie souhaite que les appareillages offerts puissent être installés dans le local MT existant du poste de Montcherand. Le fournisseur doit prendre en compte le transport et le choix d’implémentation prévu sur site. Ce nouveau banc MT servira à connecter les installations de production hydro du poste de Montcherand et à injecter cette production dans le réseau 21 kV.
