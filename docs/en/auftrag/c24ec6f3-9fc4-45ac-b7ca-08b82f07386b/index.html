Description

Das Strassenkreisinspektorat plant im Zeitraum 2025/2026 die Sanierung der Strassenentwässerung in Eggersriet, im Abschnitt zwischen Tannacker und Bensli.
Derzeit wird das Strassenabwasser über mehrere Einlaufschächte direkt in unterschiedliche Ableitungen eingeleitet. Mit dem vorliegenden Projekt soll künftig das gesamte anfallende Regenwasser gesammelt und einer zentralen Behandlungs- und Retentionsanlage zugeführt werden.
Zur Umsetzung sind zwei gezielte Massnahmen vorgesehen:
Einerseits soll im Bereich der Einmündung der Eggmoosstrasse eine unterirdische Retentionsanlage mit vorgeschalteter Behandlungseinrichtung erstellt werden.
Andererseits wird die Entwässerungsleitung kurz vor dem Dorfeingang so verlegt, dass das Regenwasser gezielt zur neuen Retentionsanlage abgeleitet werden kann.
