Description

Die Verkehrsbetriebe Zürich benötigen für die Ausschilderung von Informationstafeln, das Aufstellen von Billettautomaten und Lautsprecheranlagen sowie für Sitzbänke auf Haltestellen verschiedene Typen von Standardrohrrahmen. Um die Verfügbarkeit der notwendigen Rohrrahmen sicherstellen zu können, haben die Verkehrsbetriebe Zürich entschieden, in grösserem Umfang Rohrrahmen für die Haltestellenausrüstungen an Lager zu beschaffen.
