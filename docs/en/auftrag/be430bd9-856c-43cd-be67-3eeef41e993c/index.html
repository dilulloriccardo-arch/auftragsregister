Description

Übersetzung von 20‘000 Normzeilen pro Jahr. Bei allen Losen können die Quellsprachen Deutsch oder Französisch sein. Zielsprache ist immer Englisch. Eine Anbieterin muss mit ihren Kapazitäten mindestens den Umfang eines Loses abdecken können. Sie kann sich für mehrere Lose bewerben. Teilangebote kleiner als ein Los werden nicht akzeptiert. Es gibt keine Abnahmegarantie.
