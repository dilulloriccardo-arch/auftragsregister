Description

Die Initialeschaffung beinhaltet den Kauf von ungekühlten WBGs aus drei (3) Gerätefamilien:
- Gerätefamilie WBG Monokular (261 Stück)
- Gerätefamilie WBG Binokular (243 Stück)
- Gerätefamilie Multispektral Binokular (150 Stück)

Darüber hinaus können während der Beschaffungslaufzeit auch andere Geräte (Mono oder Bino oder Multispektral) aus dem Gesamtkatalog des Anbieters beschafft werden.
