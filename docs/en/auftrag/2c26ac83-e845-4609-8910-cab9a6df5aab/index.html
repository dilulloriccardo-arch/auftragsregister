TMA pour les systèmes et modules SAP fonctionnels suivants :
- Basis / CTS
- BW / BO
- CRM, FI / CO, MM / EWM
Ce lot est basé sur un contrat de régie forfaitisée selon un volume en jours-homme disponible dans le Cahier de réponses. La consommation du nombre de jours-homme sera pilotée entre le soumissionnaire et l’adjudicateur.
