Description

Auf dem Areal der Schule Wolfsmatt in Dietikon sollen diverse Gebäudetrakte saniert bzw. erweitert werden. Das Bauvorhaben wird in 2 Etappen ausgeführt (Etappe 1: Start Juli 2024, Etappe 2: Start Juli 2026 (Teilbereiche des Turnhallentrakts bereits 2025)) und umfasst die Gebäude Kindergarten Wolfsmatt, Kindergarten Bambi (Rückbau), Klassentrakt, Lehrertrakt, Singsaaltrakt und den Turnhallentrakt (Sanierungen), sowie die Erstellung zweier Neubauten an der Vogelaustrasse. Bezüglich der Arbeiten im Bereich Elektroanlagen in den Gebäuden bedarf es in beiden Etappen der Installation von Schaltgerätekombinationen.
