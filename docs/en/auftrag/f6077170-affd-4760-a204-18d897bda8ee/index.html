Description

Le présent appel d’offres concerne les prestations d’ingénieur civil, d’architecte et de direction locale des travaux pour les phases SIA 31 (reprise de l’avant-projet) à 53 du projet de déplacement de la gare des Diablerets. Le marché se compose de deux tranches : - tranche ferme pour les phases SIA 31-33 - tranche optionnelle pour les phases SIA 41-53.
