Description

Lieferung und Installation von folgenden Komponenten: 240 Heizungsanlagen, 244 Lüftungsanlagen, 250 Sanitäranlagen. Die Holzkesselanlage wurde bereits vorgängig auf SIMAP ausgeschrieben (SIMAP #2322-01,13.08.2024, 00225 Energieverbund Villmergen, Holzkesselanlage)

Die Gemeindewerke Villmergen erstellen einen Wärmeverbund, der die angeschlossenen Gebäude aus einer Energiezentrale mit Wärme für die Beheizung und die Warmwasserbereitung versorgt. ewz hat von der Kundin den Zuschlag für das Energiecontracting erhalten. Das Contracting beinhaltet unter anderem die Planung, den Bau und den Betrieb der Wärmezentrale für den Wärmeverbund. Die Wärmeerzeugung soll monovalent über zwei Holzschnitzelkessel erfolgen. In einer 2. Ausbauetappe soll
noch eine Abgaskondensation eingebaut werden.

Wärmeerzeugung:
Die Wärmeenergieversorgung erfolgt mittels zwei Holzschnitzelheizkessel mit einer Leistung von 600 kW und 1200 kW. Die Holzschnitzelfeuerungen werden mit einer automatischen Vorschubrostfeuerung betrieben. Die Wärmeleistung der Feuerung ist zwischen 30-100% regelbar. Zwei Wärmespeicher mit einem Inhalt von je 35‘000 Liter dient dazu, die Anfahr- und Ausbrandphasen zu reduzieren. Die Systemeinbindung der
Kesselanlage erfolgt mit einer Rücklaufhochhaltung, wobei die Holzkessel direkt in die Wärmespeicher arbeiten. Damit die LRV-Grenzwerte von 20 mg/m³ für die Feuerung, bezüglich Feststoffe (Feinstaubpartikel) in den Abgasen, eingehalten werden können, benötigt es für die Holzschnitzelkessel ein Staubabscheideverfahren. Dies wird je mit einem Elektroabscheider (Elektrofilter) gewährleistet. Um in einer 2. Etappe die Leistung zu erhöhen, soll eine Rauchgaskondensationsanlage und eine Wärmepumpe eingebaut werden. Zur Messung und Verrechnung der erzeugten Wärmeenergie, wird ein Wärmezähler im Kesselkreisvorgesehen. Die Abrechnung der Brennstoffmenge erfolgt über diesen Wärmezähler. Die Holzschnitzel werden in einer Schnitzelhalle gelagert. Das Lager hat ein Netto Füllvolumen von ca. 220 m3. Im Schnitzellager werden die Holzschnitzel über einen „Toploader“ zum Fördersystem der Holkessel geführt. Die Schnitzel-Austragung wird mit einem Schubboden sichergestellt.
