Description

Die Insel Gruppe AG ist zur Abdeckung von Auslastungsspitzen auf externe Ressourcen angewiesen und beabsichtigt die bauherrenseitige Projektleitung definierter Bauvorhaben durch externe Fachleute ausüben zu lassen (Übernahme der delegierbaren Bauherrenunterstützungsleistungen). Daneben können auch bauherrenseitige Sonderaufgaben im Planungs- und Baubereich anfallen.

Zum Überbrücken von personellen Engpässen werden maximal drei Dienstleister gesucht, welche mittels Rahmenvertrag jeweils die Möglicjkeiterhalten an einem projektspezifischen Mini-Tender teilzunehmen.
