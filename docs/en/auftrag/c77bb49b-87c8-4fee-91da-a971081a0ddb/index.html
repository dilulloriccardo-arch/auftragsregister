Description

Der Schmutzwasserkanal sowie der Bachwasserkanal aus dem Jahr 1930 in der Bachtelstrasse müssen mittels vorfabrizierten Stahlbetonelementen ersetzt werden. Die Kanäle werden in einer 5 m tiefen, offenen Baugrube gebaut. Die Querung der SBB-Linie Winterthur/Schaffhausen wird in einer Wochenende-Sperrung gebaut. Es werden Ortsbetonbauwerke, wie Regenüberlauf und Vereinigungsschächte gebaut, Werkleitungen erneuert und anschliessend wird die Strasse instandgesetzt. Alle Bauarbeiten werden in einem sehr engen städtischen Raum ausgeführt.
