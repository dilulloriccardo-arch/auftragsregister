Description

Lot 1

Le lot 1 est responsable de constituer le dossier PAP final, sur la base de ses éléments, ainsi que ceux des autres mandataires, dans les délais impartis et avec un niveau de qualité conforme aux exigences de l’OPAPIF. Aussi il est attendu du lot 1 de proposer une organisation intégrant les études et rendus des autres mandataires afin de les compiler dans le dossier final du projet de l’ouvrage (Phase 32).

Les mandats couvrent les phases SIA suivantes :
• Phases 32-33 : Tranche ferme ;
• Phases 41-53 : Tranches optionnelles.

Lot 2

Le lot 2 Génie Civil étendu concernent les prestations d’auteur de projet et de direction locale des travaux au sens de la SIA.

Le lot n°2 représente l’essentiel des prestations de construction prévues pour le projet. En ce sens, le mandataire du lot 2 doit faire preuve d’une coordination soutenue et efficace avec le lot 1 qui assure la coordination technique globale.

Les mandats couvrent les phases SIA suivantes :
• Phases 32-33 : Tranche ferme ;
• Phases 41-53 : Tranches optionnelles.
