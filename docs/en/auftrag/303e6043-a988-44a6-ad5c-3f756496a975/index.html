Description

Gesucht wird eine Entwicklung, Lieferung und Implementation einer webbasierten Applikation zur Erhebung der Schweizer Forststatistik unter Einsatz aktueller Technologien. Die grundlegenden Funktionen und Variablen sollen im neuen System im Vergleich zur bisherigen Applikation unverändert bleiben. Es wird ein Anbieter gesucht, der die geforderten Leistungen mit den nötigen fachlichen und technischen Kompetenzen erbringen kann. Der Source-Code der neuen Lösung soll im Sinne des Bundesgesetzes über den Einsatz elektronischer Mittel zur Erfüllung von Behördenaufgaben (EMBAG) mit einer Open-Source-Software (OSS) Lizenz publiziert werden. Die neue Anwendung muss eine hierarchische Benutzerverwaltung, strukturierte Datenerfassung sowie leistungsfähige Such-, Filter- und Reporting-Funktionen bieten. Sie muss beim BIT betrieben und sicher gemäss Bundesstandards sein. Die eIAM-Authentifizierung ist zwingend, ebenso eine skalierbare Architektur zur langfristigen Erweiterung und Wartung.
