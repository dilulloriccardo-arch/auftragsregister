Description

Das bestehende Laborgebäude wird im laufenden Betrieb umgebaut. Die Beleuchtungsinstallationen werden erneuert, bestehende Installationen demontiert und neue, bauseits gelieferte Beleuchtungskörper fachgerecht montiert. Die Lieferung der Beleuchtungskörper erfolgt durch die Bauherrschaft.
