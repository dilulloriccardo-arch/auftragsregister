Description

Beschafft werden im Rahmen des LifeCycle Access Switches inkl. den notwendigen Lizenzen für die Jahre 2025 - 2028.
Der Leistungsumfang beinhaltet folgendes:
- Lieferung Access Switch mit den notwendigen Lizenzen
- Access Client Switches auspacken
- Lizenzen für die Access Client Switches im iMaster NCE-Campus einspielen
- Liste mit allen Seriennummern an das Amt für Informatik und Organisation (AIO) liefern (um die Switches im Inventar zu erfassen)
- Inventarnummern an den Access Client Switches anbringen (Inventarnummern werden vom AIO geliefert)
- Access Client Switches updaten
- Access Client Switches in iMaster NCE-Campus integrieren
- Access Client Switches, Standartkonfiguration Aufspielen/Konfigurieren

Eine detaillierte Beschreibung des Beschaffungsgegenstandes findet sich im Pflichtenheft.
