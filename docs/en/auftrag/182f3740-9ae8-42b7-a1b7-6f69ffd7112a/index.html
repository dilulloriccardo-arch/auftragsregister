Description

Ekkharthof aims to implement a largely integrated ERP platform that consolidates the current systems used for payroll, time tracking, applicant management, personnel records, financial accounting, accounts payable, accounts receivable, expense management, and reporting. The new platform will form the foundation for the long-term digitalization of administrative processes.
Interfaces to Escola and Redline will need to be implemented.
The implementation is planned to take place in several phases and sub-projects between 2026 and 2028.
