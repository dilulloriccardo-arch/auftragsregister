Description

Das Gebäude wird Minergie-A/P-ECO zertifiziert. Holzgebäude dreigeschossig, 34m lang, 24m breit und 11m hoch. Auf dem Flachdach soll eine Ost-West ausgerichtete PV-Anlage mit ca. 100 kWp installiert werden. Die Dacheindeckung Kies, wird gleichzeitig als Ballastierung genutzt werden. Im Leistungsumfang ist die komplette DC-Installation inkl. Wechselrichter enthalten.
