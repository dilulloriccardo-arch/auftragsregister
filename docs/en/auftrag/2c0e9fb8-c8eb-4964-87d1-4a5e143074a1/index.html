Contracting authority's reasons

Beste Erfüllung der Zuschlagskriterien. Bei der Bewertung der Zuschlagskriterien 2 (Qualität/Referenzen) und 3 (Nachhaltigkeit) erreichte das Angebot die höchste Punktzahl.

Description

Teile der Gebäude auf dem CU-Areal in Uetikon am See müssen vor dem Rückbau / Umbau soweit gereinigt werden, dass anschliessend Arbeiten ohne zusätzliche PSA Massnahmen ausgeführt werden können. Dazu sind die Oberflächen und Installationen von Chemikalienresten / Produktionsresten zu reinigen, wobei eine Teilentkernung (teilweise mit Asbestsanierung) notwendig ist. Die Ausschreibung ist in drei Lose unterteilt, wobei für alle Lose ein Gesamtangebot abzugeben ist. Alle Lose werden an einen Anbieter vergeben.
