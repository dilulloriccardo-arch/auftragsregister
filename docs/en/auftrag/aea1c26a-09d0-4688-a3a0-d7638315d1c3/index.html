Description

Im Rahmen dieser öffentlichen Submission werden interessierte Unternehmen eingeladen, ein Angebot für Schwachstrominstallationen an den Wi-Fi Access Points am Universitätsspitals Zürich (USZ) einzureichen. Der Leistungsumfang umfasst folgende Standorte des USZ: USZ Campus, Rämistrasse 100, 8091 Zürich USZ Wollishofen, Seestrasse 323a, 8038 Zürich USZ Flughafen, The Circle 59, 8058 Zürich-Flughafen USZ Logistik- und Servicecentrum, Zürcherstrasse 123, 8952 Schlieren USZ Wagiareal, Wagistrasse 14-18, 8952 Schlieren Die ausgewählte Unternehmung wird für die Installation von 3.000 Access Points an den genannten Standorten verantwortlich sein. Von den Anbietern wird ein umfassender und effizienter Ansatz erwartet, um einen reibungslosen Betrieb sicherzustellen.
