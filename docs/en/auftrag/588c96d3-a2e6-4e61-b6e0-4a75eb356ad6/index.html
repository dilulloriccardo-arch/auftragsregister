Contracting authority's reasons

Den Zuschlag erhält die Firma ti&m AG, Buckhauserstrasse 24, 8048 Zürich, da ihr Angebot die Anforderungen der Ausschreibung am besten zu erfüllen vermag. Die Anbieterin hat sowohl mit der angebotenen Lösungsarchitektur (ZK02) als auch mit der Präsentation der drei Use Cases (ZK10.1, 10.2 und 10.3) in Kombination mit einem attraktiven Preisangebot (ZK01) überzeugt und stellt somit das vorteilhafteste Angebot dar.

Description

The purpose of this invitation to tender is to select a provider to develop, configure, deploy and operate an IT solution that will replace the current emissions database. The solution should be based on a system architecture with reusable digitalisation modules and should be capable of operating both in the cloud and within the standard federal environment. The new EMIS solution should provide a modern and scalable tool for data storage, data analysis and reporting of emissions data. The existing data must be migrated from the currently used SQL databases to the new IT solution. Following successful launch (go-live), the provider will ensure maintenance, support and continued development of the IT solution throughout the duration of the contract.
