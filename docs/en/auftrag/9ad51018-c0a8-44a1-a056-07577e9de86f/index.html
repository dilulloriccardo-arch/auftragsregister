Contracting authority's reasons

Das Angebot der Zuschlagsempfängerin zeichnet sich insbesondere durch das Kriterium Angebotspreis aus. Description

Innere Malerarbeiten mit deckenden Beschichtungen auf Wände, Decken Geländer, Zargen und Lifttüren. Oberflächen: Beton, Gipsglattstrich, Putze, Mehrschichtdämmplatten und Tapeten. Teilweise zweifarbig abgegrenzte Beschichtungen, sowie Schriften und Zahlen. Lasur auf Beton. Tapezierarbeiten. Äussere Malerarbeiten an Wände mit Grafitischutz. Lasur auf Vordachuntersichten und Stützen.
