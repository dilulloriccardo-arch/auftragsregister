Description

Auf Gleis 6 in der Halle 3 sind Dacharbeitsplätze für Arbeiten an den Tramfahrzeugen vorhanden wohingegen das Gleis 5 über keine fixen Dacharbeitsplätze verfügt und für Fahrzeuge keine fixen Einrichtungen bestehen. Für das Gleis 5 wird nun ein neuer Dacharbeitsplatz für Tramfahrzeuge gebaut. Aus diesem Grund werden Elektroarbeiten nötig.
