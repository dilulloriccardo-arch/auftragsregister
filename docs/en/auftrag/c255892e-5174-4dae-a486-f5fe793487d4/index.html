Description

Das Dach des KW Castasegna ist undicht, sodass es an mehreren Stellen zu Wassereintritt kommt. Aus diesem Grund muss das gesamte Dach erneuert werden. Die Unterkonstruktion wird dabei lediglich punktuell instandgesetzt bzw. angepasst.
