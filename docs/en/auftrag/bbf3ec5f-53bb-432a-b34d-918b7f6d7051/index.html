Description

Die SBB Infrastruktur benötigt für die Instandhaltung und den Ausbau ihres Netzes externe Unterstützung von Sicherheitspersonal.

Diese Ausschreibung dient der Auftragsvergabe für Personalverleihleistungen im Bereich Sicherheitspersonal für 2 Jahre und 3 Optionen für je 1 weiteres Jahr.

Die Anbieterin kann ein Gesamtangebot oder ein Teilangebot für einzelne Funktionen einreichen. Eine Funktion oder eine Teilmenge davon entspricht daher einem Teilangebot.

Es wird ein Los für die gesamte Schweiz bestehend aus Region Mitte, Region Ost, Region Süd, Region West vergeben. Jede Funktion ist ein Teillos. Teilangebote sind daher zulässig. Die Vergabestelle kann Teilangebote zuschlagen.

Die SBB AG vergibt den Zuschlag innerhalb der einzelnen Funktionen im Sinne des Bundesgesetzes über das öffentliche Beschaffungswesen (BöB) an mehrere Anbieterinnen. Je Funktion werden mindestens so viele Zuschläge erteilt, bis der ausgeschriebene Bedarf (FTE +25% gemäss Preisblatt) vergeben ist. Die Vergabestelle behält sich vor, zur Absicherung von allfälligen Ressourcenengpässen, zusätzlich mit den nächstplatzierten Anbieterinnen Verträge abzuschliessen.
