Description

Die bestehende Liegenschaft der Alten Gewerbeschule, Petersgraben 52, Basel wird gesamtsaniert und unter denkmalpflegerischen Aspekten umgebaut. Unter anderen werden neue Treppen und Liftschächte hergestellt sowie im Innenhof eine zweigeschossige Bibliothek eingebaut. Die gesamte Liegenschaft wird neu strukturiert und gemäss den geltenden Normen ertüchtigt. Die Liegenschaft wird für die Zeit der Umbauarbeiten leergezogen. Bei den Arbeiten handelt es sich um die Montage von PV-Anlagen auf Steil-und Flachdächern.
