Description

Die MRWA-Anlage im Projekt Volksschulhaus Weissenbühl in Bern ist eine speziell für Entrauchung entwickelte Anlage. Sie umfasst Ventilatoren und Armaturen, die in einem betonierten Kanalsystem (bauseits geliefert) integriert werden, um im Brandfall eine effiziente Rauchableitung und Frischluftzufuhr zu ermöglichen. Die Anlage ist aus temperaturbeständigen Materialien gefertigt und verfügt über eine zentrale Steuerungseinheit, die eine Integration in bestehende Gebäudesysteme ermöglicht. Die Installation beinhaltet technische Betreuung und sorgfältige Inbetriebnahme für höchste Sicherheit und Wartungsfreundlichkeit.
