Description

Die Fischbacherstrasse in Bremgarten wird auf einer Länge von 450 m ausgebaut. Das Lehnenviadukt mit einer Länge von 55 m wird abgebrochen, Aufschüttung durch Misapor. Die Strasse K270 wird mit einem Mehrzweckstreifen, einem Linksabbieger und einem Gehweg ausgebaut. Die zwei Bushaltestellen werden behindertengerecht erstellt. Zudem werden eine Wasserleitung, ein Medienrohr und weitere Werkleitungen verlegt.
