Description

Im neu geschaffenen Fachbereich «Fernwärme» ist ein Wärmeverbund an der Stettemerstrasse geplant. Die Wärmeerzeugung muss mit erneuerbarer Energie erfolgen. Dafür wird eine neue Hackschnitzelanlage erstellt. Für die Spitzenlastabdeckung und als Redundanz zu den Hackschnitzelkesseln werden zwei Gaskessel verwendet.
Gegenstand ist der Auftrag für die Lieferung, Einbringung, Montage, Installation und Inbetriebnahme
der elektrotechnischen Anlagen.
