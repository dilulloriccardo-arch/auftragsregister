Description

Das Obergericht des Kantons Zürich am Hirschengraben 15 in Zürich verfügt über eine nichtöffentliche Cafeteria. Die Betriebsgastronomie ist auf die Versorgung der vor Ort tätigen Personen ausgerichtet.

Nun soll dieser Bewirtschaftungsauftrag im Rahmen der vorliegenden Submission im offenen Verfahren neu vergeben werden. Gesucht wird eine entsprechende Cateringorganisation.
