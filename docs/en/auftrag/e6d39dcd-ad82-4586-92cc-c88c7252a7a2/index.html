Procurement of the WAB Crane Module

Public buyer
Wengernalpbahn AG
28 Jan 2027, 16:00Submission deadline
Documents and official publication on simap.chAdd the deadline to your calendarReport an error

Description

WAB intends to procure a new crane module to replace an old crane truck; this module will be mounted on an existing X 772ff module carrier using twist-lock fasteners. The vehicle-machine combination will then be pushed to the job site by a He(m) 4/4-type shunting locomotive. The work put out to bid includes the services specified in the JN_00000476 specifications.
