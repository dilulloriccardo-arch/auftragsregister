Description

Mit vorliegender Ausschreibung wird eine Software-as-a-Service (SaaS) Omnichannel Lösung beschafft. Diese ergänzt die bestehende CRM-Lösung mit einer zentrale Kundenkontaktkanal-Verwaltung bzw. einem einheitlichen Routing. Der angestrebte Customer Relationship Hub dient der Bearbeitung von Kundenanfragen im Bereich des öffentlichen Verkehrs. Es sollen mindestens 80 Nutzer auf dem neuen System berechtigt werden (inkl. Nutzungspauschalen etc.).
