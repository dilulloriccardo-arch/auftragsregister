Description

Project overview Das Eigentum an den Nationalstrassen der Schweiz liegt beim Bund. Betrieb und Unterhalt werden meist von kantonalen Baudirektionen per Leistungsvereinbarung gewährleistet. Es gibt 11 Gebietseinheiten, die für den betrieblichen Unterhalt der Nationalstrassen-Abschnitte in ihrem Kantonsgebiet sorgen. Dazu gehören unter anderem die Betriebs- und Sicherheitsausrüstungen (BSA). BSA sind inventarisiert und mittels AKS (Anlagenkennzeichnungssystem) mit einem eindeutigen Code versehen. Die Gebietseinheit XI will eine neue BSA/AKS-Lösung einführen. Mit AKS-GEXI soll ein System zur Verfügung stehen, welches die korrekte Datenerfassung und Bezeichnung von Betriebs- und Sicherheitsausrüstungen gewährleistet. Erfasste Daten durchlaufen einen Prüfungs- und Freigabeprozess. Das Endsystem soll als gehostete Webapplikation zur Verfügung stehen und sowohl zentral über fixe Arbeitsplätze wie auch über mobile Endgeräte zugänglich sein. Objectives (Ziele) Die Software-Lösung soll eine Webapplikation zur Erstellung und Aktualisierung von Komponenten, Datenpunkten und Beschriftungen sowie eine MobileApp zur Lokalisierung, Anzeige und Korrektur von Komponenten-, Datenpunkt- sowie Beschriftungs-Informationen umfassen. Die Phase 1 (Spezifikationen, die als Grundlage für die Ausschreibung der Phase 2 dienen) wurde bereits abgeschlossen. Die Phase 2 (vorliegende Ausschreibung) sieht die Realisierung der spezifizierten Tools AKS@GEXI (Grundausbau) vor.
