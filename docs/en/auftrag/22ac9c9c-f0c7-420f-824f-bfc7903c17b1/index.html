Contracting authority's reasons

Der Zuschlag wird an das vorteilhafteste Angebot gemäss den Zuschlagskriterien erteilt. Bewertet wurden die Kriterien Preis (Standartgeräte, Zubehör, Reparaturen) / Referenzen / Displayschutz / Support und Logistik. Mit einer Gesamtpunktzahl von 950 von 1’000 möglichen Punkten erzielte das Angebot der Zuschlagsempfängerin die höchste Bewertung und belegt somit den ersten Gesamtrang.

Description

Das Projekt umfasst die Beschaffung von 900 iPhone mit Ladegerät über einen Zeitraum von drei Jahren. Weitere Anforderungen gemäss Pflichtenheft in den Ausschreibungsunterlagen.
