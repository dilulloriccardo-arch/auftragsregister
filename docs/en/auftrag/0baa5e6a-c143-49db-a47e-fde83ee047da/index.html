Description

With this tender, FZAG aims to procure a modern, powerful contract lifecycle management (CLM) application as a SaaS solution. The goal is to provide a secure, scalable and user-friendly SaaS application that supports the entire contract lifecycle and ensures regular updates and compliance functions. In the first implementation phase, we will implement contract management/archiving by 31 December 2026 and, in the second implementation phase starting on 1 January 2028, we will begin implementing the remaining modules. The implementation of the CLM tool with all modules should be completed by 31 December 2028 at the latest. We reserve the right not to implement the second phase. The scope of the introduction includes the provision of the CLM application as a ‘SaaS’ solution, the migration of contracts and documents from the existing contract management application to the new CLM application, implementation and the development of expertise through training for the various user groups and the documentation of relevant topics.
