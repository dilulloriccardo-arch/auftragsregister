Description

Bei der St. Jakobshalle muss das gesamte Hängedach (90m Spannweite bzw. rund 7000 m²) in Bezug auf Wärmedämmung und Dachhaut erneuert werden. Gleichzeitig wird parallel eine Photovoltaikanlage auf dem Hängedach mit rund 1,3 MWp erstellt. Für den Rück- und Aufbau der Dachsanierung stehen 3 Monate zur Verfügung, die es einzuhalten gilt.
