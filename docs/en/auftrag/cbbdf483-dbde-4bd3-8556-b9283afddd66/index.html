Description

Erstellen, liefern und montieren einer Wärmeauskopplung von einem Heisswassersystem (PN25, 180°C) auf ein Warmwassersystem (PN16, 110°C) inklusive neuer Komponenten für die Versorgung eines neues Warmwasserfernwärmenetz. Beinhaltet insbesondere folgende neue Anlagen. Wärmeauskopplung (3x2.8 MW); Wärmespeicher (+/- 170 m3); neue Expansionsanlage; Anschluss Nachspeisung; neue Fernleitungspumpen; neue Entgasungsanlage; Diverse Messungen.
