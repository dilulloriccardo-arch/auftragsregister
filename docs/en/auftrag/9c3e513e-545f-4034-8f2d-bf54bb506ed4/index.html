Description

Der Auftrag umfasst die Planung, Lieferung, Montage und Inbetriebnahme eines Blockheizkraftwerks (BHKW) im Container einschliesslich aller erforderlichen Komponenten und Systeme. Das BHKW verfügt über eine elektrische Nennleistung von 360 kW (max. 630 A). Die Aufstellung erfolgt als Kompaktlösung im Freien.
