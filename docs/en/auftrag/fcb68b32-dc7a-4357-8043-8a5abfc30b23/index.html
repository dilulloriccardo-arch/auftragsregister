Description

Die IMION AG plant den Neubau einer Energiezentrale in Leukerbad (VS). Vorgesehen ist die Installation von zwei Wärmepumpen mit einer Gesamtleistung von ca. 3.0 MW zur Abdeckung der Grundlast.
Zur Deckung der Spitzenlast werden Holzkessel mit einer Gesamtleistung von 3.2 MW installiert.
Gegenstand dieser Ausschreibung sind die gesamten Heizungsinstallationen gemäss BKP 240. Davon ausgenommen sind die Lieferung und Einbringung der Wärmepumpen, der Holzkessel sowie der Speicheranlage.
