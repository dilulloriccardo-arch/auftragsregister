Description

Schulraumprovisorium in Modulbau als Gesamtleistung Generalunternehmer.

Kurzbeschrieb:
Am Standort der Parzelle 2197 an der Dorfstrasse in 5040 Schöftland wird auf dem bestehenden
Grundstück ein 2-geschossiger Pavillon in Modulbau erstellt.

Der Modulbau wird nicht unterkellert auf Streifen-, Punkt- oder Schraubfundamente gestellt.

Die Gebäudehülle entspricht dem Minergie-Standard bzw. den Anforderungen aus dem Energienachweis.

Die Erschliessung des oberen Stockwerkes erfolgt über den Aussenaufgang, das Erdgeschoss ist rollstuhlgängig erschlossen.

Das Projekt wird in einer Etappe erstellt.
