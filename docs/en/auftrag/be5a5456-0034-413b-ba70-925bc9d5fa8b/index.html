Description

Die Universität Zürich betreibt eine etablierte Apache Reverse Proxy Plattform (on premise) mit integrierter Web Application Firewall (ModSecurity/OWASP CRS). Die gesamte Infrastruktur ist bereits mittels Ansible vollautomatisiert und in Git versioniert. Das zugrunde liegende Betriebssystem (Ubuntu) wird durch einen externen Provider verwaltet.
Ziel dieser Ausschreibung ist die nahtlose Übernahme (Transition) sowie der langfristige Betrieb und das Engineering dieser bestehenden Plattform. Gesucht wird ein Partner, der die vorhandenen Playbooks, Custom-Apache-Module (C-Code) und WAF-Regelsätze übernimmt, die Schnittstellen zum OS-Provider (AppArmor, Netzwerk) bedient und die Umgebung technologisch (z. B. Ansible Collections, Mitogen) weiterentwickelt.
