Description

Mit dieser Ausschreibung «FlashStack» soll die Wartung der bestehenden Geräte, der Ersatz bestehender Hardware, die Erweiterung der Hardware im Rahmen von Projekten sowie 3rd-Level Supportleistungen für fünf Jahre ab Vertragsabschluss mit der optionalen Verlängerung um weitere fünf Jahre für ausgewählte Systeme bei Swissgrid beschafft werden.
