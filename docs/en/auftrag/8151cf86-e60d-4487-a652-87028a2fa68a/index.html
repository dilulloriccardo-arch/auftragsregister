Description

Vermessungsleistungen für die Beantwortung von Anforderungen wie : 1) NETZ VON FIXPUNKTEN (PF) Einrichtung eines Netzes von Präzisionsfestpunkten für die Arbeiten in den Phasen „Studien“ und „Ausführung“ auf dem Abschnitt Vennes (km 07'610) - Chexbres (km 20'400) ; 2) GEOMETRISCHE LEISTUNGEN WÄHREND DER PHASE „STUDIEN“. Die Planung der Unterhalts- und Ausbauarbeiten erfordert eine genaue Kenntnis der aktuellen Fahrbahnen, der Bauwerke und der Anlagen im Zusammenhang mit der Oberflächenentwässerung und dem Stromnetz ; Durchzuführende Leistungen : · Vermessung von Detailpunkten auf Nationalstraßen ; · Vermessung von Detailpunkten auf Bauwerken ; · Vermessungen von Kammern ; · Vermessung von Punkten außerhalb der Nationalstraße ; 3) GEOMETRISCHE LEISTUNGEN WÄHREND DER AUSFÜHRUNGS- UND REALISIERUNGSPHASE. Durchzuführende Leistungen: · Kontrollen der Absteckungen ; · Detailaufnahmen für die Erstellung konformer Pläne durch die Projektautor. Jede andere Anforderung von Vermessungs- und Beratungsleistungen auf Anfrage des BH.
