Description

Die Telecom SBB innerhalb der Division Infrastruktur, betreibt eine Bahnkommunikationsanlage für den sicheren Bahnbetrieb. Über diese Anlage werden Lautsprecher auf den Perrons durch Audio-Verstärker für manuelle und automatisierte Durchsagen angesteuert. Im Kontext dieser Signallaufkette, werden Konverter eingesetzt, welche die Signale entsprechend den technischen Gegebenheiten (z.B. IP auf Analog) übersetzen. Der Service der Lautsprecherdurchsagen ist im Bahnumfeld ein wichtiger Bestandteil für die Kundeninformation oder im Ereignisfall (z.B. Evakuierung, Unfall, etc.) für zweckgebunden Durchsagen. Heute sind rund 1'300 Konverter an ca. 800 Standorten schweizweit in Betrieb. Die SBB sucht eine Anbieterin, welche für die erwähnten Konverter eine neue Lösung anbieten kann. Services wie Gewährleistung, Reparatur, Software-/Firmwareentwicklung, Überwachung, Konfiguration, Management, Abwicklung etc. sind zu der bestehenden Hardwarelösung für ein wirtschaftliche, effiziente und qualitative Komplettlösung anzubieten.
