Description

Die Psychiatrie St. Gallen (PSG) plant zur Unterstützung sämtlicher HR-Kernprozesse die Beschaffung und erfolgreiche Einführung einer integrierten HR-Suite innerhalb eines ERP-Systems.

Dazu will die PSG per Ende Q2/2026 einen Vertrag mit einem Dienstleister abschliessen. Der Auftrag umfasst die Projektleitung, die fachliche Konzeption, die Systemeinrichtung und -konfiguration, die Datenmigration, die Integration in bestehende Umsysteme, die Durchführung von Test sowie Schulungsleistungen. Zudem beinhaltet er die Unterstützung beim Produktivstart, die strukturierte Übergabe in den Betrieb sowie die Sicherstellung von Wartung und Support über die gesamte Vertragsdauer. Weitere Informationen im Dokument <Informationen zur Präqualifikation.pdf>.

Das Verfahren wird als selektives Verfahren im Staatsvertragsbereich (WTO/GPA) durchgeführt. Zur Teilnahme am weiteren Vergabeverfahren wird eine Präqualifikation der Anbieter gemäss IVöB durchgeführt.

In der vorliegenden Phase werden ausschliesslich Teilnahmeanträge entgegengenommen. Die detaillierten Angebotsunterlagen werden ausschliesslich den präqualifizierten Anbietern zugestellt.
