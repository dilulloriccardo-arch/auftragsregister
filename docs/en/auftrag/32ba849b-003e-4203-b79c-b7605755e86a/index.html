Description

Die Hochschule Luzern beabsichtigt, einen externen Partner zum Bezug von SAP Basis Dienstleistungen für den Betrieb, Unterhalt und das Monitoring der neuen on-premises SAP S/4HANA-Systemumgebung und den dazugehörenden Datenbanken zu evaluieren. Zusätzlich ist das Monitoring von SAP Cloud Services erforderlich, insbesondere SAP Analytics Cloud.
