Description

Cloud Architekt: Cloud Architekten entwerfen und implementieren Lösungen unter Berücksichtigung der UZH Cloud-Strategie. Ihre Aufgaben umfassen die Gestaltung von Cloud-Umgebungen mit Fokus auf Skalierbarkeit, Sicherheit und Kosteneffizienz. Zudem verantworten sie das Anwendungsdesign für Cloud-Lösungen und übernehmen eine zentrale Rolle als Ansprechperson in allen Phasen der Cloud-Initiative. Software Engineer mit Cloud Kenntnissen: Die Cloud Softwareentwickler/innen konzipieren, erstellen und warten Cloud-native und Hybrid-Anwendungen. Sie schreiben Code, richten automatisierte Bereitstellungspipelines ein und verwalten die dazugehörige Cloud-Infrastruktur, um sicherzustellen, dass die Systeme sicher, skalierbar und kosteneffizient sind. Ihre Rolle umfasst sowohl die Anwendungsentwicklung als auch die Bereitstellung der zugrundeliegenden Cloud-Umgebung. Cloud Adoption Spezialist: Die Cloud-Adoption-Spezialisten unterstützen bei der Migration von Daten und Diensten in die Cloud. Dazu gehören die Migration von Anwendungen, die Gewährleistung von Sicherheit und Compliance sowie FinOps Aktivitäten. Sie unterstützen auch im laufenden Cloud-Betrieb. Sie begleiten die Umsetzung von Vorhaben und stellen dabei u.a. die Einhaltung von Compliance Anforderungen sicher. Darüber hinaus führen sie Schulungen für UZH-Mitarbeitende durch. Cloud Network Engineer: Cloud Network Engineers stellen ein funktionales Cloud-Netzwerk und dessen Anbindung zum On-Prem Netzwerk sicher. Dabei werden die konzeptionellen Anforderungen berücksichtigt, u.a. durch bestehende Zonen-Konzepte, IPAM und DNS
