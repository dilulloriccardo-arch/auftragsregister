Description

Die EPFL beabsichtigt, für das Discovery Learning Lab Physics der Fakultät für Grundlagenwissenschaften ein Rastermagnetmikroskop zu erwerben, das magnetische Strukturen mit einer Auflösung von 50 nm abbilden kann. Die Ausrüstung wird der hochmodernen Forschung in der Quantenerkennung magnetischer Strukturen unter Verwendung der neuen Technik der Fluoreszenz von N-V-Zentren in Diamant gewidmet sein. Im Hinblick auf die Bedürfnisse der EPFL und die spezifischen wissenschaftlichen Ziele ihres Physik-Lehrlabors (DLL Physique) wird der Schwerpunkt auf die folgenden Forschungsbereiche gelegt: Anwendung des Quantenraster-Magnetmikroskops: • Abbildung magnetischer Domänen in Ferromagneten, Antiferromagneten und komplexen magnetischen Strukturen • Messung von Quanteneffekten wie Spin-Entspannung und ESR • Lernen, wie man ein quasi-perfektes 2-Quanten-Niveausystem für die Magnetsensorik nutzt • Messung von magnetische Suszeptibilität auf lokaler Ebene • Spintronik • Magnetostriktive Materialien
