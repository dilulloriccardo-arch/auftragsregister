Description

Lot 1

Die Logistikbasis der Armee (LBA) ist für die Belieferung von verschiedenen Snacks (Cracker assortiert, Fruchtmischung, Nussmischung, Traubenzucker) zugunsten der Schweizer Armee verantwortlich. Damit die LBA dieser Verantwortung gerecht werden kann, soll die Versorgung von Cracker (assortiert) zugunsten des Bedarfsträgers sichergestellt werden.

Lot 2

Die Logistikbasis der Armee (LBA) ist für die Belieferung von verschiedenen Snacks (Cracker assortiert, Fruchtmischung, Nussmischung, Traubenzucker) zugunsten der Schweizer Armee verantwortlich. Damit die LBA dieser Verantwortung gerecht werden kann, soll die Versorgung von einer Fruchtmischung zugunsten des Bedarfsträgers sichergestellt werden.

Lot 3

Die Logistikbasis der Armee (LBA) ist für die Belieferung von verschiedenen Snacks (Cracker assortiert, Fruchtmischung, Nussmischung, Traubenzucker) zugunsten der Schweizer Armee verantwortlich. Damit die LBA dieser Verantwortung gerecht werden kann, soll die Versorgung von einer Nussmischung zugunsten des Bedarfsträgers sichergestellt werden.

Lot 4

Die Logistikbasis der Armee (LBA) ist für die Belieferung von verschiedenen Snacks (Cracker assortiert, Fruchtmischung, Nussmischung, Traubenzucker) zugunsten der Schweizer Armee verantwortlich. Damit die LBA dieser Verantwortung gerecht werden kann, soll die Versorgung von Traubenzucker zugunsten des Bedarfsträgers sichergestellt werden.
