Description

Le bâtiment Central de l'Université des Bastions est en cours de transformation et rénovation.

Cet appel d'offres concerne la réalisation de différents types de faux-plafonds dans un bâtiment patrimonial afin de répondre à diverses contraintes actuelles :

- adaptation de la résistance au feu selon les normes en vigueurs ;
- amélioration de la qualité acoustique ;
- des compléments de plafond dans les zones abimées ;
- pour améliorer le confort dans les bureaux des combles, ajout de plafonds actifs pour du rafraichissement ;
- fermeture amovible par le biais de bacs métalliques dans les blocs sanitaires et certains espaces techniques.
