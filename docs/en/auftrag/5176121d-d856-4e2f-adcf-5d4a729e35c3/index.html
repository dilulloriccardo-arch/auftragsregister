Description

Das IGE betreibt eine von der Bundesverwaltung losgelöste autonome (Informatik-)Infrastruktur. Zur betrieblichen Unterstützung der internen Informatikabteilung greift es für bestimmte Aufgaben und Fachgebiete auf externe Unterstützung zurück. Als Ergänzung der internen Informatikabteilung wird ein Unternehmen gesucht, welches das IGE bzgl. Linux Betrieb unterstützen kann (Generelle Betriebsunterstützung, Beratungsmandate, System Integrationsunterstützung, Projektunterstützung)
