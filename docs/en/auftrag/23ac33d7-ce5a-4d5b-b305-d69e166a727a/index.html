Description

Aktuell hat IWB 84 000 Smartmeter im Einsatz. IWB wird diese Anzahl kontinuierlich erweitern, um dem vorgegebenen Ziel der Gesetzgebung gerecht zu werden.

Um diese Geräte zu betreiben, wird eine Software eingesetzt, die laufend weiterentwickelt wird, mit dem Ziel der Verbesserung und Korrektur vorhandener sowie der Erweiterung mit neuen Funktionen, die sich von Anregungen und Wünschen der Praxis, von sich ändernden Systemumgebungen (aktualisierte Systemsoftware etc.) bzw. von gesetzlichen Rahmenbedingungen ableiten. Daher muss die Software regelmässig aktualisiert werden. Bei IWB steht die Software des Lieferanten NES im Einsatz. Die Aktualisierungen der Software (siehe Anhang C1 «SIP Datasheet») werden von NES jedoch nicht direkt an die Versorger, sondern ausschliesslich über Reseller, sogenannte Development-Partner, ausgeliefert. Die Firma NES bietet für die NES-Systemsoftware, für NES Softwaretools und die zugehörigen NES-Komponenten (Datenkonzentratoren, Zähler, Lastschaltgeräte, OSGP-Endgeräte) umfangreichen Support an. Mit dem Software Investment Protection (SIP) Platinum Service werden sämtliche Weiterentwicklungen und Systemverbesserungen abgedeckt. Die NES Wartung (SIP Service Platinum) beinhaltet Software und Firmware Updates innerhalb der gleichen Releases sowie Upgrades auf weitere Releases für Zähler, DC/DCN und NES System Software (Head End System), NES Provisioning Tool und NES Diagnostics Tool sowie Telefon und Web basierenden technischen Support. Aufgrund der bei IWB eingesetzten Software ist «SIP Platinum» oder gleichwertig erforderlich.

IWB benötigt einen Reseller, der uns die Systemanpassungen gemäss SIP Platinum auf einem von IWB definierten Datenübergabepunkt für die kommenden vier Jahre (2027-2030) zur Verfügung stellt.
