Description

Die Abteilung Strassenbau des Amts für Verkehr und Tiefbau im Kanton Solothurn setzt die Software TDcost ein. TDcost wird für die Mehrjahresplanungen (MJP) aller Projekte eingesetzt. Seit 2023 wird diese Software nicht mehr gewartet und kein Support mehr angeboten. Die fachliche Unterstützung bei der Anwendung von TDcost ist im Moment noch sichergestellt. Die Abteilung Strassenbau nutzt weiterhin TDcost auf eigenes Risiko, möchte jedoch eine neue Applikation zur Ablösung von TDcost beschaffen. Der Auftrag des vorliegenden Verfahrens umfasst folgende Leistungen: - Software für die Portfolioplanung - Schnittstellen - Datenmigration - Einführung und Schulung - Support Siehe auch Pflichtenheft.
