Description

L’Hôpital du Valais dispose de plusieurs systèmes de base de données liées à des applications médicales et souhaite se doter d’un partenariat pour le soutenir dans l’exploitation de celles-ci.
Dans ce cadre, le Service Informatique lance le présent appel d'offres. Ce dernier a pour objet l’acquisition d’un contrat de services pour ses bases de données Oracle et MSSQL.
