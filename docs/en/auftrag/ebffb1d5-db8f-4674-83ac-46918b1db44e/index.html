Description

Das Schulhaus Notker wird Gesamtsaniert. In diesem Zusammenhang wird ein Fassadengerüst benötigt für die Dach- und Fassadensanierung. Zusätzlich soll mit einem Fassadenaufzug die Materialeinbringung vereinfacht werden. Ergänzend wird ein Flächengerüst im 4.OG benötigt für die Deckensanierung zum Dachgeschoss. - Gerüstarbeiten Hauptteil: KW 30 - 47 / 2026 - Option Gerüstaufzug: bis KW 15 / 2027
