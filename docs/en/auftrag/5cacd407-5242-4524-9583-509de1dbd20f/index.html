Reasons given by the public buyer

Den Zuschlag erhält die Firma Guma AG, welche als einzige Anbieterin ein Angebot eingereicht hat. Das Angebot erfüllt die Eignungskriterien sowie die technischen Spezifikationen vollumfänglich.

Description

Die Logistikbasis der Armee (LBA) ist für die Belieferung von Dessertcrème Schokolade in Portionen zugunsten der Schweizer Armee verantwortlich. Damit die LBA dieser Verantwortung gerecht werden kann, soll die Versorgung von Dessertcrème Schokolade in Portionen zugunsten des Bedürfnisträgers sichergestellt werden.
