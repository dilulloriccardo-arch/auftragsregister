Description

Lot 1 : Prestation de restauration scolaire pour deux écoles, l’école de Confignon et l’école de Cressy Le lot 1 comprend une tranche optionnelle prévoyant l’organisation d’activités parascolaires ponctuelles sous forme d’ateliers de cuisine pour les enfants en après-midi. Le nombre de repas prévus pour le lot 1 est d’environ 43'680 repas annuels (à savoir 260 repas pour les élèves et 20 repas pour les adultes par jour x 4 jours par semaine x 39 semaines par an = 43’680 repas).
