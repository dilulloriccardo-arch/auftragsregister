Description

Beim bestehenden Gebäude soll die Gebäudetechnik erneuert, energetische Sanierungen umgesetzt sowie die Erdbebensicherheit und Security verbessert werden. Die Leistungen betreffen alle hierbei erforderlichen Elektroarbeiten.
