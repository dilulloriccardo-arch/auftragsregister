Description

Das Projekt «2K5» ist die Erweiterung der Kehrichtverwertungsanlage Hagenholz in Zürich um eine dritte Verbrennungslinie (Details dazu siehe Teil B «Projektbeschrieb»). Die ausgeschriebenen Leistungen sind in folgende Leistungsverzeichnisse (LV) gegliedert: - BKP 253 – Sanitär Versorgungsleitungen Die jeweiligen Leistungsverzeichnisse sind im Teil C, Leistungsbeschrieb, aufgeführt.
