Description

Mit der vorliegenden Ausschreibung wird eine Anbieterin für den Betrieb, Wartung und Support einer cloudbasierten Vorlagenmanagementsoftware im Bereich MS Office evaluiert. Die Vorlagenmanagementsoftware soll als SaaS Lösung angeboten werden.

Diese Software soll der zentralen Erstellung, Verwaltung und Bereitstellung von Unternehmensvorlagen in den MS-Office Tools dienen. Die Anbieterin übernimmt die Verantwortung für den reibungslosen Betrieb der Software, inklusive der regelmäßigen Wartung und technischen Support.
