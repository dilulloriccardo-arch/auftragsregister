Description

Der 21.9 km lange Nationalstrassenabschnitt zwischen den Verzweigungen Luterbach und Härkingen gehört zu den Strecken mit regelmässigen Kapazitätsüberlastungen. Im Abschnitt Luterbach – Härkingen ist nun eine Erweiterung um je einen Fahrstreifen pro Fahrtrichtung vorgesehen. Der Projektperimeter ist in drei Abschnitte eingeteilt. Der vorliegende Auftrag ist verantwortlich für die Niederspannungsanlagen auf dem ganzen Perimeter. Leistungen: - Lieferung, Ausbau und Montage von Niederspannungsschaltschränken - Lieferung, Ausbau und Montage von Schränken der Bereiche: - Kommunikation&Leittechnik - Kabelanlagen - Dokumente - Lieferung von Schränken (Grundausbau) an diverse Los der Bereiche: - Signalisation - Überwachung - Nebeneinrichtung - Lieferung, Ausbau und Montage von Niederspannungsverteilkabinen - Lieferung von Verteilkabinen (Grundausbau) an diverse Los der Bereiche: - Signalisation (QSK) - Nebeneinrichtung (Kabine für Pumpwerk und SABA) Dienstleistungen: - Realisierungspflichtenheft - Projektbesprechungen - Begehungen u. Abklärungen vor Ort - Prüfschritte für die Werksprüfung (Factory Acceptance Test) - Prüfung im Werk (Factory Acceptance Test / Teilnahme an Factory Integration Test) - Installation, Inbetriebnahme, Funktionstest - Prüfschritte für die Schlussprüfung (Site Acceptance Test) - Prüfung vor Ort (Site Acceptance Test /Teilnahme an Site Integration Test) - Probebetrieb - Dokumentation des ausgeführten Werkes - Abnahme
