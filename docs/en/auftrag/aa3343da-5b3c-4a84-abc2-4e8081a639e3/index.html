Description

The aim is to implement the Federal Administration's cloud strategy of 11 December 2020 (SB020 – Federal Cloud Strategy). To this end, this procurement is being carried out using the selective procedure in accordance with Article 19 of the PPA and is divided into three lots:
- Lot 1: Public cloud – global reach (public cloud with global data storage)
- Lot 2: Public cloud – enhanced data governance (public cloud with data storage and processing exclusively in Switzerland)
- Lot 3: Private cloud – on premises (private cloud with data storage and processing exclusively at the requesting office's locations)

In order to spread outage and security risks across several tenderers, increase security of supply and reduce dependence on individual tenderers, the requesting office is pursuing a multi-supplier strategy.
A total of five awards will be made (two each for lots 1 and 2, and one for lot 3), each to a different tenderer, for the acquisition of the cloud services and related goods/services put out to tender here. To achieve this objective, a lot limitation within the meaning of Article 32 paragraph 3 of the PPA is provided for.

Further information can be found in the tender documentation.
