API-Management-System

Public buyer
Stadt St.Gallen, Stadtwerke
30 Nov 2026, 12:00Submission deadline
Documents and official publication on simap.chAdd the deadline to your calendarReport an error

Description

The following objectives are to be achieved through the API Management Solution procurement project:

- Procure a standardized API management system that meets the requirements of all use cases across the OT-OT, OT-IT, IT-IT, and IT-Public domains. The rollout shall be carried out incrementally, starting with the OT environment and the OT-IT transition. The additional IT and IT Public Gateway environments shall be available as optional orderable extensions.

- The integration of web interfaces shall provide logical decoupling between requesting and source systems, while ensuring that systems are protected against unauthorized access and excessive traffic through authentication, authorization, and appropriate security mechanisms.

- The new partner shall support sgsw flexibly and according to operational needs, both during the implementation phase and throughout the subsequent years of operation.

- The IT-OT transition implemented via the API management solution shall be designed in such a way that it can be centrally deactivated, if required, using a small number of predefined steps (discrete OT environment).

A comprehensive API management solution shall be procured and implemented in phases, separated by system environment:

- OT Environment (initial scope of supply)
- IT-OT Transition (initial scope of supply)
- IT Environment (option / extension without any acceptance guarantee)
- IT Public Gateway (option / extension without any acceptance guarantee)

As part of this software procurement, the API management solution shall support scalable licensing that can grow in line with demand (flexible/tiered licensing model within the respective system environments). No hardware procurement is envisaged. The central components are described below.
