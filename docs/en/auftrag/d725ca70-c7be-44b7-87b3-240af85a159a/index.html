Description

Die Fachapplikation TRA ist seit 2010 beim ASTRA im Betrieb. Das System ist ein zentrales Element zur Erhaltungsplanung der Nationalstrassen. Die heutige Anwendung läuft stabil und performant und wird von den Anwendern geschätzt. Es sind keine grossen neuen fachlichen Wünsche bekannt, welche dazu führen würden, das System fundamental umzubauen. Die Fachapplikation wird beim BIT betrieben.

Für die Leitung der SW-Pflege und für den Fachsupport von 2026 bis 2032 sucht das ASTRA einen Auftragnehmer, der in Absprache mit dem Auftraggeber weitgehend selbständig folgende Aufgaben übernimmt:
- Aufnahme der fachlichen Bedürfnisse
- Spezifikation der Anforderungen
- Koordination und Begleitung der Umsetzung
- Durchführung von Abnahmetests
- Nachführung der Handbücher
- Einführung von neuen Releases
- Fachliche Unterstützung der Anwender

Der Auftraggeber kann in Absprache mit dem Auftragnehmer weitere Zusatzleistungen bestellen.
