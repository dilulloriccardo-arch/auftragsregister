Description

Der Beschaffungsgegenstand umfasst
- die Lieferung, den Einbau und das Erstellen der Betriebsbereitschaft von 3 Oracle Database Appliance X11 HA Systemen mit Oracle Premium Support für Betriebssystem/Hardware und Oracle System Software (jeweils für 5 Jahre) inkl. Netzwerkanschlüssen und Cabling,
- die Migration der Datenbanken,
- Unterstützungsarbeiten für Backup/Recovery und Monitoring.

Optionaler Beschaffungsgegenstand sind Betriebsunterstützungsleistungen.
