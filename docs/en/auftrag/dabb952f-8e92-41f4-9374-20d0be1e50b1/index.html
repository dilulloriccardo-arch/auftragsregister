Description

The subject of this procurement is a digital air situation awareness and collision warning system to be provided as a turnkey Software-as-a-Service (SaaS) solution. The system shall be capable of receiving live telemetry data from the deployed drones via API, fusing such data in real time with traffic data from cooperative airspace participants, and generating an immediate alert whenever an aircraft or other flying object penetrates the drone's moving protective volume (moving geofence).
