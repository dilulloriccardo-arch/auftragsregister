Description

In den Räumlichkeiten des Alterszentrum Du Lac beabsichtigt St. Moritz Energie, eine fossile Wärmeerzeugungsanlage für die Notversorgung und die Spitzendeckung des bestehenden Energieverbund St Moritz Bad einzubauen. In der neue Zentrale wird nebst einem Heizkessel eine Systemtrennung (Wärmetauscher) sowie eine Speicheranlage eingebaut.
