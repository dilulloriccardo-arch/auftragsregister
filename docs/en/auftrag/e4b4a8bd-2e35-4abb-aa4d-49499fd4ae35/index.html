Description

Die BLS Netz AG (nachfolgend BLS genannt) benötigt für die sichere Instandhaltung ihres Netzes technische Warnsysteme, die das Personal im Gleisumfeld von herannahenden Zügen warnt. Diese Ausschreibung dient der Auftragsvergabe zur Lieferung/Bereitstellung von mobilen Warnanlagen auf dem ganzen Netz der BLS. Mit dieser Ausschreibung soll ein Kauf-/Liefervertrag inkl. Wartung sowie einem Rahmenvertrag für Miete für die nächsten drei Jahre (Vertragsbeginn 1. Januar 2027) abgeschlossen werden mit Option auf Verlängerung von jeweils zweimal einem Jahr bis maximal 31. Dezember 2032.
