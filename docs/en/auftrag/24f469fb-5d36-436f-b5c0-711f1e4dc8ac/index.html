Description

The articulated 40 km/h wheeled excavator with outriggers is intended to serve as an all-round machine for municipal operations. It will be used to carry out waterway maintenance—utilizing the necessary extended or interchangeable mowing boom—including mulching, hedge trimming, stump grinding, and mowing basket operations on embankments, as well as public infrastructure maintenance, for the Rheinunternehmen (Rhine Authority) depot in Widnau, Switzerland (CH-9443).
