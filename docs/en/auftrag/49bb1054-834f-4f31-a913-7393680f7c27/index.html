Contracting authority's reasons

La solution proposée répond de manière optimale aux exigences formulées dans le cahier des charges, tant sur les aspects fonctionnels que techniques. Description

Cet appel d’offres a pour but d’identifier et d’acquérir une solution Software-as-a-Service sous format de souscription et de l’intégrer dans l’infrastructure IT et organisationnelle de l’école. La mise en place d’un outil d’architecture doit nous permettre d’atteindre, notamment les objectifs principaux suivants : • Mesurer l’impact des projets sur le SI • Piloter le SI de manière proactive • Sensibiliser les utilisateurs sur l’état du SI • Offrir une Business Capability Map
