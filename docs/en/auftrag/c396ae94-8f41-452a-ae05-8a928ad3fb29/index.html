Description

Die bestehende Rundbahn der Sportanlage Gersag ist sanierungsbedürftig. Die Rundbahn, inkl. Sektoren wird mit einem Retoping und mit diversen kleineren Anpassungen aufgewertet. Gleichzeitig gibt es eine neue Einhausung für die Zeitmessung, diverse Anpassungen am Geräteraum werden vollzogen und die Beleuchtungsanlage wird auf LED-Umgerüstet.
