Description

Es ist im gesamten Gebäude eine Gebäudeautomationsanlage zu erstellen. Die Gebäudeautomation wird zur Einhaltung der Minergie Vorschriften im Zweckbau benötigt. Die Gebäudeautomation wird für folgende Punkte benötigt: - Sonnenschutz / Beschattung: Eine automatische Beschattung nach Sonnenstand und -einstrahlung, welche mit einer Wetterstation gemessen wird und die Beschattungansteuerbar macht für den Sonnenschutz / Überhitzungsschutz. Damit wird der sommerliche Wärmeschutz zur Unterstützung für Freecooling via Fussbodenheizung und Kühlung via Lüftung unterstützt. - Raumautomation (Heizen / Kühlen): Raumthermostaten über KNX in den Schalter integriert, Einzelraumregulierung mit Heiz-/Kühl-Aktoren (gleicher Aktor abhängig von der Aussentemperatur). Sowie Präsenzmelder mit integrierten Temperatursensoren in den Räumen ohne Schalter. Verhindern von Parallelbetrieb Heizen/Kühlen. - Lüftung: Ansteuerung der Volumenstromregler zur automatischen Regulierung der Durchströmmenge der Luft. - Licht: Präsenzmelder in allen relevanten Räumen mit Fenster für Konstantlichtregelung /tageslichtabhängige Steuerung. Damit das Licht nach Tageslichteinfall gedimmt werden kann, eine Abschaltung bei Abwesenheit erfolgt. Durch die automatische Lichtregelung wird Energie gespart und eine unnötige Wärmeerzeugung verhindert.
