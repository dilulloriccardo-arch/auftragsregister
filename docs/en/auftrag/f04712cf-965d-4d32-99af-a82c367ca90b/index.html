Description

Zur professionelleren Kommunikation und Verbesserung der Unternehmenswahrnehmung im Falle von Umleitungen und Baustellen beschafft die BVB mobile digitale Anzeigen für provisorische Haltestellen.

Die BVB beschafft mobile digitale Anzeigen mit Zubehör, Software und Lizenzen (digitale Fahrgastinformationen). Hierfür schliesst die BVB einen Rahmenliefervertrag mit einer Zuschlagsempfängerin ab.
