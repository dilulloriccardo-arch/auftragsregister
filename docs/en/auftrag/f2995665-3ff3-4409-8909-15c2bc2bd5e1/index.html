Reasons given by the contracting authority

Die beauftragte Firma reichte das vorteilhafteste Angebot ein.

Description

Um hygienisch optimale Bedingungen zu schaffen, erfolgt die Warmwasserzeugung mittels
Frischwasserstation über die Erdsonden-Wärmepumpe der Heizung. Das Warmwasser wird auf 60°C
erwärmt. Für einzelne Warmwasserentnahmestellen wie Putzräume und Teeküchen wird das
Warmwasser vor Ort durch kleine Elektroboiler bereitgestellt, wodurch lange Leitungen und hohe
Zirkulationsverluste vermieden werden. Auf den Einsatz von Warmwasser wird im Schulhaus wo sinnvoll verzichtet. Die horizontalen Verteil- und Sammelleitungen werden sichtbar oder in Abhangdecken geführt. Es wird für die Zugänglichkeit und Wartung der Leitungen, sowie für das SNBS- Label weitmöglichst auf Einlagen verzichtet.
San. Installationen im 2. + 3. UG müssen mittels einer Abwasserhebeanlage auf das
Kanalisationsniveau gepumpt werden. Das Regenwasser wird in einem Regenwassertank gesammelt und für die Umgebungsbewässerung genutzt. Wenn kein Regenwasser zur Verfügung steht, wird direkt Trinkwasser nachgespiesen.
