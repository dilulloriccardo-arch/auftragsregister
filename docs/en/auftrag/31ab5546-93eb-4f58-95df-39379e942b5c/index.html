Description

BERNMOBIL beabsichtigt, die Dienstleistungen für die Weiterentwicklung der bestehenden SAP S/4HANA-Lösung im Bereich Private Cloud mittel Rahmenvertrag zu vergeben. Ziel ist es, die bestehende Systemlandschaft strategisch und technisch weiterzuentwickeln sowie optimal an die zukünftigen Anforderungen anzupassen.
