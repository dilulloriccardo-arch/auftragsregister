Description

Lots 1, 2

Die Gemeinde Zumikon ist Eigentümerin zahlreicher Liegenschaften in Zumikon. Mit dieser Ausschreibung wird die Grünflächenpflege von ausgewählten Grünanlagen für vier Jahre ausgeschrieben - mit Option auf Verlängerung durch die Gemeinde Zumikon um ein weiteres Jahr. Die Pflege soll fachkundig geleistet werden und das ökologische Potential der Flächen ideal ausschöpfen.
