Description

Im Rahmen der Gesamtsanierung des Strandbads in Rorschach wird die bestehenden Badewasseraufbereitung durch eine der aktuellen SIA-Norm 385/9 entsprechende Anlage ersetzt. Insbesondere werden folgende Komponenten neu installiert:
- Druckanschwemmfilter inkl. Verrohrung und Armaturen
- Filterpumpen
- Steuerung
- Messungen
- Aggregate
- Beckenverrohrung
