Anzubieten sind die Bereitstellung, Konfiguration und Inbetriebsetzung eines intelligenten Messsystems (iMS) mit MDM als ASP Dienstleistung
iMS bestehend aus
- intelligenten Messgeräten (iMG) => Lieferung
- allfälligen Gateways => Lieferung
- einem Zählerdatenverarbeitungssystem (KMS, HES und MDM) inkl. Schnittstellen zu den Umsystemen => als Dienstleistung
- einem allfälligen Gateway Management => als Dienstleistung
- Energieportal => als Dienstleistung
