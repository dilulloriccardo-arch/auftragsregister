Beschreibung

BERNMOBIL beabsichtigt eine neue Komplettlösung für das Planungs- und Dispositionstool für die Fahrdienstleistenden zu beschaffen. Diese Software beinhaltet die Fahrplanung, die Dienstplanung sowie die Personaldisposition. Die Ausschreibung beinhaltet sowohl die Beschaffung der Software wie auch das gesamte Einführungsprojekt sowie die Wartung der Lösung.
