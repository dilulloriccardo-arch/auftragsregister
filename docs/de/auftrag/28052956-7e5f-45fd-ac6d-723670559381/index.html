Begründung des Auftraggebers

Es handelt sich um das vorteilhafteste Angebot auf Basis aller Kriterien.

Beschreibung

Der Auftrag umfasst die folgenden Arbeiten: - Die Sicherung der Fußgängerwege auf den Tunnelkappen durch die Schaffung von Betontreppen und Kieswegen. - Die Lieferung und Installation von BSA-Kabelschächten Typ S3 für die Installation von neuen SOS-Alarmkasten. - Die Erstellung von BSA-Kabeleinführungen in den technischen Räumen der Tunnelportale. - Die Schaffung von Kabelschächten und Fundamenten für die Installation von zukünftigen Verteilekabinen (QSK). - Die Neuinstallation und den Ersatz vom bestehenden Kabeltrasse und den Schutzabdeckungen des Kabeltrasse an den beiden Tunnelportalen. Die Arbeiten finden auf einer strategisch wichtigen Autobahnachse mit sehr hohem Verkehrsaufkommen statt.
