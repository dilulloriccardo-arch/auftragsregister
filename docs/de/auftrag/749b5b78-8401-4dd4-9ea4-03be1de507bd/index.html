Beschreibung

Die Siedlungsentwässerung der Stadt Luzern muss eine Meteorleitung auf dem Werftareal der SGV Shiptec AG erneuern. Die Leitung DN 600 wird auf einer Länge von 96m neu gebaut. Die Einleitstelle in den See wird auch erneuert. Die Shiptec AG baut in diesem Zusammenhang ebenfalls Werkleitungen. Schmutzwasserleitungen inkl. Ölabscheider usw. Der Baubereich liegt in einer Altlast und im Grundwasserbereich.
