Lieferung + Montage 16kV-MS-Schaltanlage TS ZM Lieferung + Einbringung 16/0.4kV-Transformatoren TS ZM Zur Versorgung der neuen Kälteerzeugungsanlagen im Gebäude E10, Energiezentral Mitte, wird im G02 eine neue Transformatorenstation mit der Bezeichnung TS ZM erstellt.
