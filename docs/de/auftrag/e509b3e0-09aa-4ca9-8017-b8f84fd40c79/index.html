Beschreibung

Eine grössere Anzahl Server erreichen in den nächsten Jahren ihr Lebensende (End of Life) und müssen ersetzt werden. Im Rahmen der Ausschreibung zur (Ersatz-)Beschaffung von Servern hat die ZI, das Beschaffungsvorhaben in fünf (5) Lose aufgeteilt: · Los 1: Serverinfrastruktur · Los 2: Serverinfrastruktur mit erhöhtem Arbeitsspeicher · Los 3: Serverinfrastruktur mit GPU Beschleunigung · Los 4: GPU Karten · Los 5: Server Management Software für die angebotenen Server
