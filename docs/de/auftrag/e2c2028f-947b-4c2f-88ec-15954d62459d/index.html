Beschreibung

Ce document, établi par GEMB traite de la description relative aux fournitures et aux travaux liées à l’appel d’offres (AO) du lot 302, dans le cadre de l’agrandissement de la STEP de Lucens. Il concerne les systèmes de ventilation et de rafraichissement décrites dans le lot. L’appel d’offres comprend notamment les études de détail, les fournitures, les travaux de montage, les essais, les réglages, les mises en service et les instructions de service.
