Beschreibung

Die FHNW sucht eine Partnerin für den Betrieb der IRF (Institutional Repository) inkl. SaaS‑Lösung. Es wird ein Dienstleistungsvertrag über vier (4) Jahre mit der Option auf Verlängerung um zwei (2) Jahre abgeschlossen. Die Dienstleistungspartnerin hat die FHNW mit spezifischen Dienstleistungen zu bedienen, wie: - Support - Aktualisierung der Software - Fixieren von Bugs - Weiterentwicklung - Bereitstellung und Betrieb der SaaS-Lösung.
