Beschreibung

Les travaux objet du présent marché consistent dans le renouvellement de certaines sous-installations d’éclairage dans les tunnels de Gentilino et de Maroggia, y compris le démontage et l’élimination des installations existantes. Elles resteront en service tant que les nouvelles installations auront passé avec succès tous les tests prévus dans le cahier des charges. Les principales activées des travaux sont : - renouvellement complète du système de gestion – éclairage ; - renouvellement complète de l’installation éclairage de traversée; - renouvellement complète de l’installation éclairage d’adaptation; - renouvellement complète de l’installation balisage lumineux; Pour la structure des supports des équipements électromécaniques installés dans l’espace de trafic (partie assemblée) est requise une certification de résistance au feu E60.
