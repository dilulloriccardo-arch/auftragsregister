Beschreibung

Die Auftragnehmerin liefert eine Vialsabfüllmaschine und einen Vialswasher, folgend als System genannt. Das System arbeitet im Verbund und ist aufeinander abgestimmt. Das Systems wird im pharmazeutischen GMP-Bereich betrieben (DIN EN ISO 14644-1). Das System muss in die bestehende Infrastruktur und den vorgegebenen Raum (ISO 7 - Hygienezone C) integriert werden. Der bestehende und verbaute Laminar Flow (über dem Abfüllbereich) hat die gleiche Hygienezone wie der Raum. Das System soll 100 mL Vials aus Glas verarbeiten und die Leistung soll bei 20 - 40 Vials pro Minute liegen.
