Contracting Mélèzes Susten - BKP 240 Heizungsanlage

Beschreibung

Das Projekt Contracting Mélèzes in Susten (VS) umfasst die zentrale Wärmeversorgung von insgesamt sieben Gebäuden (A bis G) über ein gemeinsames Wärmenetz. Die Wärmeerzeugung erfolgt über einen Holzkessel mit einer Heizleistung von 255 kW. Zur Wärmespeicherung sind vier Pufferspeicher mit einem Volumen von jeweils 3'000 Litern vorgesehen. Die Wärmeverteilung erfolgt mit einer Systemtemperatur von 70/50 °C. Jedes Gebäude verfügt über eine eigene Wärmeübergabestation mit Plattenwärmetauscher, Regelarmaturen, Umwälzpumpen und Wärmezähler. Zur Gesamtanlage gehören zudem die erforderlichen Sicherheitseinrichtungen.
