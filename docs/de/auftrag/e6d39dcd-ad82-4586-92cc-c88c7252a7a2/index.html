Beschreibung

Die WAB beabsichtigt als Ersatz für einen alten Kranwagen ein neues Kranmodul zu beschaffen, welches mittels Twist-Lock-Verriegelungen auf einem bestehenden Modultragwagen X 772ff montiert wird. Die Fahrzeug-Maschinen-Kombination wird anschliessend mit einer Schiebelok vom Typ He(m) 4/4 zum Einsatzort geschoben. Die ausgeschriebenen Arbeiten umfassen die Leistungen gemäss Lastenheft JN_00000476.
