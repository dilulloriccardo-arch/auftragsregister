Beschreibung

Mit dieser Dienstleistungsausschreibung möchte die Kantonspolizei Zürich eine geeignete und zeitgemässe Werbe-/Designagentur, mit der Umsetzung einer neuen Personalwerbekampagne beauftragen.
Mit der vorliegenden Ausschreibung wird eine «All-in-One-Agentur» gesucht. Die Arbeitgebermarke der Auftraggeberin soll positiv ausgebaut werden, um auf dem polizeilichen Arbeitsmarkt Schweiz eine tragende Rolle einzunehmen. Insbesondere soll der Fokus auf digitale Produkte und digitale Marketingstrategien ausgerichtet werden.
