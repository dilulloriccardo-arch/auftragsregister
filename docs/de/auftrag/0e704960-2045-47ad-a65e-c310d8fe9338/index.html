Korrosionsschutz 2027

Beschreibung

Anbringen von Korrosionsschutzanstrichen an Stahltragwerken von Hochspannungsleitungen vor Ort. Detaillierter Projektbeschrieb im Dokument C2 Swissgrid Standard Korrosionsschutzarbeiten sowie C3.1 Leistungsverzeichnis.

Insgesamt werden Arbeiten für 231 Hochspannungsmasten (220/380 kV) und rund 109'500 Quadratmeter ausgeschrieben.

Es gibt ein maximales Vergabevolumen pro Anbieter gemäss den Bedingungen in der Verfahrensanweisung.
