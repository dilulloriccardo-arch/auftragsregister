Beschreibung

Das neue Kraftwerk wird über den Erschliessungsstollen Grimsel 4 (EGR4) erschlossen. Der neue Stollen zweigt ab dem bestehenden Erschliessungsstollen Handeck – Gerstenegg ab. Er wird im Sprengvortrieb ausgebrochen und hat eine Länge von rund 1.4 km. Der Ausbruchquerschnitt beträgt ca. 28 m2. Im Anschluss an den Erschliessungsstollen ist zudem eine Montagekaverne (Montagearbeiten Stahlwasserbau) mit einem Volumen von ca. 2'600 m3 (fest) auszubrechen
