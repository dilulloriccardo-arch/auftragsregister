Beschreibung

Das Projekt "2K5" ist die Erweiterung der Kehrichtverwertungsanlage Hagenholz in Zürich um eine
dritte Verbrennungslinie (Details dazu siehe Teil B "Projektbeschrieb").

- BKP 281.11
