Beschreibung

Le système du niveau de gestion centralisé MCRG pour la Suisse Romande (système PC Vue) est utilisé dans l'automatisation des bâtiments pour tous les sites d'armasuisse Immobilier Romandie. Dans une première phase, le mandataire doit compléter différentes fonctionnalités sur le système. Par ailleurs, au cours des prochaines années, le mandataire devra intégrer de nouvelles installations de technique du bâtiment dans le système de gestion centralisé sur différents sites. Les stations d'automatisation dans les différents bâtiments sont réalisées dans le cadre de projets de construction ou de rénovation par différents entrepreneurs et avec différents produits d'automatisation BacNet.
