Beschreibung

Im Rahmen des Projekts zur Renovierung und Erweiterung des Werkhofs San Bernardino Süd, ist die ausführliche Planung und Errichtung hocheffizienter doppelseitiger Photovoltaikanlagen erforderlich, die senkrecht auf den Dächern der Gebäude B/C/E/F installiert werden.
Die Photovoltaik-Module sind in eine Metallstruktur integriert und auf mit Kies überzogenen Grundplatten befestigt.

Die Abmessungen jedes Photovoltaikmoduls betragen 1,76m x 1,13m.

• Gebäude B - Mechanikerwerkstatt

Auf dem Dach sollen etwa 250 Module installiert werden, was einer Plattenfläche von ca. 500 m2 entspricht. Es wird eine Modulleistung von 455 Wp (Vorderseite) angenommen, was eine Gesamtleistung von 113,8 kWp für die Dächer des Gebäudes B ergibt.

• Gebäude C - Elektrowerkstatt
Auf dem Dach sind rund 240 Module zu installieren, was einer Plattenfläche von ca. 480 m2 entspricht. Es wird eine Modulleistung von 455 Wp (Vorderseite) angenommen, was eine Gesamtleistung von 109,2 kWp ergibt.

• Gebäude E - Lager
Auf dem Dach sind rund 44 Module zu installieren, was einer Plattenfläche von ca. 88 m2 entspricht. Es wird eine Modulleistung von 455 Wp (Vorderseite) angenommen, was eine Gesamtleistung von 20 kWp ergibt.

• Gebäude F - UTGR-Wartungsgebäude
Auf dem Dach sind rund 153 Module zu installieren, was einer Plattenfläche von ca. 300 m2 entspricht. Es wird eine Modulleistung von 455 Wp (Vorderseite) angenommen, was eine Gesamtleistung von 69,6 kWp ergibt.
