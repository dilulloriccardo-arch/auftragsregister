Beschreibung

Das Schulhaus Notker in Gossaus SG, ein denkmalgeschütztes Schulhaus, wird Gesamtsaniert. Das Hauptdach wird überarbeitet, die Mansarden werden bauphysikalisch aufgewertet, Absturzsicherungen, Blitzschutz, Schneefang, Anschlüsse und Bleche werden saniert
