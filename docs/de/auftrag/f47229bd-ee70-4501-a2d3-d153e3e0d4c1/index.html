Beschreibung

Le marché mis en soumission dans le présent appel d’offres en procédure ouverte est un mandat pluridisciplinaire pour l’élaboration de deux PLQ sur le secteur Praille Ouest. Les compétences recherchées sont les suivantes : - Urbanisme - Architecture - Paysage - Mobilité - Energie - Environnement L’adjudicataire sera un groupement, composé et organisé selon le document A1 - Instructions et directives.
