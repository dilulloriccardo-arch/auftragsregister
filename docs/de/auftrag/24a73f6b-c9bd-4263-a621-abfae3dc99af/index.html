Begründung des Auftraggebers

Die Zuschlagsempfängerin hat das preislich günstigste Angebot eingereicht. Sodann hat sie beim Zuschlagskriterium «Erfahrung, Referenzen» eine gute bis sehr gute Bewertung erhalten. Bezüglich des Zuschlagskriteriums «Schlüsselpersonen» erhielt sie ebenfalls eine gute bis sehr gute Bewertung. Insgesamt hat sie daher in der Gesamtbewertung am besten abgeschnitten. Im Ergebnis hat damit die Burkhardt Gebäudehülle AG, 7304 Maienfeld mit 485 von 500 erzielbaren Punkten das vorteilhafteste Angebot eingereicht, womit ihr der Zuschlag zu erteilen ist.
