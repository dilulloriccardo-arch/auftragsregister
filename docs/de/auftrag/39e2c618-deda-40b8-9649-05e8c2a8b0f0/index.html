Begründung des Auftraggebers

L'offre a été jugée la plus avantageuse sur l'ensemble des critères d'appréciation fixés dans le dossier d'appel d'offres.

Beschreibung

Il s’agit d’un marché de fournitures. Le présent appel d’offres porte sur l’acquisition de 1'250 smartphones pour l’offre de base.

L’offre remise devra également inclure le chiffrage des options suivantes :
- 1’250 fourres de type professionnel ;
- 1’250 protections d’écrans et installation par le soumissionnaire sur le matériel avant livraison ;
- 1’250 casques phonie compatibles avec le matériel proposé ;
- 500 batteries de rechange, activables par commande de 20 exemplaires ;
- Réalisation du paramétrage des équipements : profil MDM+ configuration de base + identification de chaque boite (1’250 équipements) ;
- Réalisation de la distribution et paramétrage sur site (1’250 conducteurs) ;
- 500 smartphones en option sur 4 ans, activable par commande de 50 exemplaires

Ces smartphones devront notamment être compatibles avec la technologie 5G a minima et adaptés à l’univers professionnel de l’activité du client (conducteur bus, métro, train, intervenants terrain, etc.).
