Beschreibung

Die bestehende Gebäudeautomation wird ersetzt. Parallel dazu wird der
bestehende Gaskessel durch eine EWS-Wärmepumpe ersetzt. Die
Erdwärmesonden werden ausserdem für eine Free-Cooling-Anwendung
genutzt. Zudem werden sämtliche Lüftungskomponenten jeglicher Lüf-
tungsanlagen ersetzt.
