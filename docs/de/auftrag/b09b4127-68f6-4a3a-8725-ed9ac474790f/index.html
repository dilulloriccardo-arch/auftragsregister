Beschreibung

Für den Neubau Garage Rank benötigt die BVB diverse Stempelanlagen (Hebevorrichtungen) für das Anheben von Normalbussen, Gelenkbussen und Doppelgelenkbussen. Total werden 7 Anlagen benötigt. Mit dem Zuschlagsempfänger wird ein Werkvertrag abgeschlossen.
