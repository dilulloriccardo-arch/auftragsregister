Beschreibung

Das Kantonale Tiefbauamt Thurgau plant eine erneute Korridordigitalisierung des Kantonsstrassennetzes, die Daten sollen danach als «digitale Strasse» in 3D für Planungs- und Betriebsarbeiten bereitgestellt werden. Dies stellt eine Aktualisierung zu den Korridordigitalisierungen von 2015 und 2019 dar.

Auf die aktualisierten Informationen zum Strassenraum kann direkt via Web-Viewer zugegriffen werden. Die Möglichkeiten darin umfassen neben der Ansicht aus verschiedenen Blickwinkeln auch hinterlegte Geodaten und die Möglichkeit zu Abmessungen aus dem Bild. Der Zugriff kann direkt via ThurGIS erfolgen.

Dieses «Ökosystem der digitalen Strasse» bietet unter anderem den folgenden Nutzen:
• Zustandsbeurteilungen
• Geometrische Analysen
• Grundlagen für Lärmanalysen
• Erfassung und Beurteilung von Schwachstellen
• Informationsmedium

welche direkt vom Computer ausgeführt werden können.

Der detaillierte Projekt- und Leistungsbeschrieb ist dem Dokument B der Ausschreibungsunterlagen zu entnehmen.
