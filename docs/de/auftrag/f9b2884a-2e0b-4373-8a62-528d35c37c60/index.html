Beschreibung

Gegenstand der Beschaffung sind Beratungsleistungen im Bereich Data Governance. Konkret sucht IWB eine Firma, welche auf das Thema spezialisiert ist und über viel Wissen und Erfahrung im Thema Data Governance verfügt. IWB erwartet vom Anbieter den Nachweis, dass der Anbieter mindestens über zwei Berater verfügt, welche die Mindestanforderungen zum Data Governance (Lastenheft Ziffer 1.3 ff.) vollumfänglich erfüllen und diese anbieten kann.
