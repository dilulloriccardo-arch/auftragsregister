Gratis abonnieren

Beschreibung

Das STZ beabsichtigt über die nächsten Jahre neue Intensivbetten zu beschaffen, welche die hohen Spitalanforderungen an Qualität erfüllen.

Die derzeit eingesetzten Intensivbetten haben ihr Lebensende erreicht und müssen ersetzt werden.

Im Rahmen dieser Ausschreibung soll eine Anbieterin evaluiert werden, die ein am Markt etabliertes Intensivbett innerhalb des vorgesehenen Zeitrahmens liefern kann, welches auf Thoraxhöhe mit dem C-Bogen durchleuchtbar ist.
