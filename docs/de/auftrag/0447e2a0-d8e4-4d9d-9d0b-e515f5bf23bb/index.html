Beschreibung

Die Einwohnergemeinde Reichenbach beabsichtigt zum Zwecke der Kontrolle des ruhenden Verkehrs im Ordnungsbussenverfahren auf dem Gebiet der Einwohnergemeinde Reichenbach wiederum einen privaten Drittpartner beizuziehen. Derzeit besteht ein Vertrag, welcher per 31.12.2026 ausläuft. Aus diesem Grund erfolgt eine Ausschreibung dieses Dienstleistungsauftrages für eine Dauer von 5 Jahren mit einer Option auf Verlängerung um 2 Jahre.
