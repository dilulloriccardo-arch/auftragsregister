Begründung des Auftraggebers

Das Angebot der CKW Gebäudetechnik AG weist den tiefsten Angebotspreis auf und erzielte bei diesem Kriterium die maximale Punktzahl. Beim Zuschlagskriterium Qualität / Referenzen erhielt die Zuschlagsempfängerin eine sehr gute Bewertungen. Damit fiel nicht weiter ins Gewicht, da das Angebot der CKW Gebäudetechnik AG auch beim Kriterium Ökologie + Nachhaltigkeit, Lehrlingsausbildung eine sehr gute Bewertung erhalten hat.

Beschreibung

In Birmensdorf wird eine neue Dreifachturnhalle auf dem Areal der Schulanlage Stundenmätteli gebaut werden. Für das Gebäude wird keine Minergie-Zertifizierung angestrebt, jedoch sollte der Neubau möglichst in Anlehnung des Minergiestandards realisiert werden. Der Neubau beinhaltet eine Dreifachsporthalle, neben der Halle wird ein dreistöckiger Anbau mit Garderoben, Duschanlagen, WC-Anlagen, Abstell- und Technikräumen erstellt.
