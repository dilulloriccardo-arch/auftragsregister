Beschreibung

Gesucht wird eine Standard-Software für die Projektierung von Elementen der Sicherungsanlagen und Leittechnik auf einem schematischen Gleisnetz zur Planung der Bahninfrastruktur. Diese soll vorzugsweise via Webbrowser nutzbar sein und entsprechend den Bedürfnissen der SBB parametrisierbar / konfigurierbar sein sowie mit spezifischen Erweiterungen ergänzt werden können. Spezifische Funktionalitäten für die SBB sollen über klar definierte API’s eingebunden werden können. Bestandteil der Beschaffung sind Lizenzen, Einführung, Schulung, Dokumentation, Wartung/Support. Optional ist die Implementierung kundenspezifischer Regeln, Schnittstellenanpassungen und die Migration bestehender Daten wie auch Betrieb und Hosting der Software durch den Anbieter. Der vollständige Beschaffungsgegenstand kann aus den Ausschreibungsunterlagen entnommen werden.
