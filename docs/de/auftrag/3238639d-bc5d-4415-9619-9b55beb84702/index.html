Beschreibung

Das Strassenkreisinspektorat beabsichtigt im Jahr 2026 / 2027 die Hauptstrasse in Staad von der Wilenrampe bis zur Buechenrampe zu sanieren. Im Projektperimeter wird eine komplett neue Entwässerung mit dazugehörigen Reinigungsschächten erstellt. Zudem werden die Randsteine teilweise demontiert und neu versetzt. Im Bereich der Hafenstrasse erfolgt eine neue Fussgängerquerung mit entsprechender Anpassung der Bushaltestellen (BehiG). Der Belag im Gehweg wird neu erstellt. In der Fahrbahn erfolgt jeweils eine prov. Instandstellung der Fahrbahn. Im Abschluss wird der Belag bis auf die Tragschicht flächig gefräst und neue erstellt (AC B 22H und SDA 4-12/16).

Auf der gesamten Länge erfolgt eine neue Rohranlage bzw. neue Fundamente für die öffentliche Beleuchtung.

Zudem erfolgt im Abschnitt Staad ein neues Leerrohr für die technischen Betriebe Thal. Auf der Höhe
Buechenstrasse erfolgt ein Ersatz des T-Stückes für das Wasser.

Im Rorschacherberg werden die Hausanschlüsse vom Wasser teilweise erneuert bzw. die bestehende Rohranlage von den EW entsprechend ergänzt.

Die Swisscom ersetzt die Deckel der Schlaufschächte.

Das Bauamt Thal erstellt eine Hochwasserentlastung vom Bahnhof Staad bis zum See (Durchmesser bis 800mm, teilweise GFK).
