Beschreibung

Für ausgewählte Bauprojekte soll die Bauherrenvertretung an eine externe Projektleitung Bauherrschaft (Beauftragter) delegiert werden oder diese soll beratend der Bauherrschaft (Bauherrenunterstützung) zur Seite stehen.
