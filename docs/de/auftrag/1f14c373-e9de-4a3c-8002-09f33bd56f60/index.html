Beschreibung

Die Ausschreibung beinhaltet den Neubau Kunstrasenfeldes Sportanlage Grünfeld in Jona. Der Kunstrasen soll im Unverfüllten System verbaut werden.

Es ist aufzuzeigen, dass die entsprechende fachgerechte Entsorgung und Recyclingswege eingehalten werden.
