Beschreibung

Mit der vorliegenden Beschaffung sucht das Spital Emmental den geeignetsten und finanziell vorteilhaftesten Managed Security Service Provider (MSSP) für den Betrieb eines Security Operations Center (SOC) as a Service. Der MSSP soll dabei Dienstleistungen im Bereich Security Operations Center (SOC) während einer Laufzeit von 3 Jahren plus optionaler Verlängerung als Generalunternehmen erbringen.
