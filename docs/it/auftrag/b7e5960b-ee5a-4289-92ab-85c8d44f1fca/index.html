Motivazione del committente

Das Angebot der Zuschlagsempfängerin, erfüllt die definierten Anforderungen in vollem Umfang. Die vorgeschlagene technische Lösung überzeugt im Besonderen durch ihre einfache Implementierung sowie durch ihre Skalierbarkeit und bietet damit eine zukunftsorientierte Grundlage.

Descrizione

Mit dieser Ausschreibung wird die künftige Beauftragte für Lieferung, Wartung und Support der städtischen «Speicherlösung», bestehend aus der Infrastruktur für (i) Storage Area Network (SAN), (ii) Block Storage, (iii) Network Attached Storage (NAS) und (iv) Object Storage-Infrastruktur sowie, bei entsprechendem Entscheid der Vergabestelle, einer Backuplösung für die Network Attached Storage Systeme für die nächsten maximal 10 Jahre, festgelegt.
