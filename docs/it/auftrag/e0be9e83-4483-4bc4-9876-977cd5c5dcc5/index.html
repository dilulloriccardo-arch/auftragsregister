Descrizione

Das KSGL beabsichtigt die Beschaffung eines Medizinischen Universalarchivs (MUA). Ziel ist die Einführung einer zentralen Plattform zur revisionssicheren Speicherung, Verwaltung und Bereitstellung medizinischer Bild- und Dokumentdaten. Das neue System soll bestehende Datensilos auflösen, klinische Workflows unterstützen und eine langfristige Archivierung gemäss regulatorischen Anforderungen sicherstellen.
