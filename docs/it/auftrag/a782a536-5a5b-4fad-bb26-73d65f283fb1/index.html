Descrizione

Für den Neubau Garage Rank sucht die BVB eine Unternehmung, welche die Zutrittskontrolle und die Schliessanlage liefern und montieren kann. Mit dem Zuschlagsempfänger wird ein Werkvertrag abgeschlossen.
