Motivazione della scelta

Den Zuschlag erhält die Firma Garmin Switzerland Distribution GmbH, die als einzige Anbieterin ein Angebot eingereicht hat. Das Angebot erfüllt sämtliche Eignungskriterien sowie die technischen Spezifikationen vollumfänglich.

Descrizione

Im Rahmen dieser Beschaffung wird ein Sortiment an neuen GNSS-Empfängern beschafft.

Das Sortiment besteht aus den folgenden Geräten:
· GNSS-Handgerät «klein»
· GNSS-Handgerät «gross»
· GNSS Fz Gerät «PW»
· GNSS Fz Gerät «LKW»
