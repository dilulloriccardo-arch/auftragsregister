Descrizione

Das Projekt «Lichtraumprofil-Massnahmen Häggenschwil-Winden – St. Gallen» umfasst Massnahmen zur Behebung von Einragungen ins Lichtraumprofil (fünf Fahrbahnabsenkungen sowie ein Neubau einer Überführung), welches neu auf das Lichtraumprofil (EBV2) angepasst werden soll. Im Weiteren umfasst der Auftrag sechs Teilabschnitte für eine Fahrbahnerneuerung im Zusammenhang mit den Fahrbahnabsenkungen. Die Ingenieurleistungen umfassen die Phase SIA 31 für die folgenden Fachbereiche: Projektleitung inkl. Fachbereichskoordination Ingenieurbau Tiefbau / Fahrbahn Ingenieurbau Tragkonstruktionen / Kunstbauten
