Descrizione

Das Gebäude wird Minergie-A/P-ECO zertifiziert. Holzgebäude dreigeschossig, 34m lang, 24m breit und 11m hoch Anzahl: Rund 60 Fenster, 22 Oberlichtfenster Spezifikationen: - Holzfenster mit farbloser Lasur - Holzrahmen 90mm Stärke, Festverglasung, Flügel - Fensteranschlussfolie - Dreifachverglasung Ug ≤ 0.6 W/m2K - Randverbund ψ ≤ 0.03 Wm/ K - Fensterrahmen Uf ≤ 1.25 W/m2K - Lichttransmissionsgrad tL = 72% - Aussenreflexionsgrad von max. 15% - g-Wert = 0.49
