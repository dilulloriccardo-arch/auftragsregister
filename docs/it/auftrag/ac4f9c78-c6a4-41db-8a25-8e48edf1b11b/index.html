Descrizione

Zur Umsetzung der Neugestaltung der Statthalterstrasse werden Baumeisterarbeiten gefordert. Der Abschnitt zwischen Morgen- und Wangenstrasse soll verkehrsberuhigt werden. Konkret wird die Fahrbahn verengt, ein neuer Grünstreifen wird erstellt, das nördliche Trottoir wird chaussiert und ein neuer sickerfähiger, eingefärbter Fahrbahnbelag wird eingebaut.
