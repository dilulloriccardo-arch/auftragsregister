Erneuerung der amtlichen Vermessung der Gemeinden : - Prez, Sektor Noréaz, auf einer Fläche von 690 ha und ohne Vermarkungsrevision ; - Grolley-Ponthaux, Sektor Ponthaux, auf einer Fläche von 566 ha und ohne Vermarkungsrevision.
