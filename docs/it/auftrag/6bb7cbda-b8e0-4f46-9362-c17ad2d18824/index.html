Motivazione della scelta

Lotti 1, 3

Das berücksichtigte Angebot hat aufgrund seiner Merkmale und Vorteile die meisten Nutzwertpunkte (NWP) erzielt. Die Zuschlagskriterien (ZK) wurden wie folgt bewertet:

ZK 1 Preis: 185.59 von 200 NWP
ZK 2 Referenzauftrag Anbieter: 220 von 300 NWP
Total: 405.59 von 500 NWP

Die Anbietenden können sich unabhängig von einer allfälligen Beschwerde für ein informelles Debriefing über kfoeb@bs.ch bei der Kantonalen Fachstelle für öffentliche Beschaffungen melden.

Lotti 2, 4, 5, 6, 7, 8

Wegen Loslimitierung in diesem Los kein Zuschlag an das Angebot mit den meisten Nutzwertpunkten (NWP). Die Zuschläge werden gemäss den in der Ausschreibung beschriebenen Regel an die über alle Lose betrachtet vorteilhafteste Kombination von Angeboten vergeben. Das berücksichtigte Angebot wurde aufgrund seiner Merkmale und Vorteile in den Zuschlagskriterien (ZK) wie folgt bewertet:

ZK 1 Preis: 0 von 200 NWP
ZK 2 Referenzauftrag Anbieter: 300 von 300 NWP
Total: 300 von 500 NWP

Die Anbietenden können sich unabhängig von einer allfälligen Beschwerde für ein informelles Debriefing über kfoeb@bs.ch bei der Kantonalen Fachstelle für öffentliche Beschaffungen melden.
