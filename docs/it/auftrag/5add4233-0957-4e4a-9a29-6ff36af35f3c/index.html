Motivazione dell’aggiudicazione

Offre économiquement la plus avantageuse, c'est à dire représentant le meilleur rapport entre les critères d'adjudication énoncés dans l'ordre décroissant.

Descrizione

Lotto 1

Classeurs A4 4 cm.
Pour le lot 1, tous les cantons participants souhaitent acquérir des classeurs.

Lotto 2

Classeurs A4 7 cm.
Pour le lot 2, l’Etat de Genève, l’Etat du Valais et l’Etat de Fribourg souhaitent acquérir des classeurs.

Lotto 3

Classeurs « école » pour la distribution générale dans les écoles primaires et enfantines du canton de Genève.
Pour le lot 3, seul l’Etat de Genève souhaite acquérir des classeurs.

Lotto 4

Classeurs « école » pour la distribution générale dans les cycles d’orientation du canton de Genève
Pour le lot 4, seul l’Etat de Genève souhaite acquérir des classeurs.
