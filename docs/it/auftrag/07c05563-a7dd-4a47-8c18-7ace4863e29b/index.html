Motivazione della scelta

Das Angebot der Zuschlagsempfängerin erwies sich nach sorgfältiger Evaluation der eingereichten Angebote als das vorteilhafteste im Sinne von Art. 41 Interkantonale Vereinbarung über das öffentliche Beschaffungswesen (IVöB; SAR 150.960) vom 15. November 2019 (Stand 1. Juli 2021). Der Vorteil des berücksichtigten Angebots lag massgeblich beim Kriterium Preisangebot.

Descrizione

Der Betrieb von MS-SQL-Servern an der FHNW umfasst folgende Dienstleistungen:

-Vollumfängliches Betreiben der Microsoft SQL Server an der FHNW inkl. Einsatz lizenzpflichtiger Monitoringlösung.

-Abwickeln von Aufträgen im Zusammenhang mit dem Microsoft SQL Server Betrieb
-Beratung und Unterstützung im Microsoft SQL-Server Umfeld zur Verbesserung und Entwicklung der Datenbankumgebung.
