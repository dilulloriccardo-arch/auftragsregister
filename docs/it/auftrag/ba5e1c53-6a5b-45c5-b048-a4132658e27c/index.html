Descrizione

In der bestehenden RhB Werkstatthalle in Landquart soll eine moderne Abgas-Absauganlage installiert werden, damit Lokomotiven mit oben- und untenliegenden Auspuffendrohren fachgerecht abgesaugt werden können.
Die neue Absauganlage soll dem heutigen Stand der Technik entsprechen und so gestaltet werden, damit eine effiziente Absaugung alle im Fuhrpark der RhB befindlichen Looks abgesaugt werden können, und auch für Diesel Aggregate auf den Wagen angewendet werden können
