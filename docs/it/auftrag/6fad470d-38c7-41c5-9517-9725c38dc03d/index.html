Descrizione

Les Explorateurs de l’Énergie est un programme ludo-pédagogique développé en 2004. Il propose un grand concours inter-cantonal ouvert à tous les établissements primaires de Suisse romande, qui constitue le temps fort du programme.

Le marché concerne la recherche d'un prestataire pour la gestion de ce programme ludo-pédagogique.
