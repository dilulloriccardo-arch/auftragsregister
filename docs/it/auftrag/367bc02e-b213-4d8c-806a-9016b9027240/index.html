Descrizione

Gegenstand des vorliegenden Vergabeverfahrens ist die Auswahl und die Einführung eines Package Repositories, auch Artifact Repository genannt. Die Lösung kann auf firmeneigener Hardware selbst gehostet oder als SaaS Dienst betrieben und genutzt werden. Die Lösung soll ein Repository mit automatisiertem und manuellem Blacklisting von potenziell schädlichen Packages beinhalten, sowie eine Software Bill of Materials erstellen können.

Der Leistungsumfang umfasst zudem Unterstützungsleistungen bei der Einführung der Software, der Konfiguration des Metamodells, der Integration in die bestehende Systemlandschaft, sowie Leistungen für Betrieb, Wartung und Support.

Gesucht wird ein Anbieter, der das IWB Package Repository Tool zur Verfügung stellt und in den folgenden Bereichen Leistungen anbietet:

· Zugriffe für ca. 50 User
· Unterstützung bei Implementierung, Konfiguration, Customizing sowie bei der Anbindung über Schnittstellen
· Schulung der relevanten Benutzergruppen sowie strukturierter Wissenstransfer
· Wartungs- und Supportleistungen während der gesamten Vertragslaufzeit
· Automatisierte und manuelle Filterung von schadhaften Packages
· Alarmierung bei Erkennung von schadhaften Packages
