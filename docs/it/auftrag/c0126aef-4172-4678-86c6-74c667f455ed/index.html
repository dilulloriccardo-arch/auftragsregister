Descrizione

Für die Stationsstrasse und die Kreuzwiesenstrasse in Igis (Gemeinde Landquart) wurde ein Betriebs- und Gestaltungskonzept erarbeitet. Dieses soll nun umgesetzt werden. Im Rahmen der vorliegenden Ausschreibung soll das Bauprojekt inklusive Bewilligungen und Ausführung erarbeitet werden (SIA Phasen 31-53).
