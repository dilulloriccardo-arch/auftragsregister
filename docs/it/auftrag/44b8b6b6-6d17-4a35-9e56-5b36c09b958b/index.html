Descrizione

Das bestehende Laborgebäude wird im laufenden Betrieb umgebaut. Die Beleuchtungsinstallationen werden erneuert, bestehende Installationen demontiert und neue Beleuchtungskörper fachgerecht montiert. BKP 233 Lieferung von Leuchten.
