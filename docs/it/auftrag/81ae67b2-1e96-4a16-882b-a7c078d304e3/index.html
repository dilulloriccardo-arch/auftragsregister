Descrizione

Le présent appel d’offres porte sur la collecte des déchets ménagers urbains, en porte-à-porte, sur le territoire de la commune de Moudon. Cela concerne les déchets incinérables (deux fois par semaine), le papier-carton (une fois par mois). La population desservie est d’environ 6'800 habitants.
