Descrizione

Il bando comprende modifiche del sistema di gestione LSK esistente, necessari a seguito del rinnovo dell’impianto segnaletica della galleria San Bernardino. Prestazioni principali: -modifica software del sistema di gestione LSK per integrazione del nuovo sistema di comando segnaletica e dei nuovi pannelli a messaggio variabile (PMV, comando tramite centrale di gestione traffico); -modifica software impianto ausiliari per integrazione di nuovi disgiuntori; -modifica software impianto illuminazione per trasmissione del valore della luminanza alla segnaletica; -fornitura e posa nuovi quadri di comando PMV, incl. PLC.
