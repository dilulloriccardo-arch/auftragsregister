Ausgangslage / Projektbeschrieb
Die Axpo Grid AG beabsichtigt die Beschaffung von 8 Stück SF6- gasisolierten- Leistungsschaltern 123 kV für das Unterwerk Niederurnen.

Die ausgeschriebenen Leistungen umfassen folgende Hauptarbeiten:

- Herstellung und Prüfung von 8 Stück SF6- gasisolierten- Leistungsschaltern 123 kV gemäss Spezifikation: EE00371 110-kV-AIS-Schalter Technische Spezifikation Rev.05 Gasisolierte Schalter

- Lieferung der SF6- gasisolierten- Leistungsschalter 123 kV
