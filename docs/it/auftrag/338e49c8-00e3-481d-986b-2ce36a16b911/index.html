Descrizione

La Commune de Bourg-en-Lavaux (Maître de l’Ouvrage) envisage de transformer le bâtiment « Watteville », afin de créer plusieurs logements. Pour ce faire, le Maître de l’Ouvrage a réalisé une étude de faisabilité. Sur la base de ce document, le Maître de l’Ouvrage a opté pour la variante 1.3, avec trois appartements, pour un montant d’investissement estimé à environ 3,7 mio TTC, avec les aménagements extérieurs. Fort de ce qui précède, la commune souhaite organiser un appel d’offres pour le mandat d’architecture, pour les phases 32 à 53, organisé en procédure « ouverte » (sans présélection), respectant la loi sur les marchés publics, non soumise aux marchés internationaux.
