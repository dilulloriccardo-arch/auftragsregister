Motivazione della scelta

Das Angebot hat in der Gesamtbewertung der Zuschlagskriterien die höchste Punktzahl erreicht.

Descrizione

Gesamtinstandsetzung des Restaurants Degenried, Generalplanungsleistungen (unter Vorbehalt der Kreditgenehmigung)

Das Restaurant Degenried in Zürich Hirslanden wurde seit der Erstellung 1971 nur punktuell verändert. Es stehen umfangreiche bauliche Massnahmen für eine Instandsetzung an. Neben dem Haupthaus mit der Gastwirtschaft gehört auch ein Ökonomiegebäude zum Ensemble. Das Ziel ist die kostengünstige Gesamtinstandsetzung der Gebäude zur Sicherstellung der Gebrauchstauglichkeit für einen Zeitraum von weiteren 25-30 Jahren. Zudem soll die Wirtewohnung zu einem Saal umgebaut werden, damit das Restaurant mehr Innenplätze anbieten kann.

Beschaffung von Generalplanungsleistungen (BKP 298.1) mit folgenden vorgeschriebenen Teammitgliedern / Fachbereichen:
– BKP 291 Architektur / Baumanagement
