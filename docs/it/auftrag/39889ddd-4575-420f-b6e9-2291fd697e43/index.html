Descrizione

Cet appel d’offres porte sur l’attribution d’un marché pour la fourniture, installation et mise en service d’équipements basse tension ainsi que de mise à terre.

Un descriptif détaillé des travaux est donné dans le document [B2] Série de prix. Les principales prestations attendues sont les suivantes :
- Distribution et ensembles d’appareillage 400VAC /50 Hz ;
- Eclairages ;
- Eclairages de sécurité ;
- Equipements basse tension (force, coffret-prises)
- Equipements CVS ;
- Télécommunication et courant faible ;
- Automatisation du bâtiment et KNX ;
- Mise à la terre ;
- Infrastructure à câbles ;
- Câbles ;
- Equipements provisoires.
