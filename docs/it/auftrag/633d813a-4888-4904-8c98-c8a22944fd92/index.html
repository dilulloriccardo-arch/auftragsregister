ZK 1 Preis: 300 von 300 NWP
ZK 2 Kann-Kriterien: 81.68 von 125 NWP
ZK 3 Optionale Ausstattung: 51.67 von 75 NWP
Total: 433.35 von 500 NWP
Es handelt sich um einen Rahmenvertrag. Der Zuschlagspreis bezieht sich auf die maximale Bezugsmenge. Es besteht kein Anspruch auf vollständigen Abruf derselben.

Die Anbietenden können sich unabhängig von einer allfälligen Beschwerde für ein informelles Debriefing über kfoeb@bs.ch bei der Kantonalen Fachstelle für öffentliche Beschaffungen melden.
