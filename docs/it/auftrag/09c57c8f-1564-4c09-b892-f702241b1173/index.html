Motivazione della scelta

Das berücksichtigte Angebot hat aufgrund seiner Merkmale und Vorteile die meisten Nutzwertpunkte (NWP) erzielt. Die Zuschlagskriterien (ZK) wurden wie folgt bewertet:

ZK 1 Preis: 350 von 350 NWP
ZK 2 Referenzauftrag Anbieter: 96.67 von 100 NWP
ZK 2 Referenzauftrag Schlüsselperson: 0 von 50 NWP
Total: 446.67 von 500 NWP

Die Anbietenden können sich unabhängig von einer allfälligen Beschwerde für ein informelles Debriefing bei der Kantonalen Fachstelle für öffentliche Beschaffungen melden.

Descrizione

- Ausführung von Baumeisterarbeiten
- Erstellen von Fundamenten aus Stahlbeton
- Wasserhaltung, da Ausführung im Grundwasser
- Abdichtungsarbeiten
- Kernbohrungen
- Erstellen von Baustelleneinrichtung
