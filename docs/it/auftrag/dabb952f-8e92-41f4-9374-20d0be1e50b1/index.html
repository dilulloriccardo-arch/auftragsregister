Descrizione

Ausgeschrieben wird ein digitales Luftlage- und Kollisionswarnsystem (LKS) als schlüsselfertige Soft-warelösung (SaaS). Das System muss in der Lage sein, die Live-Telemetriedaten der eingesetzten Drohnen via API zu empfangen, diese mit den Verkehrsdaten kooperativer Luftverkehrsteilnehmer in Echtzeit zu fusionieren und beim Eindringen von Flugobjekten in das mitfliegende Schutzvolumen (Moving Geofence) der Drohne umgehend Alarm zu schlagen.
