Motivazione della scelta

Descrizione

Die Logistikbasis der Armee (LBA) ist für die Belieferung von Nussaufstrich in Portionen zugunsten der Schweizer Armee verantwortlich. Damit die LBA dieser Verantwortung gerecht werden kann, soll die Versorgung von Nussaufstrich in Portionen zugunsten des Bedürfnisträgers sichergestellt werden.
