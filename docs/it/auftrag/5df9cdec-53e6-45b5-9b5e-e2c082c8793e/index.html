Descrizione

Mit der vorliegenden Ausschreibung sucht die Gemeinde Glarus Nord einen zuverlässigen und wirtschaftlich günstigen Lieferanten für das Catering Tagesstrukturen, über welchen kindgerechte, ausgewogene Mahlzeiten für die Mittagstische bezogen werden können.
