Sanierung der Altbauten Gymnasium Hofwil:
2.1 Hauptgebäude: Div. neue Brandschutztüren, div. neue gestemmte Türen / div. Brandschutztüren mit gestemmter Aufdoppelung, Türergänzungen, Glastrennwand neu.

2.3 Mensa: neue WC Türen UG, neue Brandsschutztüre UG/ Rahmentüre UG, div. Zargentüren.

2.4 Wohnhaus: div. neue gestemmte Türen / div. Brandschutztüren mit gestemmter Aufdoppelung.
