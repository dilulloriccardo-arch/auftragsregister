Descrizione

BKP 248 Gebäudeautomation, im Wesentlichen bestehend aus:
- Lieferung GA-Server / Leitrechner inkl. Programmierung Software und Inbetriebsetzung
- Lieferung der GA-Schaltgerätekombinationen (SGK) für die Steuerung der HLS-Anlagen inkl. Programmierung der Software und Inbetriebsetzung (Total 8 SGKs)
- Lieferung und Inbetriebsetzung der Netzwerkkomponenten für das Gebäudeautomations- Netzwerk
- Lieferung der Feldgeräte gemäss beiliegendem Leistungsverzeichnis-Feldgeräte
