Motivazione della scelta

Die Zuschlagsempfängerin hat das preislich günstigste Angebot eingereicht. Sodann hat sie beim Zuschlagskriterium «Referenzen der Unternehmung» eine gute Bewertung erhalten. Bezüglich des Zuschlagskriteriums «Qualifikation des Schlüsselpersonals» erhielt sie eine gute bis sehr gute Bewertung. Insgesamt hat sie daher in der Gesamtbewertung am besten abgeschnitten. Im Ergebnis hat damit die Marti AG, Bauunternehmung, 8050 Zürich mit 480 von 500 erzielbaren Punkten das vorteilhafteste Angebot eingereicht, womit ihr der Zuschlag zu erteilen ist.

Descrizione

Baumeisterarbeiten, Abbrucharbeiten, Altlastensanierung, Werkleitungen
