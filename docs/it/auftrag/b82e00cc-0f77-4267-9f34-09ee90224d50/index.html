Descrizione

Les tpg souhaitent acquérir 1700 tablettes et ses accessoires pour le personnel de conduite afin de permettre à ces derniers d'accéder à leurs applications via un équipement tpg sécurisé, facilitant ainsi leurs opérations quotidiennes. Dans le futur, les tpg auront besoin d’acquérir un certain volume d’appareils complémentaires compatibles pour les fournir aux futurs collaborateurs (et pour le remplacement des appareils endommagés) Pour plus de précision, merci de se référer au cahier des charges.
