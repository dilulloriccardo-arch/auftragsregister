Descrizione

Prestazioni di servizio per la manutenzione del software e dell’ampliamento delle licenze, l’appalto prevede:
- I servizi della manutenzione del software SAP dal 01.01.2027 al 31.12.2028 (due anni), con la possibilità di ampliamento annuale per ulteriori tre anni, termine massimo 31.12.2031;
- La fornitura per l’ampliamento delle licenze SAP nel periodo di manutenzione sopra citato.
