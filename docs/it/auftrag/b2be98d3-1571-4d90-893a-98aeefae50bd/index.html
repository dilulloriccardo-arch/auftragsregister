Descrizione

Le lot 1 comprend les prestations ordinaires d’ingénieur chauffage, ventilation et MCR pour les phases suivantes:
- Avant-projet
- Projet
- Phase préparatoire de l’exécution
- Phase de l’exécution
- Phase finale (mise en service)

Des prestations spécifiques sont aussi comprises dans ce lot et décrites dans le cahier des charges.
