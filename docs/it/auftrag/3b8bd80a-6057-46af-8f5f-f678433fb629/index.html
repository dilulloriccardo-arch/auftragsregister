PV-Anlage Wohnsiedlung Salzweg

Descrizione

Das Elektrizitätswerk der Stadt Zürich (ewz) erstellt eine Photovoltaikanlage auf dem Neubau der Wohnsiedlung Salzweg, Rautistrasse 309-323 / 331-345 / 351-365 in 8048 Zürich. Die Anlage umfasst insgesamt 745 Module mit einer Gesamtleistung von 365 kWp. Die Installation erfolgt etappenweise ab Mai 2027.
