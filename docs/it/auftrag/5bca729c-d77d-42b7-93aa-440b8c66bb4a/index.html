Descrizione

Der Auftrag umfasst die Ausführung folgender Arbeiten: - Erstellung eines Geschiebesammlers mit einem Rückhaltevolumen von ca. 12'000 m3 - Neubau von vier Wildbachsperren (eine mit Leitwerken und Vorschwelle) - Entfernung von Altlasten - Erstellung einer verankerten Mikropfahlwand - Schaffung ökologischer Ausgleichsflächen - Rückbau mehrerer Beton- / Bruchsteinbauwerken - Umlegung und Neubau von Werkleitungen - Neubau asphaltierte Strasse - Neubau mehrerer Weiher
