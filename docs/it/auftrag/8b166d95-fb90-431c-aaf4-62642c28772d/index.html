Descrizione

Erneuerung der bestehenden Kälteerzeugung:
Die beiden bestehenden Kälteerzeugungsanlagen mit einer Kälteleistung von jeweils 70 kW werden ausser Betrieb genommen und demontiert. In einem ehemaligen Wasserreservoir im 2. Untergeschoss wird eine neue Kältezentrale erstellt. Die neuen Kältemaschinen verfügen ebenfalls über eine Leistung von jeweils 70 kW und verwenden ein natürliches Kältemittel. Die bestehenden Rückkühler werden weiterverwendet. Zudem werden die neuen Anlagen mit einer Abwärmenutzung für die Heizung ausgerüstet.Ein bestehender Kältespeicher wird weitergenutzt; ein zusätzlicher Kältespeicher wird in der neuen Zentrale installiert. Die beiden Hauptgruppen der Kälteverteilung werden erneuert. Im Hochtemperatur-Kältenetz erfolgen hydraulische Anpassungen an den Kälteverbrauchern.
