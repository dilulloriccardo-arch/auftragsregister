Motivazione della scelta

Descrizione

Die Werkstatt des D-ITET ersucht um die Abgabe von Offerten für eine 5-Achs-Simultan-CNC-Fräsmaschine.

Das System soll sich ideal für die Herstellung kubischer Frästeile eignen.
