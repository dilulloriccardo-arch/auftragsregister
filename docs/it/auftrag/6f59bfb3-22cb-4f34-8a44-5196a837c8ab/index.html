Motivazione della scelta

Descrizione

Ziel dieser Ausschreibung ist die Beschaffung einer Smart Metering Lösung für die Gemeindebe-
triebe Lotzwil. Im Rahmen dieses Projekts sollen gemäss den gesetzlichen Vorgaben bis Ende 2027 mindestens 80% der Stromzähler durch Smart Meter ersetzt werden. Dafür soll das bestehende, gemeindeeigene FTTH-Netz eingesetzt werden. Die nötigen Softwaresysteme wie HES und MDM sollen von der Anbieterin im SaaS-Modell betrieben werden.
