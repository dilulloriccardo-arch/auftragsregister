Descrizione

Für Fahrzeuge der PostAuto AG sollen im Rahmen des Life-Cycle-Managements neue Bildschirme als Innenanzeigen zur Visualisierung von Fahrgastinformationen und zur Visualisierung sowie zum Abspielen digitaler Werbung beschafft werden.
Die Anzeigen dienen der Darstellung von fahrgastrelevanten Informationen im Fahrzeuginnern und werden überwiegend direkt durch das PostAuto-eigene System angesteuert.

Im Rahmen der Beschaffung sind insbesondere die folgenden technischen Anforderungen von zentraler Bedeutung:
• Zertifizierte Fahrzeugtauglichkeit für den Einsatz im öffentlichen Personenverkehr
• 24‑V-Stromversorgung ohne Einsatz eines externen Netzteils
• Geringe Austauschzeiten
