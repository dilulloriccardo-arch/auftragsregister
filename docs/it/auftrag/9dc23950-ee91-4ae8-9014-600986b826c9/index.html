Descrizione

Der bestehende Gaskessel wird durch eine EWS-Wärmepumpe ersetzt,
wozu Erdsonden-Bohrungen durchgeführt werden müssen. Die Erdwärmesonden
werden ausserdem für eine Free-Cooling-Anwendung genutzt. Zudem werden
sämtliche Lüftungskomponenten jeglicher Lüftungsanlagen ersetzt.
