Descrizione

Le présent projet concerne les travaux d'assainissement du Pont de la Madelon.

Les quantités principales du projet sont les suivantes :
- BFUP coulé (sorte UA) : 35 m3
- BFUP projeté : 1.2 m3
- Asphalte coulé : 48 to
- Enrobés bitumineux : 30 to
- Armatures passives : 6'500 kg
- Armatures INOX (1.4529) de renfort à l’effort tranchant dans carottages : 66 p
- Armatures scellées : 370 p
- Terrassement : 105 m3
- Remblayage : 95 m3
- Blocs de protection type mégabloc : 36 p
