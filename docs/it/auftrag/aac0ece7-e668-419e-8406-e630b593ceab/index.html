Descrizione

Das bestehende Nachbargebäude wird über eine zentrale Cisco-WLAN-Architektur versorgt. Die IT-Infrastruktur des Neubaus wird physisch und logisch an dieses bestehende System gekoppelt. Aus Gründen der technischen Interoperabilität, des unterbrechungsfreien VoIP-Betriebs sowie zur Sicherung bestehender Investitionen muss das neue WLAN-System vollumfänglich und nativ kompatibel zur bestehenden Cisco-Infrastruktur im direkt anliegenden Gebäude sein.
