Descrizione

Zweck dieser Ausschreibung ist die Auswahl von einem Anbieter («Reseller») zum Bezug von Public Hyperscaler Cloud Services (bspw. Microsoft Azure, Amazon AWS, Google Cloud, etc.) für die Nachfolge der bestehenden Cloud-Plattform von Swissgrid. Der Bezug der Cloud Services erfolgt nach Bedarf über die Laufzeit von 5 Jahren (Rahmenvertrag).
