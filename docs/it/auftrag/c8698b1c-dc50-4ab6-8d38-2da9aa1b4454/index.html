Motivazione della scelta

Den Zuschlag erhält die Firma IWF AG, da sie die Teilnahmebedingungen, Eignungskriterien, technischen Anforderungen sowie Zuschlagskriterien erfüllt hat. Zudem handelt es sich um das einzige eingegangene Angebot.

Descrizione

Es wird eine Anbieterin gesucht, welche einen Helpdesk (First-Level) für das ZVM-Tool für das 2026 bzw. bei optionaler Verlängerung bis 2030 gewährleisten kann.
