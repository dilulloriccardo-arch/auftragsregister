Descrizione

Das neue Schulhaus besteht aus einem Untergeschoss, zwei oberirdischen Geschossen. Das komplette Untergeschoss inklusive Decke und der Gebäudekern werden in Massivbauweise erstellt. Die oberirdischen Geschosse werden als Elementbau in vorfabrizierter Holzbauweise erstellt. Die Geschossdecke über EG wird als Holz-Beton-Verbunddecke ausgebildet. Das Walmdach und der Dachboden werden als Rippenelemente ausgeführt. Das Gebäude wird mit einer hinterlüfteten Holzfassade eingekleidet.
