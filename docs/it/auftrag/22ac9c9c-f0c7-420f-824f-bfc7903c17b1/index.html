Motivazione del committente

Der Zuschlag wird an das vorteilhafteste Angebot gemäss den Zuschlagskriterien erteilt. Bewertet wurden die Kriterien Preis (Standartgeräte, Zubehör, Reparaturen) / Referenzen / Displayschutz / Support und Logistik.
