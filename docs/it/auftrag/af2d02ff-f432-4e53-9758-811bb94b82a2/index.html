Descrizione

Die Logistikbasis der Armee (LBA) ist für die Belieferung von Eistee in Portionen zugunsten der Schweizer Armee verantwortlich. Damit die LBA dieser Verantwortung gerecht werden kann, soll die Versorgung von Eistee in Portionen zugunsten des Bedürfnisträgers sichergestellt werden.
