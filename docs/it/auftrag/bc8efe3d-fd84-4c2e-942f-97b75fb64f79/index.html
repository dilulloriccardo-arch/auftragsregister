Descrizione

Dans le cadre d'une analyse de sécurité, le LEB a constaté que certains locaux techniques des installations de sécurité ne sont pas suffisamment protégés contre le risque d'incendie. Le présent appel d’offres porte sur les travaux de mise en place d’un système de détection et d’extinction incendie de type aérosol.
