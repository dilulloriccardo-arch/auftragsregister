Descrizione

Auf dem gesamten Flachdach des Schulhauses, wird eine Photovoltaikanlage mit einer Leistung von mindestens 296,52 kWp und extensiver Begrünung installiert. Die gesamte verfügbare Dachfläche ist vollständig mit Modulen zu belegen, um einen maximalen Ertrag zu gewährleisten. Die Module der Dachanlage werden mit drei separaten Wechselrichtern ausgeführt. Das volle Potenzial der verfügbaren Dachfläche soll optimal genutzt werden. Abweichungen von der ausgeschriebenen Gesamtleistung der Anlage von 296.52 kWp sind nur mit einer fundierten Begründung zulässig.
