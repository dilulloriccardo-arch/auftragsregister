Descrizione

Currently, KOMRA is implemented as a collection of calculation routines written in a single C script. The first implementation started in the early 2000s and has irregularly been expanded and modified. In its current state, the code does not conform to modern programming standards and the gradual changes over the years are difficult to retrace. This complicates its expansion and changes to its functionalities. A main drawback of the KOMRA code is that it offers only limited functionality to apply different scaling factors on waste packages assigned to the same AGT. Critical control files (e.g. to assign specific scaling factors to an AGT) are manually created and copy pasted in the program folder of KOMRA, further complicating traceability and making it error prone. Therefore, Nagra plans a complete reimplementation of the KOMRA code in Python.
