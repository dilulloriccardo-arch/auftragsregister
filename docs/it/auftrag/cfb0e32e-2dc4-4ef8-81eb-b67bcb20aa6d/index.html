Descrizione

Die Feuerwehr Stadt Luzern beschafft ein Kleineinsatzfahrzeug (KEF) für die Berufsfeuerwehr. Das Fahrzeug dient für kleine Einsätze im Feuerschutzgebiet der Stadt Luzern. Das Fahrzeug muss einen vollelektrischen Antrieb haben.
