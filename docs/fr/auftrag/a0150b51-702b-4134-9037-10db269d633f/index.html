Description

Die Instandsetzungsmassnahmen des Brückenbauwerks umfassen die Erneuerung der Abdichtung inkl. neuem Belagsaufbau auf dem Bauwerk, den Rückbau der bestehenden Fahrbahnübergänge, die Umlegung von Werkleitungen und die Beschichtungserneuerung der Stützen. Unterhalb der Brücke wird das Fahrzeugrückhaltesystem ersetzt.
