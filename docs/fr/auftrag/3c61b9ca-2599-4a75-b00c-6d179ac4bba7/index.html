Description

L’objet du projet est la gestion du patrimoine (EP) du tronçon d’autoroute entre la jonction de Wiggertal et d’Aarau Ost sur la N01.

L’objet du mandat mis en soumission sont les prestations d'ingénierie dans le domaine Passage à faune pour les phases de projet d'exécution (PA) jusqu'à la mise en service/finalisation (pendant la phase AP avec étude des variantes). La méthode BIM doit être appliquée à toutes les phases de la conception du projet.
