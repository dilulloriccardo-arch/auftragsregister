Description

Im Kaufmännischen Berufs- und Weiterbildungszentrum St.Gallen, soll die Beleuchtung erneuert werden.

Es werden die bestehenden Leuchten mit LED-Umrüstsätzen ausgerüstet für:
- 78 Stück 2-flammige 36W Pendelleuchten direkt/indirekt
- 674 Stück 2-flammige 58W Pendelleuchten direkt/indirekt
- 42 Stück 2-lammige 36W Aufbauleuchten direkt
- 96 Stück 2-flammige 58W Aufbauleuchten direkt
- 83 Stück 1-flammige 36W Einbauleuchten

Der Einbau von den Umrüstsätzen-LED erfolgt bauseitig durch den Elektroinstallateur.
