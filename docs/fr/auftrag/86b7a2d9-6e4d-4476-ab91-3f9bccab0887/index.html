Description

Le système APFZ installé dans les véhicules prend en charge des tâches importantes telles que l’information aux voyageurs. Ce système doit être modernisé. La plateforme de communication actuelle est en effet obsolète, alors même que les réseaux mobiles ne cessent de se développer.
Il est donc prévu d’acquérir une nouvelle plateforme de calcul et de communication pour les véhicules sur rails. Cette plateforme aura pour objectif d’assurer la liaison de données entre le véhicule et les systèmes à terre, de garantir la communication avec la commande du véhicule et de fournir une puissance de calcul suffisante pour les applications embarquées. Est recherchée une solution compacte et robuste sans ventilateurs, adaptée à l’exploitation ferroviaire. Cette plateforme devra être dotée d’une technologie 5G moderne, des interfaces requises ainsi que d’un concept de produit et de support disponible dans la durée.
