Description

Mit der vorliegenden Ausschreibung sollen qualifizierte Full-Service Web-und Digital-Agenturen evaluiert werden, welche Schweiz Tourismus fortlaufend bei der Umsetzung und Weiterentwicklung von Web-Projekten aller Art unterstützen. Hierzu beabsichtigt Schweiz Tourismus den Abschluss eines Dienstleistungsrahmenvertrags, um einen «Dienstleister-Pool» zu etablieren. Von den Rahmenvertragspartnerinnen erwartet ST die Erbringung von Dienstleistungen auf Abrufbasis (Mini-Tender). Weiterführende Details sind im Lastenheft ersichtlich.
