Motifs du choix

Den Zuschlag erhält die Firma Liip AG. Ihr Angebot überzeugte mit einer insgesamt sehr guten Erfüllung der Qualitätskriterien (ZK 02 und ZK 03); das ZK 03 hat sie vollumfänglich erfüllt. Auch hat sie das preislich tiefste gültige Angebot eingereicht. Bei der Beurteilung der Zuschlagskriterien erzielte ihr Angebot daher insgesamt die höchste Punktzahl. Ihre Offerte ist somit in ihrer Gesamtheit die Vorteilhafteste.

Description

Le présent appel d'offres porte sur l'acquisition d'une application permettant une gestion efficace des processus, y compris les prestations de service correspondantes (maintenance et entretien, développement, etc.). Pour ce faire, une application sera acquise, dans laquelle les événements déclarés au SESE seront enregistrés et traités. La gestion du projet ouvre des enquêtes sur les incidents survenus dans l'application. De même, les recommandations et les avis de sécurité sont gérés dans l'application. En outre, les finances sont traitées et les données de base sont gérées dans l'application. L'application sert de base aux rapports statistiques et soutient la direction dans la gestion du SESE.
