Description

Verlegen von Vinylbodenbelag 4200m² Vorbereiten der Böden, Entfernen von Kleberesten oder Teppichboden, Untergrund vorbereiten und gewünschten Boden (Vinylplatten) verlegen. Es kommen 2 verschiedene Masse zur Anwendung, in den Zimmern anders als im Korridor. Abschlussarbeiten und Sockel geschraubt. Arbeiten müssen bis August fertiggestellt sein.
