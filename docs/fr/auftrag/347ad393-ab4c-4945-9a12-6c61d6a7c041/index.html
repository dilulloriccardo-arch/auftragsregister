Description

Die Biogas Zürich AG (BGZAG) betreibt am Standort Zürich-Werdhölzli ein Vergärwerk mit einer Jahreskapazität von bis zu 35‘000 Tonnen Inputmaterial (biogene Abfälle), bestehend aus Bioabfall (= pflanzlicher Gartenabfall + biogener Küchenabfall), Gartenabraum, gewerblichen Speiseresten sowie sonstigen biogenen Abfällen. Bei der Verwertung der biogenen Abfälle im Vergärwerk fallen nebst Biogas und festem Gärgut (Kompost) auch flüssiges Gärgut an. Erstgenanntes dient zur Düngung resp. Pflanzenernährung auf landwirtschaftlich genutzten Flächen. Das Gärgut fest soll vom Anbieter, bzw. von der Anbieterin zu geeigneten Landwirtschaftsbetrieben transportiert und auf deren Nutzflächen fachgerecht verteilt werden.
