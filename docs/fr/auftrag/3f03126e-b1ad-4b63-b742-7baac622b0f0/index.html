Description

Le marché porte sur la préparation et la livraison de repas destinés aux structures d'accueil de jour du primaire de Bâle-Ville pendant 38 semaines scolaires pour les années scolaires 2027/2028 et 2028/2029. Pour les sites proposant un accueil pendant les vacances, la livraison de repas chauds doit avoir lieu toute l'année (c'est-à-dire également pendant onze semaines de vacances au maximum). Les repas sont livrés chauds. Le contrat-cadre peut être prolongé une seule fois d’un an, à titre facultatif.

Publication officielle : Voir le projet 43664 sur simap.ch — seule la publication qui y figure fait foi.
