Prestations RH, projet 5171

Description

Par le présent appel d’offres, l’adjudicateur recherche plusieurs soumissionnaires pour des prestations RH. Les prestations RH comprennent les Assessment & Development Centers , le feed-back à 360°, le conseil général en RH et le conseil orienté vers le développement de l’organisation. En outre, les formations Résilience dans la surveillance ainsi que les entraînements à la conduite d’entretiens dans le contexte des établissements assujettis font partie des prestations RH.
