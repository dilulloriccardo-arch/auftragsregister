Description

Mit der vorliegenden Ausschreibung soll ein Lieferant für ein modernes mobiles Augenmikroskop ermittelt werden. Das Anwendungsspektrum der zu liefernden Systeme umfasst die folgenden Bereiche: Intraokulare, komplexe Augenchirurgie (Kataraktchirurgie mit Softwaresystem zur Achsenmarkierung, Hornhaut und Netzhautchirurgie, potentiell mit der Möglichkeit für ein intraoperatives OCT, Glaukomchirurgie). Ausserdem ist angedacht, optional ein zweites Mikroskop neu oder Occasion zu beschaffen, wenn sich entsprechender Bedarf ergibt. Es werden die nachfolgend aufgelisteten Leistungsgegenstände beschafft: • Ein (1) mobiles Operationsmikroskop • Optional: - ein weiteres mobiles Operationsmikroskop - ein Occasionsgerät mit Vollgarantie
