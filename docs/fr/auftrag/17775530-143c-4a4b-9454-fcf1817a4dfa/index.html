Description

Das Projekt «2K5» ist die Erweiterung der Kehrichtverwertungsanlage Hagenholz in Zürich um eine dritte Verbrennungslinie (Details dazu siehe Teil B «Projektbeschrieb»).

Die ausgeschriebenen Leistungen sind in folgende Leistungsverzeichnisse (LV) gegliedert:
- BKP 213.81 NPK 111 und 113
- BKP 213.82 VG-2K5
- BKP 213.83 RGR-2K5
- BKP 213.84 KBUS
- BKP 213.85 EHS
- BKP 213.86 Diverse Stahlbauten

Weitere Informationen finden Sie in den Ausschreibungsunterlagen.
