Description

Das Projekt "Umgestaltung Rheinstrasse" beinhaltet die Realisierung einer rund 1050m langen Strasse für Fussgänger und Radfahrer mit einem Grünstreifen zur Trennung der beiden Fahrbahnen. Ebenfalls sind für verschiedene Werkeigentümer neue Leitungen und Rohrblöcke zu verlegen.
