Description

Bestandteil des Mandats sind im Wesentlichen die Realisierung der Schutzgalerie, der Strassenabschnitte nördlich und südlich der Galerie inklusive den zugehörigen berg- und talseitigen Kunstbauwerken.

- Schutzgalerie, mit einer Länge von 127 m. Diese wird als Tagbautunnel mit einer Rahmenkonstrukion aus Ortsbeton konzipiert.

- Strassenstück Süd, mit einer Länge von ca. 187 m. Folgende Bauten sind auf diesem Abschnitt vorgesehen: talseitige Stützmauern (LTotal = 95 m), bergseitige Stützmauern (L = 132 m), sowie einem Lehnenviadukt (L = 60 m).

- Strassenstück Nord, mit einer Länge von ca. 159 m. Folgende Bauten sind auf diesem Abschnitt vorgesehen: talseitigen Stützmauern (LTotal = 56 m), bergseitigen Stützmauern (L = 195 m).
