Description

Conception technique, fabrication et installation d'une infrastructure à ultra-haut vide (UHV) reliant plusieurs installations expérimentales pour le dépôt de couches minces et les caractérisations in situ. La plateforme expérimentale complète est appelée Materials Innovation Cluster (MIC) à l'Institut Paul Scherrer, Suisse. Pour plus de détails, voir la spécification PSI-PD37-001 Rev.1.0.
