Description

Die für die Zeit vom 01.08.2025 bis zum 01.08.2029 notwendigen Wartungsarbeiten der Spiralförderer einschliesslich der Lieferung von Ersatzteilen, in Verbindung mit einem Bereitschaftsdienst für den Einsatz im Störfall und Instandsetzungsarbeiten bilden das vom/von der Anbieter/in zu erbringende Leistungspaket.
