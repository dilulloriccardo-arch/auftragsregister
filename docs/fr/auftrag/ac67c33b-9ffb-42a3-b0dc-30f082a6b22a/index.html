Description

Im Gebäude der St.Galler Kantonalbank an der Signalstrasse in Rorschach entsteht eine neue Quartierzentrale der Technischen Betriebe Rorschach. Dafür werden drei Technikräume mit einem Dienstbarkeitsvertrag zur Verfügung gestellt. Es wird eine neue Propan-Wärmepumpe eingebaut. Der jetzige Heizkessel, der die unmittelbaren Gebäude mit Wärme versorgt, wird von den Technischen Betrieben Rorschach übernommen. So können Spitzenlasten abgedeckt und Redundanz gewährleistet werden. Ziel dieses Bauvorhabens ist es, den Einsatz fossiler Energieträger so weit wie möglich zu reduzieren und einen Schritt in Richtung Dekarbonisierung zu gehen. Die Wärmepumpe wird zukunftsgerichtet mit einem natürlichen Kältemittel (Propan) betrieben, das einen niedrigen GWP-Wert aufweist. Aus diesem Grund sind zusätzliche Sicherheitsmassnahmen notwendig. (Die Wärmepumpe ist nicht bestandteil dieser Ausschreibung).
