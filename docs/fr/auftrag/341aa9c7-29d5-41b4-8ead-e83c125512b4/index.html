Motivation de l'adjudicateur

Der Zuschlag erhielt das insgesamt wirtschaftlich vorteilhafteste Angebot auf Basis der in der Ausschreibung festgelegten Zuschlagskriterien. Das Angebot der Zuschlagsempfängerin zeichnet sich insbesondere durch die Kriterien Angebotspreis, Qualität, Leistungsfähigkeit und Referenzen aus.

Description

Die bestehende Gasheizung wird ersetzt durch eine Wärmpumpenanlage. Neu wird die Schulanlage mit einer Wasser-/Wasser-Wärmepumpe mit Heizenergie versorgt. Wärmequelle Anergie der EZL. Die Frischwasserstationen und der Pufferspeicher bleiben bestehend. Der Elektroschaltschrank wird wieder verwendet.
