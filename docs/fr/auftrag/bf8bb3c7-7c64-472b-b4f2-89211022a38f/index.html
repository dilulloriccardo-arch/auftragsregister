Description

Im Rahmen der Arbeiten der UPlaNS Vennes-Chexbres plant das ASTRA die Installation von Durchflussmesssystemen. Dieses Los sieht die Einrichtung von drei Rampenregelungen für die Anschlussstellen Chexbres, La Croix und Vennes der N09 vor und umfasst die Lieferung, Installation und Inbetriebnahme folgender Ausrüstung: - Verkehrsmanagementsystem (LS-Dosage, AS-Dosage) - Wechselverkehrszeichen - Feste Beschilderung - Dynamische Beschilderung - Lichtsignalanlagen - Energieversorgung (Verkabelung, Erdung, Feldschaltkasten für die Dosierungssignalisierung, Umbau bestehender Schaltkästen) - Rundmasten Das vorliegende Los umfasst zudem den mehrstufigen Abbau bestimmter bestehender fester Beschilderungselemente an allen Dosierungsanlagen.
