Étendue des prestations de gestion de projet / assistance au maître d’ouvrage (PM / BHU) Description des modules de prestations partielles dans le DOC B, chapitre 5 Les modules de prestations partielles ne peuvent pas être rattachés explicitement aux phases de projet SIA. Module de prestations partielles 1 : PM / BHU – Appel d’offres (SIA 41) Module de prestations partielles 2 : PM / BHU – Réalisation (SIA 51–53) Module de prestations partielles 3 : Soutien à la direction générale des travaux (OBL) (SIA 41–53) Module de prestations partielles 4 : Contrôle des contrats / gestion des avenants (SIA 41–53) Module de prestations partielles 5 : Direction générale des travaux (OBL) (SIA 41–53) Tous les modules doivent faire l’objet d’une offre séparée.
