Description

L’objet du marché consiste en une offre, d’une validité de 9 mois, pour l’acquisition d’un chargeur télescopique diesel. Le véhicule aura pour tâches de charger des matériaux et les déposer dans des camions. Il sera fourni avec les 3 agrégats demandés dans les documents d’appel d’offres. Le véhicule ne nécessite pas d’immatriculation pour rouler sur la voie public. Il sera uniquement utilisé dans l’enceinte de VADEC.
Spécifications techniques éliminatoires :
- Fournir un chargeur télescopique
- La hauteur hors tout est de maximum 2'550 mm (cabine en position repliée).
- Fournir une motorisation diesel.
- La charge de levage maximale est de minimum 3'500 kg.
- Fournir un graissage centralisé automatique du châssis
- Les côtés du châssis du véhicule sont fermés afin d’éviter la pénétration de matériaux dans le véhicule.
- Le véhicule est équipé de 4 roues directrices.
- Le véhicule n’est pas articulé.
- Fournir une cabine télescopique.
- Toutes les vitres de la cabine sont blindées.
- Le véhicule est équipé de pneus pleins.
- Le véhicule est équipé d’une balance permettant le pesage des godets lors des chargements.
- Le véhicule est adapté au climat et à la région de Colombier ainsi qu’au bâtiment où il sera stocké.
- Les spécifications techniques avec la mention « éliminatoire » dans l’Annexe C sont toutes acceptées.
