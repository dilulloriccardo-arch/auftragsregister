Description

Die AEW Energie AG wird den Hauptsitz im Frühjahr 2027 in die Bahnhofstrasse verlegen. Sie bezieht ein bestehendes Gebäude im Stadtzentrum. Vor dem Bezug ist ein Mieterausbau notwendig. Unter anderen Gewerken muss die Elektroinstallation erneuert und ersetzt werden. Dafür wird ein geeignetes Unternehmen gesucht.

Der Baustart ist für Anfang Januar 2027 vorgesehen, die Fertigstellung für April 2027.
