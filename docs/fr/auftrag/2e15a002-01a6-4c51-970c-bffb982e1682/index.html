Motifs du choix

Die Zuschlagsempfängerin hat beim Kriterium Preis mit knappem Rückstand die zweit höchste Punktzahl erreicht. Beim Kriterium Lehrlingsausbildung hat die Zuschlagsempfängerin die maximale Punktzahl erreicht während die beiden anderen Anbieterinnen bei diesem Kriterium jeweils null Punkte erhalten haben. Beim Kriterium Qualität des angebotenen Produktes hat die Zuschlagsempfängerin 297.90 von maximal möglichen 300 Punkten erreicht. Der Vorsprung auf die zweit- und drittplatzierte Anbieterin beträgt bei diesem Kriterium 12.15 respektive 101.70 Punkte. In der Gesamtauswertung hat die Zuschlagsempfängerin mit einem Vorsprung von 136.27 respektive 171.55 Punkte eine Punktzahl von 967.75 Punkten erreicht (maximale mögliche Gesamtpunktzahl = 1000 Punkte). Die Firma Hager AG hat somit das vorteilhafteste Angebot eingereicht, welches den Zuschlag erhält. (Art. 41 IVÖB 2019)

Description

Mit vorliegender Submission wird die Lieferung von Hausanschluss-Kasten 160A für die Stromversorgung ausgeschrieben.
