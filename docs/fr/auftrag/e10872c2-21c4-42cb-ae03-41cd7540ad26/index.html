Description

Für das Industriezentrum Klybeck sind Sofortmassnahmen zur Dachsicherheit erforderlich. Die BVB beschafft hierfür die notwendigen Leistungen im Bereich der Dachsicherheit. Zu diesem Zweck wird die BVB mit der Zuschlagsempfängerin einen KBOB-Werkliefervertrag abschliessen.
