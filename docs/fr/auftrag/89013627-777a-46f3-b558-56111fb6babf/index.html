Description

In der Sulzerallee werden die Bushaltestellen Im Link und Industriepark neu erstellt. Stadteinwärts werden zwei Wartehallen realisiert. Im Haltestellenbereich werden die best. Beläge abgebrochen und durch Betonplatten ersetzt. Zusätzlich werden insgesamt vier Mittelschutzinseln erstellt. Stadtwerk passt die Lage der Kandelaber an.
