Description

Die vorliegende Ausschreibung umfasst die Plattenarbeiten im Aussenbereich für das bestehende Wellenbecken, inkl. der Abdichtungsarbeiten für das komplette Becken. Zusätzlich get es um die Plattenarbeiten bei der Sockelausbildungen beim Übergang Flachdach an Aussenbrüstungen.
