Motifs du choix

Unter Berücksichtigung der in den Ausschreibungsunterlagen festgelegten Zuschlagskriterien erweist sich das Angebot der Firma Brack AG, Hintermättlistrasse 3, 5506, Mägenwil als das vorteilhafteste Angebot. Die Bedingungen gemäss Ausschreibungsunterlagen werden beim berücksichtigten Angebot vollumfänglich erfüllt.

Description

Im Zuge des Erweiterungsbaus H2/Q des KSGR werden zusätzliche Arbeitsplätze benötigt und entsprechend ausgestattet. Um diese neuen Arbeitsplätze bereitzustellen, werden die folgenden ThinClients benötigt.

- Hersteller: Hewlett Packard
- Modell: HP ProDesk 5 G1i ThinClient 16GB
- Memory: 16GB (1x16GB) DDR5 5600 SODIMM Memory
- Festplatte: 256GB 2280 PCIe NVMe Value Solid State Drive
- Betriebssystem: OS LOCALIZATION HP - PSG TOP CONFIG
- Netzteil: HP 65W Gallium Nitride 4.5mm nPFC Smart (3-pin) AC
- Kabel: C5 Conventional 1.0m Sticker Power Cord
- Zusatz Lizenzen: Igel OS 12 Lizenz

Die Ausschreibung umfasst die Beschaffung von 680 ThinClient der obigen Konfiguration. Die Lieferung muss in abgestimmten Tranchen nach Vorgaben des KSGR erfolgen, da die Installation im neuen Gebäude in verschiedenen Etappen erfolgen wird. Die erste Etappe startet Anfangs September 2026.

Es ist zu beachten, dass in der Ausschreibung ausschliesslich der Beschaffung und termingerechte Lieferung der im Dokument "Zuschlagskriterien" aufgeführten Hardware Komponenten ausgeschrieben werden. Die Installation und Inbetriebnahme dieser sind NICHT Teil dieser Ausschreibung.
