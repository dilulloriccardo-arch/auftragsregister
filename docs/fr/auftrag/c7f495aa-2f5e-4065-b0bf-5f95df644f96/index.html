Description

Der Ersatz der alten Eternitleitung DN150 sowie der Bau einer neuen Einspeiseleitung in der Zone Oberalmet. Zusätzliche muss eine neue Signalkabelverbindung zwischen dem Reservoir Oberalmet und Reservoir Gstein sowie ein Kabelschutzrohr für die Stromversorgung erstellt werden. Den genauen Baubeschrieb finden Sie unter "B_Projektbezogenen Bestimmungen".
