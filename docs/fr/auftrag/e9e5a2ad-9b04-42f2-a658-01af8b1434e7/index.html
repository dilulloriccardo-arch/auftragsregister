Description

Des projets de maintenance sont élaborés pour les tronçons de projet Egga et Gabi sur le versant sud du Simplon. Afin de pouvoir formuler de manière fiable une recommandation de variante à retenir lors des phases EK/MK, il convient de se procurer des informations détaillées sur les objets situés le long des tronçons.

Le présent marché comprend les travaux spécifiques à l'ouvrage et aux matériaux de construction pour l'acquisition des données de base. Un contrat est établi par tronçon de projet.
