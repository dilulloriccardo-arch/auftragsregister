Description

Erstellung von Werkleitungen ab dem Neubau haus O bis Spitalstrasse für die Medien Entwässerung (Schmutzwasser, Regenwasser), Fernwärmeleitungen, Hydrantenleitung, Kabelschutzrohranlagen. Ausführung in Etappen, Aufrechterhaltung der Zufahrt zur Baustelle Haus O und Studenweg, Berücksichtigung der Fussgänger intern Spital sowie öffentliche Fussgänger inkl. Schulweg.
