Description

Die vorliegende Ausschreibung umfasst die Arbeiten für die Sanierung und Umgestaltung der Allmendstrasse Ost inkl. Werkleitungsarbeiten (Strassenentwässerung, Kanalisation, Strom, Fernwärme), Neubau Strasse, Entsiegelung Parkplätze und Erstellung von Schwammstadtelementen im Strassenraum.
