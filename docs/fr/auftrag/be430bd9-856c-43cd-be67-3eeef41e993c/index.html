Description

Traduction de 20 000 lignes standard par an. Pour tous les lots, les langues sources peuvent être l'allemand ou le français. La langue cible est toujours l'anglais. Un soumissionnaire doit être en mesure de couvrir au moins le volume d'un lot avec ses capacités. Il peut postuler pour plusieurs lots. Les offres partielles inférieures à un lot ne sont pas acceptées. Il n'y a pas de garantie d'acceptation.
