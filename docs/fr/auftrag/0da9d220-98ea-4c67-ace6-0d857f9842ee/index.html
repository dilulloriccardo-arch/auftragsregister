Description

Die Energie Thun AG baut im Jahr 2026 ihr Fernwärmenetz um ca. 315m aus. Parallel werden im selben Perimeter auf 288m die Trinkwasser und auf 259m die Stromleitungen ersetzt. Punktuell werden an der Oberfläche Belagsflächen instand gestellt. Die Arbeiten haben innerstädtischen Charakter und finden teilweise in beengten Platzverhältnissen statt. Es wird von einer Bauzeit von ca. 8 Monaten auf Basis einer Arbeitsgruppe ausgegangen. Elektrorohrblock inkl. Hauszuleitungen ca. 259 Meter Trinkwasserleitung inkl.
