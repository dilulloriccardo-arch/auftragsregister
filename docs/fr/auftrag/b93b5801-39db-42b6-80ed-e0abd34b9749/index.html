Description

Mit dem offenen Verfahren im vom Staatsvertrag erfassten Bereich sucht die Stadt St.Gallen für ihre Schulen das vorteilhafteste Angebot für neue Smartdisplays. Gegenstand der vorliegenden Ausschreibung ist die Lieferung von Smartdisplays und passiven Displays der Firma SMART Technologies ULC sowie die damit verbundene Erbringung der Installations- sowie Wartungsleistungen.
