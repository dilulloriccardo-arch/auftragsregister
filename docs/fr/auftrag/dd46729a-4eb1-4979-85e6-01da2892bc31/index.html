Description

Les objectifs sont de poursuivre la réalisation de l’entretien et de l'assainissement des installations BSA en lien avec l’UPlaNS N16 Tavannes – Bözingenfeld, Tronçon TP2 (Secteur Bienne Nord – La Heutte) - Lot 202 - BSA principal. Les principales prestations du présent lot comprennent les installations suivantes : • D1 - Energie • D2 - Eclairage • D5 - Installations divers • D7 - Câblage • D8 - Installation auxiliaire
