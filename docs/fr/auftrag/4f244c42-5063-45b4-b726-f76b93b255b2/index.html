Description

Die Dienstabteilung «Immobilien Stadt Zürich» (nachfolgend IMMO genannt) bewirtschaftet Liegenschaften und mobile Vermögenswerte der Stadt Zürich. Sie stellt deren Werterhaltung, Gebrauchstauglichkeit und Nutzwert sicher, abgestimmt mit den übergeordneten Interessen der Stadt Zürich. Das Portfolio umfasst rund 1'800 Liegenschaften, die mehrheitlich über das ganze Stadt-
gebiet verteilt sind.

Im Gesundheitszentrum für das Alter Selnau an der Selnaustrasse 16, 8001 Zürich, soll im 2025
die bestehende fossile Wärmeerzeugung durch ein umweltfreundliches System abgelöst werden.

Hierfür soll auf dem Grundstück eine Luft-/Wasser-Wärmepumpen installiert und die erzeugte
Heizenergie dem bestehenden Verbrauchernetz zugeführt werden.

Ebenfalls soll im Rahmen dieser Sanierung ein Armaturen- und Regelungsersatz erfolgen, damit
die Betriebssicherheit für die nächsten Jahre gewährleistet werden kann. Das Gesundheitszent-
rum Selnau soll hundertprozentig mit erneuerbarer Energie beheizt werden.
