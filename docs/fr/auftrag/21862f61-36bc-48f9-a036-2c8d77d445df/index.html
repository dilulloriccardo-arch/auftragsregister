Description

Gestion sécurité trafic travaux de nuit. Le présent marché de service concerne la mise à disposition d’agents de sécurités de nuit dans le cadre des travaux autoroutier du projet Vennes-Chexbres ainsi que la mise à disposition d’un agent superviseur pour encadrer l’ensemble des travaux de nuit.
