Description

Im Rahmen einer Dienstleistung soll für die zugehörigen Fahrwerke (Drehgestell) der Anhänger Typ B4S und der Motorwagen Be4/4 die gesetzlich vorgeschriebene Revision durchgeführt werden.

Ziel der Revision ist, dass die Fahrwerke für weitere 5 Jahre im Fahrgastbetrieb mit einer durchschnittlichen Laufleistung von 30’000 km pro Jahr ohne weitere Revisionen betrieben werden können.
