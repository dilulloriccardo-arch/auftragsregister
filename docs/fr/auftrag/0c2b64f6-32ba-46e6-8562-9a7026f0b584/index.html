Description

In der Schulanlage «Schulhaus Egg, Frenkendorf» wird die bestehende Beleuchtungsanlage durch moderne LED-Leuchten ersetzt, welche mittels intelligenter Einzelraum-Lichtsteuerung das vorhandene Tageslicht optimal nutzen und damit zusätzlich eine markante Energieeinsparung erzielen. Da es sich um ein Schulhaus im Betrieb handelt, müssen vier Umbauetappen geplante werden, welche jeweils während den Schulferien umgesetzt werden. Ausnahmsweise und nur in Absprache mit dem Bauherrn, können Nebenräume an schulfreien Mittwoch- und Donnerstagnachmittagen auch unter dem Jahr umgerüstet werden.
