Description

Bau einer Quartierzentrale für die Wärmeerzeugung und Wärmeverteilung an zwei örtliche Wärmenetze Nord und West. Der Bau der Quartierzentrale beinhaltet ein neuer Zweistoff Öl/Gas Heizkessel (700 kW) inkl. neuem Kaminzug, Speicheranlage inkl. Gruppenaufbauten für interne und externe (Wärmenetze Nord und West) Wärmeverteilung, Interne Brauchwarmwasseraubereitung, Gaszuleitung erneuern, Lüftungsanlagen, Anpassungen an Sanitären Installationen, Energiezulieferung in Chromstahl für eine Wärmepumpenanlage (Wärmepumpe separater Auftrag), Druckhaltestation des Anergienetzes etc.
