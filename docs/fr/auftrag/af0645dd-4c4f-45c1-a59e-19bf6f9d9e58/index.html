Motivation de l'adjudicateur

Die Zuschlagsempfängerin hat unter Berücksichtigung sämtlicher Zuschlagskriterien die höchste Punktzahl erreicht. Die Firma Kern Strassenbau AG hat somit das vorteilhafteste Angebot eingereicht, welches den Zuschlag erhält. (Art. 41 IVÖB 2019)
