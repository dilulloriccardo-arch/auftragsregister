Motivation de l'adjudicateur

Das berücksichtigte Angebot hat aufgrund seiner Merkmale und Vorteile die meisten Nutzwertpunkte (NWP) erzielt. Die Zuschlagskriterien (ZK) wurden wie folgt bewertet: ZK 1 Preis: 102.55 von 150 NWP ZK 2 Auftragsanalyse: 200 von 200 NWP ZK 3 Referenzauftrag Anbieter: 150 von 150 NWP Total: 452.55 von 500 NWP Die Anbietenden können sich unabhängig von einer allfälligen Beschwerde für ein informelles Debriefing bei der Kantonalen Fachstelle für öffentliche Beschaffungen melden.

Description

Die Bestandsliegenschaften der Sanität Basel wird entkernt und vollumfänglich saniert und umgebaut. Die Liegenschaft wird für die Zeit der Umbauarbeiten leergezogen. Lieferung und Komplettmontage einer Indach-PV-Anlage auf einem Satteldach.
