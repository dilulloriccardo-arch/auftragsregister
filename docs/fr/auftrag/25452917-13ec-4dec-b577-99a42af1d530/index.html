Description

Die bestehende Quellableitung Teppenriedli - Ribi soll durch eine neue erdverlegte Druckleitung DN 200mm ersetzt werden. Die Druckleitung aus Duktilguss wird mit formschlüssigen, hochbelastbaren Steckmuffen-Verbindung erstellt und das hydroelektrische Potential zur Stromproduktion im Trinkwasserkraftwerk Ribi genutzt. Vorliegend gelangen die Baumeister- und Rohrleitungsbauarbeiten zur Ausschreibung. Das Baulos erstreckt sich über eine Höhendifferenz von knapp 400 Höhenmeter bei einer Leitungslänge von weniger als 700 m.
