Description

Leistungsumfang
Der Gesamtaufwand für 2027 und 2028 wird auf 11'400 Stunden geschätzt. Im Jahr 2027 wird teilweise mit mindestes vier Temporärstellen gerechnet, im Jahr 2028 mit mindestens zwei Temporärstellen. Es besteht jedoch kein Anspruch auf eine garantierte Stundenzahl.

Qualifikation / Ausbildung
-Abgeschlossene Berufslehre EFZ, Ideal im Bereich Elektro, Logistik oder Gastronomie
-Gültiger Führerausweis Kategorie B

Aufgabenbeschreibung
-effiziente, termin-/fachgerechte und kundenorientierte Verbrauchsdatenerfassung der verschiedenen Medien für die Versorgungsunternehmen
-korrekte Verbrauchsdatenerfassung bei den einzelnen Kundenanlagen
-Sicherstellen einer hohen Kundenzufriedenheit durch zuvorkommendes Verhalten bei der Verbrauchsdatenerfassung
