Motifs du choix

Unter Berücksichtigung der in den Ausschreibungsunterlagen festgelegten Zuschlagskriterien erweist sich das Angebot der Firma STRABAG AG, Unterrohrstrasse 5, 8952 Schlieren als das vorteilhafteste Angebot.

Description

Die ausgeschriebenen Leistungen beinhalten die Baumeisterarbeiten für das Anbohren des Kanalnetzes und Anschliessen von privaten Abwasserleitungen an das Kanalnetz der Stadt Zürich.

Das kalkulatorische Gesamtvolumen für die ausgeschriebenen Leistungen liegt jährlich voraussichtlich bei ca. 300 Anschlüssen. Abhängig von den durchgeführten Bauvorhaben kann das Gesamtvolumen variieren und ist daher nicht verbindlich.
