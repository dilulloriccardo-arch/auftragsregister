Description

Die Bauherren wollen im Abschnitt Brühlweg - Martinsweg in Zofingen den Fuss- und Radweg ausbauen, in diesem Zusammenhang die bestehende Fussverkehrbrücke über die Henzmannstrasse ersetzen, die Henzmannstrasse dem Temporegime anpassen, die Florastrasse umgestalten und die Werkleitungen und Strassenbeleuchtungen sanieren.
