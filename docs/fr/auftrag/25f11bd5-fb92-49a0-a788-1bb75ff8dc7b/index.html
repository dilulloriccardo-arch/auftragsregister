Motivation de l'adjudicateur

Das berücksichtigte Angebot hat aufgrund seiner Merkmale und Vorteile die meisten Nutzwertpunkte (NWP) erzielt. Die Zuschlagskriterien (ZK) wurden wie folgt bewertet: ZK 1.1 Preis Grundauftrag: 90 von 90 NWP ZK 1.2 Preis Optionen: 60 von 60 NWP ZK 2 Technische Lösung: 155 von 175 NWP ZK 3 Integration: 32 von 50 NWP ZK 4 Betrieb: 40 von 50 NWP ZK 5 Umsetzungsanforderungen: 30 von 50 NWP ZK 6 Angebotspräsentation: 21.25 von 30 NWP Total: 428.25 von 500 NWP Die Anbietenden können sich unabhängig von einer allfälligen Beschwerde für ein informelles Debriefing über kfoeb@bs.ch bei der Kantonalen Fachstelle für öffentliche Beschaffungen melden.

Description

Das Ziel des Projekts INFRA21+ / Remote Access / ZTNA ist, die bisherige VPN-basierte Remote Access Infrastruktur sowie den Secure Web Gateway durch eine zukunftsfähige, hochsichere und flexible Zero Trust Network Access (ZTNA)-Lösung abzulösen. Diese Lösung soll die Anforderungen der modernen Arbeitswelt abdecken, indem sie sichere und ortsunabhängige Zugänge zu den IT-Diensten und -Systemen ermöglicht. Mit der vorliegenden Ausschreibung wird somit eine geeignete Leistungserbringerin evaluiert, welche die Lösung im Detail und in enger Zusammenarbeit mit den Fachspezialisten von IT-BS konzipiert, alle notwendigen Komponenten liefert, installiert, konfiguriert und in Betrieb setzt sowie den anschliessenden Betrieb über die Vertragslaufzeit sicherstellt.
