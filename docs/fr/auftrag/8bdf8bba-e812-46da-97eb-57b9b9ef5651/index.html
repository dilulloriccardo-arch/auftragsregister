Description

EBL (Genossenschaft Elektra Baselland), das Elektrizitätsversorgungsunternehmen im Kanton Basel-Landschaft, benötigt eine mobile Infrastruktur für den Betrieb des Netzes, das für die Versorgungssicherheit unserer Kunden von entscheidender Bedeutung ist. Der Projektumfang umfasst das Engineering, Konstruktion, Herstellung, Montage und IBN eines Containers mit gasisolierten Schaltanlagen (GIS). Geliefert werden zudem leeren Seecontainer für Mittespannungsschaltanlage, Batterien, Netz- und Schutzkontrolle und EB. Die Schnittstellen zu anderen Containern müssen berücksichtigt und geplant werden, dazu gehören Sekundärtechnik, Mittel- Spannungsschaltanlagen, Transformatoren, USV, usw..
