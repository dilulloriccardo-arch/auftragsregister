Description

Sul mappale 477 RFD di Manno, AET intende costruire una nuova sottostazione 150/50 kV. La nuova sottostazione viene inserita nella parte a verde lato nordest del mappale 477 RFD. Il corpo principale della sottostazione è costituito da: 1. un edificio di 3 piani in calcestruzzo armato di cui uno interrato; 2. un cunicolo interrato in calcestruzzo armato in corrispondenza del lato posteriore dell’edificio; 3. una vasca di recupero oli per trafo 50/16 kV in calcestruzzo armato interrata; 4. una vasca di recupero oli per trafo 150/50 kV in calcestruzzo armato interrata.
