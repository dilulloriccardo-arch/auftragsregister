Description

Die ausgeschriebene Leistung besteht aus der Lieferung von Glasfaserkabel mit 144 Fasern für den Aussenbereich gemäss technischem Pflichtenheft und Technischen Spezifikationen (Dokumente B1 / A2b). Der voraussichtliche Jahresbedarf (bezogen auf das Geschäftsjahr der Auftraggeberin vom 1. Oktober bis 30. September) beträgt rund 150'000 m. Die erfolgreiche Anbieterin hat jedoch keinen Anspruch auf eine bestimmte Mindestbestellmenge. Die Glasfaserkabel werden auf Stahlbobinen à 6000 m abgerufen. Für die Grobplanung der ungefähr benötigten Mengen führt EKZ einen unverbindlichen Forecast, welche mit der erfolgreichen Anbieterin geteilt wird. Der Vertrag wird über eine feste Dauer von drei Jahren abgeschlossen. Der Auftraggeberin steht eine einseitig ausübbare Option auf Verlängerung des Vertrages um maximal zwei weitere Jahre zu.
