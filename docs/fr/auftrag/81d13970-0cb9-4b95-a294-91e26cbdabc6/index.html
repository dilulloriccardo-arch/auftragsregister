Description

Lot 1

Lot 1 : Prestation de restauration scolaire pour deux écoles, l’école de Confignon et l’école de Cressy

Le lot 1 comprend une tranche optionnelle prévoyant l’organisation d’activités parascolaires
ponctuelles sous forme d’ateliers de cuisine pour les enfants en après-midi.

Le nombre de repas prévus pour le lot 1 est d’environ 43'680 repas annuels (à savoir 260 repas pour
les élèves et 20 repas pour les adultes par jour x 4 jours par semaine x 39 semaines par an = 43’680
repas).

Lot 2

Lot 2 : Prestation de restauration préscolaire pour deux crèches : La crèche de Confignon et la crèche de Aire-la-Ville.

Le nombre de repas prévus pour le lot 2 est d’environ 28'060 repas annuels (à savoir 108
repas/goûters par jour pour les enfants et 14 repas pour les adultes x 5 jours par semaine x 46
semaines par an = 28’060 repas).
