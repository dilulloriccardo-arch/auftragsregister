Description

Beim vorliegenden Projekt handelt es sich um die Erweiterung des Schulcampus Dorf, Binnigen (SCD). Vom Untergeschoss bis und mit Bodenplatte Erdgeschoss wird der Rohbau als klassische Stützen- Plattenkonstruktion in Stahlbeton ausgeführt. Die Geschossen Erdgeschoss bis 2. Obergeschoss werden aus einer Holzbau-Konstruktion mit einer Holz-Beton-Verbunddecke gefertigt. Das Gebäude wird als Schulhaus genutzt. Diese Ausschreibung enthält folgende Arbeiten / Bauteil: - Akustisch wirksame Wandbekleidungen aus Holz
