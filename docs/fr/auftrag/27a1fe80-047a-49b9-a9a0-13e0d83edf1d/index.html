Description

SH POWER baut im Schweizersbild (Schaffhausen) einen neuen Werkhof, welcher voraussichtlich im 2. Quartal 2025 bezugsbereit sein wird. Der Werkhof besteht aus einem Büro- und Lagergebäude sowie einem überdachten Aussenlager.

Der Gegenstand dieser Ausschreibung umfasst die Lieferung und Montage der Lagereinrichtungen für das Lagergebäude sowie das Aussenlager.
