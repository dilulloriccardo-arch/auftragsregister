Description

Le marché concerne l’extension du centre scolaire de Moréchon à Savièse.

Le projet se compose de trois bâtiments :
· Une école primaire (~10'300 m3 selon SIA 416)
· Une salle de gym double, avec un abri PC (~13’800 m3 selon SIA 416)
· Une unité d’accueil pour la petite enfance (UAPE, ~4'700 m3 selon SIA 416).

Le budget total du projet est estimé à environ 30 millions de francs TTC.
