Description

Acquisition d'un camion forestier 3 essieux avec grue et système multibenne
1. Objet du marché
Le présent appel d'offres porte sur la fourniture, la mise en service et la livraison d'un camion forestier neuf destiné aux activités du Service forestier Zorèyè.
Le véhicule sera principalement utilisé pour :
- le transport de bois rond et de produits forestiers ;
- le transport de plaquettes forestières ;
- le transport de bennes, matériaux et équipements ;
- les travaux de manutention au moyen d'une grue forestière ;
- les interventions sur l'ensemble du territoire des communes desservies par le Service forestier Zorèyè.
Le soumissionnaire devra fournir un véhicule entièrement opérationnel, homologué pour circuler sur le réseau routier suisse et conforme à l'ensemble des prescriptions légales en vigueur.
2. Configuration générale souhaitée
Le véhicule devra répondre aux caractéristiques minimales suivantes :
- camion porteur neuf à trois essieux ;
- transmission 6×4 ;
- PTAC conforme à la législation suisse ;
- cabine adaptée à une utilisation professionnelle intensive ;
- châssis compatible avec un équipement multibenne et une grue forestière ;
- crochet d'attelage homologué pour remorque ;
- charge utile optimisée tout en respectant les charges maximales admissibles sur les essieux.
3. Equipements
Le véhicule devra notamment être équipé de :
- une grue forestière montée derrière la cabine ;
- portée hydraulique d'environ 15 mètres ;
- radiocommande complète ;
- système multibenne ;
- prises hydrauliques et électriques nécessaires à l'exploitation ;
- éclairage de travail LED ;
- caméra de recul ;
- équipement de sécurité conforme aux prescriptions en vigueur.
4. Prestations attendues
Le soumissionnaire devra inclure dans son offre :
- la fourniture complète du véhicule ;
- l'ensemble des adaptations nécessaires ;
- les essais de réception ;
- la mise en service ;
- la formation des utilisateurs ;
- la documentation technique en français ;
- le carnet d'entretien ;
- les certificats d'homologation.
5. Garanties et service après-vente
L'offre devra préciser notamment :
- les garanties constructeur ;
- les garanties sur la chaîne cinématique ;
- les garanties sur la grue et les équipements hydrauliques ;
- les prestations couvertes ;
- les délais d'intervention en cas de panne ;
- la disponibilité des pièces de rechange ;
- les possibilités de contrat d'entretien ;
- les coûts des contrats de maintenance proposés.
6. Délais
Le soumissionnaire indiquera :
- le délai de fabrication du châssis ;
- le délai de montage des équipements ;
- la date prévisionnelle de livraison du véhicule prêt à l'emploi.
7. Critères d'évaluation
Les offres seront évaluées selon les critères suivants :
- prix global de l'offre ;
- qualité technique du véhicule ;
- adéquation aux besoins du Service forestier ;
- coûts d'exploitation et d'entretien ;
- garanties proposées ;
- qualité du service après-vente ;
- délais de livraison ;
- valeur résiduelle estimée ;
- références du fournisseur.
8. Documents à fournir
Chaque offre comprendra notamment :
- fiche technique détaillée ;
- plans d'implantation des équipements ;
- répartition des charges sur les essieux ;
- poids à vide et charge utile ;
- descriptif complet des équipements ;
- consommation et caractéristiques moteur ;
- garanties ;
- contrat d'entretien (facultatif) ;
- planning de livraison.
Le pouvoir adjudicateur se réserve le droit de demander tout complément d'information utile à l'analyse des offres.
