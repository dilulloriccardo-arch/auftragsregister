Motivation de l'adjudicateur

Die Obrist Transport + Recycling AG hat das vorteilhaftestes Angebot eingereicht. Ausschlaggebend war das Zuschlagskriterium Preis sowie Schadstoffemissionen.

Description

Die Auftragnehmer sammelt den Haushaltkehricht inkl. Sperrgut, das Grüngut, den Karton, das Altpapier und transportiert die Abfälle zur Verwertungsanlage. Das Grüngut muss vergärt werden.
