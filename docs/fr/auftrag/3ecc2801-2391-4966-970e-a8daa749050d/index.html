Motifs de l'adjudication

Das berücksichtigte Angebot hat aufgrund seiner Merkmale und Vorteile die meisten Nutzwertpunkte (NWP) erzielt. Die Zuschlagskriterien (ZK) wurden wie folgt bewertet: ZK 1 Preis: 150 von 150 NWP ZK 2 Referenzauftrag Anbieter: 35 von 35 NWP ZK 3 Anbieterin / Hersteller / Managed Service: 65 von 75 NWP ZK4 Lösung On-Premise Backup: 60 von 90 NWP ZK 5 Lösung Cloud Backup: 33.30 von 50 NWP ZK 6 Lösung Langzeitspeicher: 33.30 von 50 NWP ZK 7 Nachhaltigkeit: 50 von 50 NWP Total: 426.60 von 500 NWP Die Anbietenden können sich unabhängig von einer allfälligen Beschwerde für ein informelles Debriefing bei der Kantonalen Fachstelle für öffentliche Beschaffungen melden.

Description

Der Gegenstand der Ausschreibung ist die Evaluation eines Managed Services für Backup / Recovery von On-Premises und Cloud Infrastrukturen der IT-BS, sowie einer Langzeitspeicher Lösung im Pay-per-Use Verfahren. Die Anbieterin stellt die notwendige Infrastruktur in der benötigten Kapazität zur Verfügung und betreibt diese gemäss den definierten SLAs (siehe Lastenheft Abschnitt 3.2.4). Die Hardware und Software bleiben im Besitz der Anbieterin. Neben einer jährlichen Kostenpauschale richtet sich der Preis nach den monatlich effektiv von IT-BS genutzten Kapazitäten und wird pro TB pro Monat verrechnet. IT-BS garantiert eine definierte Mindestabnahmemenge.
