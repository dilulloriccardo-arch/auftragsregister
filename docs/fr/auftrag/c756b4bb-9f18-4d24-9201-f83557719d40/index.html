Description

Kurzbeschrieb Gebäude Neubau Sicherheits- und Rettungsstützpunkt Riet in Wangs. Das dreigeschossige Gebäude mit Schrägdach wird grundsätzlich in Holzbauweise erstellt. Bodenplatte, Streifenfundamente, Stützen und Treppenhauskerne sind aus Ortbeton. Kurzbschrieb ausgeschriebene Arbeiten Komplettes Fassadengerüst im Zusammenhang mit dem Neubau gemäss Leistungsverzeichnis, ca. 7620m2
