Motivation de l'adjudicateur

Die Zuschlagsempfängerin hat beim Kriterium "Preis" die zweit höchste Punktzahl erreicht. Beim Kriterium "Auszubildende" hat die Zuschlagsempfängerin mit weiteren drei Anbieterinnen die maximale Punktzahl erreicht während vier Anbieterinnen nicht die maximale Punktzahl erreicht haben und zwei weitere Anbieterinnen haben bei diesem Kriterium jeweils null Punkte erhalten. Beim Kriterium "Qualität der angebotenen Anlage" hat die Zuschlagsempfängerin 276.00 von maximal möglichen 300 Punkten erreicht. Der Vorsprung auf die zweit- und drittplatzierte Anbieterin beträgt bei diesem Kriterium 138.00 respektive 168.00 Punkte. In der Gesamtauswertung hat die Zuschlagsempfängerin mit einem Vorsprung von 11.51 respektive 170.72 Punkte eine Punktzahl von 819.51 Punkten erreicht (maximale mögliche Gesamtpunktzahl = 1000 Punkte). Die Firma Senero AG hat somit das vorteilhafteste Angebot eingereicht, welches den Zuschlag erhält. (Art. 41 IVÖB 2019)
