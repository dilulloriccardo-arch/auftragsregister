Description

Le marché consiste en l’achat de licences de l’éditeur Microsoft dans le cadre du programme de licences « CASA EES » pour les écoles publiques du canton du Valais. Les produits concernés sont en particulier Microsoft 365 ainsi que les infrastructures et services Azure.
