Description

Le présent marché concerne les travaux de la réalisation d’une place multifonctionnelle sur le site du CeRN à Bursins ainsi que la réalisation des travaux préparatoires pour 3PS (réalisation des places d’installation de chantier) situés sur les communes de Perroy, Luins et Duillier. Les travaux principaux sont : - Réalisation d’une place multifonctionnelle d’environ 5'000 m2 en enrobé ; - Déplacement de batteries de tubes et canalisations ; - Construction d’un SETEC ; - Travaux de terrassement pour la réalisation d’un étang de compensation ; - Construction de 3 places d’installation de chantier annexes. Les quantités principales sont approximativement : - Excavation : 17'350 m3 - Remblais : 3’000 m3 - Enrobé : 1'700 to - Béton : 650 m3 - GNT 0/45 : 3'000 m3
