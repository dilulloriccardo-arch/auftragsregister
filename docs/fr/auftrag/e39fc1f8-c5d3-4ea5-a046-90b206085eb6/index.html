Description

Lot 1

L’objectif de l’appel d’offres est la conclusion d’un contrat-cadre avec un ou plusieurs soumissionnaires pour l’acquisition des besoins prévus pour le ballast RC pour les années 2027 et 2028, avec une option de prolongation d’un an pour 2029, 2030 et 2031. Pour la région de l'Oberland.

Lot 2

L’objectif de l’appel d’offres est la conclusion d’un contrat-cadre avec un ou plusieurs soumissionnaires pour l’acquisition des besoins prévus pour le ballast RC pour les années 2027 et 2028, avec une option de prolongation d’un an pour 2029, 2030 et 2031. Pour la région du Mittelland.

Lot 3

L’objectif de l’appel d’offres est la conclusion d’un contrat-cadre avec un ou plusieurs soumissionnaires pour l’acquisition des besoins prévus pour le ballast RC pour les années 2027 et 2028, avec une option de prolongation d’un an pour 2029, 2030 et 2031. Pour la région de l'Emmental.

Lot 4
