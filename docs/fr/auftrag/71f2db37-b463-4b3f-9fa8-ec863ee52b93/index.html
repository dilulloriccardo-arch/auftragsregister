Description

Die Baumassnahme sieht im Hinblick auf die Umnutzung des bestehenden KSW Spital-Gebäudes Haus T eine Aufstockung des bestehenden Gebäudes um ein weiteres Geschoss und eine Technikzentrale darüber. Im Rahmen des Projektes sollen folgende Nutzungen im Haus T implementiert werden: 3.OG - Technikzentrale (Aufstockung des Bestands, neu) 2.OG - Büroräumlichkeiten + Radiopharmazie (Aufstockung des Bestands, neu) 1.OG - Einbau von 2x PET-CTs inkl. Vor- und Nachbereitungsräumen (neu innerhalb Bestand) EG - Molekularpathologie (neu innerhalb Bestand) 1.UG - Histologie (Bestand, temporärer Auszug während Umbau) 2.UG - Serverfarm + Technik (Bestand)
