Description

À tous les niveaux du rez-de-chaussée et des étages supérieurs, le plafond principal sera réalisé sous forme de plafond acoustique en bois. Cela concerne les espaces publics dans les salles d'audience, les salles d'attente, les bureaux ainsi que les espaces de pause. Les plafonds acoustiques doivent être réalisés soit en version standard, soit en version RF1.
