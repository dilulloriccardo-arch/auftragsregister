Motivation de l'adjudicateur

L'offre a été jugée la plus avantageuse sur l'ensemble des critères d'appréciation fixés dans le dossier d'appel d'offres.

Description

Le présent appel d’offres porte sur l’acquisition de 319 routeurs pour l’offre de base - 278 routeurs pour la Route (modules pour véhicules Route) ; - 41 routeurs pour le métro M1 et le LEB (modules pour véhicules Ferroviaire) ; et sur l’acquisition de 140 routeurs en option - 120 routeurs pour la Route (modules pour véhicules Route) ; - 20 routeurs pour le métro M1 et le LEB (modules pour véhicules Ferroviaire). Ces routeurs devront notamment être compatibles avec la technologie 5G et sont certifiés ITxPT.
