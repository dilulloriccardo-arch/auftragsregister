Description

Le présent marché porte sur la rénovation, transformation et l’agrandissement du centre culturel de l’épicentre, sis au chemin de Mancy 61 sur le territoire communal de Collonge-Bellerive, sur la parcelle de propriété communale n°4489. Le site existant comprenant deux bâtiments et un skate-park sera complété par une nouvelle construction. CFC 243.2 SONDES GÉOTHERMIQUES, forages et installation
