Motivation de l'adjudicateur

Das Angebot erweist sich gestützt auf die Bewertung der in den Ausschreibungsunterlagen festgelegten Zuschlagskriterien als das vorteilhafteste.

Description

Erstellen von zwei neuen Parkplätzen mit total 151 Parkplätzen sowie einem Zweiradunterstand als Sichtbetonkonstruktion. Die Parkplätze kommen auf Schotterrasenflächen zu liegen. In den Fahrgassen ist Asphalt vorgesehen. Für die Beleuchtung müssen Werkleitungen erstellt werden. Die angrenzenden Flächen werden neu bepflanzt.
