Description

Mit der vorliegenden Ausschreibung soll dem obsiegenden Anbieter der Auftrag zur Erbringung der Catering-Dienstleistungen für das Zivilschutzausbildungszentrum Eiken erteilt werden, damit die Verpflegung der Auszubildenden, des Ausbildungspersonals sowie der Drittnutzer weiterhin sichergestellt ist.
