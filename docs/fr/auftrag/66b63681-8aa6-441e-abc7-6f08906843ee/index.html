Motivation de l'adjudicateur

Der Zuschlag erfolgt an das beste Angebot gemäss den im Pflichtenheft definierten Zuschlagskriterien Preis, Dienstleistungen und Service-Leistungen, Hardware-Management und Manageability, Nachhaltigkeit, Referenzen.

Description

Die Vergabestelle sucht einen Leistungserbringer für: a) die Lieferung definierter Arbeitsplatz-Hardware (Notebook, Desktops, Dockingstations, Monitore und Zubehör) inklusive Veredelungs-Dienstleistungen (Asset-Tagging, Pre-Provisioning) b) die Erbringung von Garantie-Wartungs-Arbeiten der definierten Arbeitsplatz-Hardware, c) die Rücknahme von Altgeräten (Trade-In) d) die Zurverfügungstellung eines Serviceportals
