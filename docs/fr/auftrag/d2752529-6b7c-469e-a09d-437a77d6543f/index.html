Description

CFC 201.00 Fouilles en pleine masse Dans le cadre du projet d’extension de l’antenne de Berthoud, d’importants travaux de construction seront réalisés dans plusieurs bâtiments. Font partie de cet appel d’offres 33 000 m3 d’excavation, 26 500 m3 d’évacuation vers la décharge de l’entrepreneur, dont 8 800 tonnes de matériaux faiblement pollués.
