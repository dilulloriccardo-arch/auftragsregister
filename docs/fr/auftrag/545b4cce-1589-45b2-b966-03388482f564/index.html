Description

L’Etat de Fribourg, représenté par la Direction des Finances (DFIN), lance un AO pour l’administration et la gestion des systèmes SAP sur site (SAP ECC, SAP S/4HANA, BW, etc.) dans leurs environnements techniques respectifs (VMWare, Windows, MS SQL, Oracle, HANA, SUSE Linux), et incluant les activités SAP Basis, répondant aux exigences du Fascicule 4 - Cahier des charges.
