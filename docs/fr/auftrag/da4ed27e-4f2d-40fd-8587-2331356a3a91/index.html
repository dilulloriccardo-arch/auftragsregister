Description

L'ETH Zurich cherche un ou plusieurs partenaires de services qui soutiennent l'école supérieure dans la réalisation et le suivi des examens numériques (support informatique de premier niveau pour les examens numériques Windows). L'objectif est de conclure des contrats-cadres avec une à trois entreprises.

Publication officielle : projet 8953 sur simap.ch – seule cette publication fait foi.
