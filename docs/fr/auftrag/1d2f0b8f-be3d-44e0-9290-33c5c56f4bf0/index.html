Description

Cet appel d'offres a pour objectif de sélectionner deux partenaires externes qualifiés pour la fabrication et la fourniture de câbles destinés aux postes d'aiguillage. Les deux soumissionnaires les mieux classés se verront attribuer chacun un contrat-cadre d'une durée fixe de trois ans. Les commandes concrètes seront attribuées, dans le cadre de ces contrats, projet par projet, selon une procédure dite de « mini-appel d'offres ». L'objectif est de garantir un approvisionnement économique et respectueux des délais afin d'assurer une exploitation ferroviaire sûre et durable sur le réseau de la BLS
