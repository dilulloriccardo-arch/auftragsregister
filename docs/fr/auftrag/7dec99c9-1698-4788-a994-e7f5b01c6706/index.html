Description

Die KVA Linth erweitert ihr Fernwärmenetz. Dazu wird in den Jahren 2024 und 2025 eine Verbindungsleitung mit dem Nenndurchmesser DN250 nach Bilten erstellt. Der Anschluss erfolgt an eine bereits bestehende Leitung DN200. Weitere Informationen finden Sie in der Submission
