Description

Die ausgeschriebene KI-gesteuerte Trockenwäschestrasse ist für ein breites Trockenwäsche-Sortiment für den Krankenhaus- und Hotelbereich vorgesehen. Die neue Anlage für unsere Zentralwäscherei in Liestal, wird täglich im Einsatz sein. Um das tägliche Wäschevolumen zu bewältigen muss die Anlage den Qualitätsansprüchen der internen und externen Kunden entsprechen und für das Personal möglichst einfach bedienbar sein.
