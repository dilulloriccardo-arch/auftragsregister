Description

Le mandat comprend le marquage d'entretien pour les années 2026-2031 sur les routes nationales dans la zone de l'unité territoriale 1 (voir 05.0_Filialkarte F2 – Mst 100’00.pdf). Le marquage des routes nationales est entretenu à intervalles réguliers (voir 06.0_Bauprogramm Bauherr.pdf). Tous les marquages sont rafraîchis et, si nécessaire, refaits.
· Marquages longitudinaux : env. 1'085'151 m
· Marquages transversaux : env. 5'470 m
· Marquages de surface : env. 48'099 m²
· Marquages pour le trafic en stationnement : env. 10'759 m
· Flèches : env. 754 pces
· Symboles : env. 298 pces
· Inscriptions : env. 105 pces
