Description

Travaux de défrichement et de plantation sur N01/42 en direction de Saint-Gall. Côté route, les murs Evergreen existants doivent être débarrassés des anciennes plantations envahies de néophytes puis, après application d’un substrat propre, revégétalisés avec de petits ligneux (p. ex. du lierre). La logistique est effectuée via une piste de chantier à aménager côté terrain / avec des grues.
