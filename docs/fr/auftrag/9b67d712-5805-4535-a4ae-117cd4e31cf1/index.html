Description

Die Primarschule Mettmenstetten hat ein neues ICT-Konzept erarbeitet. Dies sieht unter anderem eine Erweiterung des Bestandes an iPads und Notebooks vor. Mit dieser Submission soll einerseits der zusätzliche Bedarf an Hardware und andererseits der Ersatz der vorhandenen Geräte entsprechend dem Lifecycle beschafft werden. Ein Teil der Geräte wird gekauft, für den anderen Teil ist ein Leasing vorgesehen.
