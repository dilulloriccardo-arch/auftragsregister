Description

- Handlaufsystem mit integrierter Beleuchtung und integrierten Kabelkanal. - Die integrierte LED-Beleuchtung (Notbeleuchtung) leuchtet den Fluchtweg und die Fluchtwegschilder an. - Alarmierungseinheiten (Einschaltung der Notbeleuchtung mittels Nottaster vor Ort und Übermittlung an die Verkehrsleitzentrale). - Für das Handlaufsystem benötigte Befestigungsmaterial. - Kabel für die jeweilige System Kabel zur Installation gemäss Vorgaben in Tunnels. - Spezialanfertigungen im Bereich der Sicherungsanlagenelementen (wie z.B. Signale, Kabelverteiler etc.) sowie Nischen. - Reservematerial – Ersatzmateriallieferungen. - Engineering Leistungen (inkl. Schulung und Montageanleitungen).
