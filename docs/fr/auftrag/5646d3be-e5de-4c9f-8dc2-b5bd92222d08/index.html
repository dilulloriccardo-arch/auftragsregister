Description

Nuovo serbatoio dell'acqua potabile avente le seguenti caratteristiche: - Nome: Serbatoio Sottosasso, capacità 2'300 m3; - Tecnica costruttiva: esecuzione in tradizionale in CA; - 2x vasche da 1'150 m3 più una camera manovra e SP 2 l/s che carica la zona alta di Barbengo; - Quota TP: 370 m.s.l.m; - Base normativa: direttiva SSIGA W6; - Accesso sufficiente con veicoli di servizio, con spiazzo per due posti auto; - Trattamento di potabilizzazione: nessun impianto di trattamento - Idraulica: condotta entrata / uscita DN 300; condotta premente verso zona alta DN 125.
