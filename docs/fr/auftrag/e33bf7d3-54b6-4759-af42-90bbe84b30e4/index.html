Description

L’IPI utilise une infrastructure (informatique) autonome, indépendante de celle de l’administration fédérale. Afin de seconder son service informatique interne, il fait appel à des prestataires externes pour certaines tâches et dans certains domaines spécifiques Pour compléter le service informatique interne, nous recherchons une entreprise capable d'assister l'IPI dans le domaine Assistance d'exploitation réseau (assistance générale à l'exploitation, mandats de conseil, assistance à l'intégration de systèmes, assistance à la réalisation de projets).
