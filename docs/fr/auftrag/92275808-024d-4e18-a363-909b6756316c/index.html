Description

Der Schwerpunkt des Contracting-Auftrags liegt in der Erbringung einer kontinuierlichen Nutzwärmelieferung auf Basis einer mobilen Holz-Pelletanlage und der dazugehörigen Betriebs-Dienstleistung über die gesamte Vertragslaufzeit. Der Leistungsumfang gliedert sich in folgende Hauptbereiche: Planung&Erstellung, Bereitstellung, Energielieferung, Betrieb/Instandhaltung, 24/7 mit Pikettdienst, Rückbau.
