Description

L’objet du marché consiste en une offre, d’une validité de 6 mois, pour l’acquisition d’une balayeuse diesel pour la Commune de Villars-sur-Glâne.

La machine est une version communale d’une balayeuse possédant les caractéristiques suivantes :
- Motorisation Diesel ;
- Possède 2 places au minimum ;
- Volume total de la cuve entre 4 et 6 m³ ;
- Hauteur hors tout maximum 3'100 mm ;
- Equipée de 3 brosses ;
