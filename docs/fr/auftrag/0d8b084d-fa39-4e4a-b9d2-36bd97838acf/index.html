Description

- Bereitstellung einer Marken-Management-Software (Lizenzen oder als SaaS)
- Betrieb/Hosting der Software
- Implementierung und Migration bestehender digitaler Assets
- Onboarding und Schulung
Mittels einer Marken-Management-Software stellt die Universität St.Gallen (HSG) alle Standards des HSG-CI/CD, internen und externen Anspruchsgruppen zur Verfügung. Die Markenplattform dient als Hub für Vorlagen, Brand Assets und internen Dienstleistungen. Die Funktionalität und Inhalte der Plattform werden kontinuierlich ausgebaut und auf die Bedürfnisse der User ausgerichtet.
