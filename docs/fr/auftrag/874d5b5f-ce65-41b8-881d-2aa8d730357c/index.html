Motifs du choix

Das berücksichtigte Angebot hat aufgrund seiner Merkmale und Vorteile die meisten Nutzwertpunkte (NWP) erzielt. Die Zuschlagskriterien (ZK) wurden wie folgt bewertet:

ZK 1 Preis: 250 von 250 NWP
ZK 2 Referenzauftrag Anbieter Holzbau: 55 von 75 NWP
ZK 2 Referenzauftrag Anbieter Lehmbau: 40 von 50 NWP
ZK 2 Referenzauftrag Schlüsselperson: 50 von 50 NWP
ZK 2 Nachhaltigkeit: 65 von 75 NWP
Total: 460 von 500 NWP

Die Anbietenden können sich unabhängig von einer allfälligen Beschwerde für ein informelles Debriefing bei der Kantonalen Fachstelle für öffentliche Beschaffungen melden.

Description

- Ausführung von Holzbauarbeiten in Element- und/oder Modulbauweise
- Erstellen von Tragwerk
- Konstruktionsbau
- Beizug von Lehmbauspezialisten zur Erstellung von Decken- und Wandausfachungen als Gewölbe in Lehm sowie einer bewitterten Aussenwand in Stampflehm.
