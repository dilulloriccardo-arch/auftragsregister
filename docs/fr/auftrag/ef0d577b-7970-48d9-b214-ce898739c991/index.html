Description

Die BVB benötigt für Objekte am Streckennetz und für ihre Betriebsgebäude Elektroinstallationsarbeiten inkl. Engineering, um eine lückenlose Aufrechterhaltung des Betriebes sicherstellen zu können. Die vorliegende Ausschreibung dient dem Abschluss eines Rahmenvertrages für die vorgenannten Leistungen. Allfällige Aufträge in weiteren Objekten können ebenfalls unter diesem Vertrag abgewickelt werden, sofern die Objekte von der BVB genutzt oder verwaltet werden.
