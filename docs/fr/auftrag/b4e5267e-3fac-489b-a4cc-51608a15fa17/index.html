Description

Zwischen Jenaz und Küblis im Kanton Graubünden wird die Linienführung der Nationalstrasse (neu 2. Klasse) neu gestaltet. Parallel dazu wird eine zusätzliche Lokalstrasse realisiert. Es werden vier Strassenbrücken neu gebaut und eine saniert. Ebenfalls neu gestaltet wird die Linienführung der Rhätischen Bahn, unter anderem mit dem ca. 1.4 km langen Fiderisertunnel und drei neuen Bahnbrücken. Die Neugestaltungen weisen eine Länge von jeweils ca. 3.5 km auf.

Dieser Auftrag beinhaltet die Projektierung der Wasserbaulichen Massnahmen der Landquart in Fideris. Ausgeschrieben werden die SIA-Teilphasen 41 bis 53.
