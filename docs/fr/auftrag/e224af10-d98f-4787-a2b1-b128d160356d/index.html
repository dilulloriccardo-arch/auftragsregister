Motifs de l'adjudication

Es wurde nur eine Offerte eingereicht. Das Angebot entspricht jedoch dem aktuellen Marktpreis. Zudem überzeugt der Zuschlagsempfänger in der Qualität des Anbieters über eine sehr gute Erfahrung des Montageleiters.

Description

Les deux bâtiments de service de l'aire de repos de Glooten se trouvent en mauvais état. Pour les usagers de la route, les toilettes sont souvent inutilisables ou dans un état inacceptable. L'OFROU rénouvelle donc l'installation de service comme mesure de transformation de l'aire de repos dans le cadre de l'assainissement de la route nationale entre Interlaken Est et Brienz. A’ cet effet, l'installation sanitaire dans les deux bâtiments existants doit être remplacée par un module préfabriqué. Les modules préfabriqués doivent être raccordées aux conduites de service existantes.
