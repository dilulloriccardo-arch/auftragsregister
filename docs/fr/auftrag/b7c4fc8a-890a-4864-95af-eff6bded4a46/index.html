Description

Le GSM-R AreaManager est l'outil de configuration des services GSM-R tels que LDA, eLDA, appels d'urgence et de groupe, autorisation de départ, etc. et constitue la base de données maîtresse des données de configuration GSM-R de la communication d'exploitation et de manœuvre (BTA / LISA, RACO). Le GSMR- AreaManager est intégré dans un environnement complexe avec de nombreuses interfaces vers des systèmes environnants. La maintenance et le développement de GSMR- AreaManager doivent être assurés jusqu'à la fin de vie (EoL) du GSM-R. La SA CFF reste le propriétaire du GSM-R AreaManager.
