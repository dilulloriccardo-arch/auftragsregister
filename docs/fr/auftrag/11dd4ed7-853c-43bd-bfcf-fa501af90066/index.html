Description

ESB a l'intention de construire un nouveau bâtiment aux Champs-de-Boujean pour abriter les composants haute tension. Pour ce faire, la ligne 50 kV existante UST Reuchenette - UST Mâche sera bouclée dans la nouvelle sous-station. La description détaillée et l'étendue des prestations sont disponibles dans le dossier d'appel d'offres. Aperçu des prestations : - Ingénierie, fabrication, livraison, montage et contrôle des installations de câbles et des accessoires - Démontages - Documentation finale
