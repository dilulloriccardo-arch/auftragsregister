Description

Das Amt für Informatik (AFI) des Kantons Zürich entwickelt und betreibt heute – in Bezug zur «Informations- und Kommunikationstechnologiestrategie (IKT)» des Kanton Zürich vom 25. April 2018 - mehrere Tenants in der Microsoft Azure Cloud um die Bedürfnisse der kantonalen Verwaltung und auch der SEKII Schulen (Berufs- und Mittelschulen) optimal erfüllen und umsetzen zu können. Der Betrieb dieser Microsoft Azure Tenants soll durch externe, spezialisierte Dienstleister mit ausgewiesener Microsoft Azure Expertise unterstützt werden.
