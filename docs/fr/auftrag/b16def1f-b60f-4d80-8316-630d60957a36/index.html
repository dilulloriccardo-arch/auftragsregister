Description

Für das Schulareal der Gemeinde Zwingen soll eine neue Wärmeerzeugeranlage installiert werden. Die neue Wärmeerzeugeranlage mit zwei identischen Grundwasserwärmepumpen wird im Technikraum im 2. Untergeschoss im bestehenden Technikraum installiert. Die Wärmeverteilung wird neu aufgebaut und an die bestehenden Leitungen angeschlossen. Der Öltankraum wird für die Energiespeicher umgenutzt. Die Grundwasserbrunnen sowie die Leitungen sind bereits bis ins 1. Untergeschoss vorbereitet.
