Motifs du choix

Die Vergabe erfolgt an das nach den Kriterien der Ausschreibung ermittelt wirtschaftlich vorteilhafteste Angebot.

- Preislich auf den 1. Rang
- Qualifizierte Schlüsselpersonen angeboten
- Offertangebot in einer hohen Qualität
- Transparente Offerte in der Preisfindung

Description

Es werden zwei neue Perrondächer aus Stahlbau mit direkt integrierter Photovoltaikanlage realisiert. Die Werksplanung erfordert eine enge Koordination mit dem separat beauftragten Solateur.

Die Perrondächer auf den zwei Perrons werden in zwei zeitlich unterschiedlichen Etappen jeweils unter Bahnbetrieb gebaut.

- Stahlprofile (Stützen und Träger) ca. 110'500 Kg
- Oberflächenschutz: ca. 2'250 m2
