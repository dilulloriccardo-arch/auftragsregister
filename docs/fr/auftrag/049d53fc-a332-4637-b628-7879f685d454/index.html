Description

Das Kommandogebäude ist ein Stahlbeton-Skelettbau aus dem Jahre 2000 und soll um zwei Geschosse aufgestockt (ET1) und die bestehenden Geschosse (ET3) saniert werden.

Die Submission beinhaltet folgende Leistung:
Erstellung der Flachdacharbeiten auf dem neuen Hauptdach sowie im Innenhof auf einer Fläche von rund 840 m2.
