Description

L’objet du présent appel d’offres est la fourniture à l’Hôpital universitaire de Zurich (USZ) de prestations de services correspondant à différents profils spécialisés dans l’environnement SAP BI. Trois partenaires sont recherchés. Ceux-ci doivent employer directement les spécialistes concernés et ne doivent pas agir en tant qu’agences de placement de personnel. L’acquisition de prestations de services SAP est effectuée dans le cadre de plusieurs procédures d’appel d’offres distinctes, réparties par thématiques.
