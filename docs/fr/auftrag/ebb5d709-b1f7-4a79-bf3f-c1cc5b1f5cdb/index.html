Description

Un projet de maintenance est prévu sur le tronçon UPlaNS Bilten-Murg-Näfels, lequel devrait être réalisé à partir de 2032. Les points forts de ce projet de maintenance sont la remise en état de la chaussée et de tous les ouvrages d’art dans le périmètre du projet ainsi que la rénovation complète de l’équipement d’exploitation et de sécurité.

Dans le cadre de ce mandat, des prestations d’étude de projet doivent être fournies pour un relevé d’état / un contrôle de conformité aux normes, une étude d’approfondissement et, par la suite, un concept de mesures concernant l’équipement d’exploitation et de sécurité.
