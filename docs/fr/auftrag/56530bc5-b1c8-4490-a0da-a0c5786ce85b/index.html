Description

Beschaffungsgegenstand dieser Ausschreibung ist die Ausführung des Stahlbaus für ein zusätzliches Tragwerk in der Garage Hagenholz gemäss den Ausschreibungsunterlagen. Das Tragwerk dient der Aufnahme und sicheren Befestigung der Ladeinfrastruktur für Elektrofahrzeuge, der Löschanlage so-wie der Beleuchtungseinrichtungen.
