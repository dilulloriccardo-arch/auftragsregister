Description

Die BVB benötigt für Baustellen Schwarzbelag. Der Schwarzbelag wird von der BVB ab Werk in unterschiedlichen Rezepturen bezogen. Das Werk hat zwingend auf Schweizerischem Boden zu liegen, sodass eine maximale Flexibilität bei der Abholung ohne administrative Hürden, wie z.B. Verzollung, gewährleistet ist. Mit dem Zuschlagsempfänger wird ein Rahmenvertrag abgeschlossen.
