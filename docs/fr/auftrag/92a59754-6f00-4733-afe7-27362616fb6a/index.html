Description

Ziel dieser Ausschreibung ist der Vertragsabschluss mit einem Anbieter («Reseller») zum Zweck der Zurverfügungstellung bzw. Vermittlung von Public Hyperscaler Cloud Services. Der Bezug der Cloud Services erfolgt nach Bedarf über die Laufzeit von 5 Jahren (Rahmenvertrag).
