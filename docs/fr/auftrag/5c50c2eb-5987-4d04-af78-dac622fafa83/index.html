Description

Le Service d’organisation et d’informatique (SOI) souhaite identifier deux prestataires spécialisés dans la sécurité des systèmes d’information afin d’établir un partenariat permettant de réaliser chaque année une vingtaine d’audits de sécurité de types différents, pour une volumétrie totale d’environ 750 jours de prestation sur la durée du marché.

Les audits de sécurité attendus sont de quatre types :
— audit de conformité ;
— audit de configuration ;
— audit de code source ;
— test de pénétration (ci-après « Pentest »).

Afin de pouvoir s’appuyer sur des avis et approches différentes, et conduire les audits dans les délais attendus par le SOI, deux partenaires seront sélectionnés sur la base des deux meilleurs dossiers. La répartition se fera de la manière suivante :
— 60 % du marché au soumissionnaire de rang 1 ;

40 % du marché au soumissionnaire de rang 2.
