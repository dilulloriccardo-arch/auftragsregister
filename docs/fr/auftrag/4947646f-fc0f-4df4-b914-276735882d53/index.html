Description

L'Institut des matériaux de construction (IfB) lance un appel d'offres pour l'achat d'un microscope électronique à balayage (MEB). Le système sera utilisé pour une large gamme d'analyses d'échantillons effectuées par le personnel, les étudiants en doctorat et les post-doctorants, pour la recherche ainsi que pour les activités d'enseignement. Les applications typiques comprennent l'imagerie par SEM et l'analyse EDS. Pour plus de détails, voir le document de spécification.
