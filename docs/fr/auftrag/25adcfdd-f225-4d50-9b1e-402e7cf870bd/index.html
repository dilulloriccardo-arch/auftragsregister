Description

Lot 1

Ce projet d'achat vise à trouver des prestataires spécialisés dans les architectures logicielles et les architectures de solutions dans le domaine des solutions Java (Spring, JEE) à même d'apporter un soutien ciblé au CSI-DFJP dans l'exécution de ses diverses activités.

Lot 2

Ce projet d'acquisition vise à trouver des prestataires dans le domaine du développement logiciel qui apporteront leur soutien au CSI-DFJP dans l'exécution de ses tâches variées.
