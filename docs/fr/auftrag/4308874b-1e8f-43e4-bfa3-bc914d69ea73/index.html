Description

Dans le cadre de l'acquisition du nouvel avion de combat F-35 pour la Suisse, il convient de se procurer et d'installer, sur les aérodromes, des abris pour avions et des emplacements prévus à différents endroits, équipés de nouveaux groupes frigorifiques stationnaires pour l'avionique, conformément aux spécifications techniques.
