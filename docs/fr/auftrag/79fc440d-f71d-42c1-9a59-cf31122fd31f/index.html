Motifs de l'adjudication

Das berücksichtigte Angebot hat aufgrund seiner Merkmale und Vorteile die meisten Nutzwertpunkte (NWP) erzielt. Die Zuschlagskriterien (ZK) wurden wie folgt bewertet: ZK 1 Preis: 396 von 400 NWP ZK 2 Referenzauftrag Anbieter: 84 von 100 NWP Total ZK1 / ZK2: 480 von 500 NWP Die Anbietenden können sich unabhängig von einer allfälligen Beschwerde für ein informelles Debriefing bei der Gemeindeverwaltung Riehen, Abteilung Immobilien (Fachbereich Hochbau) melden.

Description

Errichtung eines temporären, schlüsselfertigen, dreigeschossigen Schulgebäudes in Holzmodulbauweise. Im Weiteren wird auf die detaillierte Beschreibung in den Ausschreibungsunterlagen verwiesen.
