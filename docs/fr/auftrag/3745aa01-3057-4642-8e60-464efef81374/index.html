Description

Im Gesundheitszentrum für das Alter (GFA) Kalchbühl an der Kalchbühlstrasse 118, 8038 Zürich, soll im Jahr 2026 die bestehende fossile Wärmeerzeugung gegen ein umweltfreundliches System abgelöst werden. Das Grundstück bietet sich aus Gründen des Baumbestands und des Geländeverlaufs leider nicht für Erdwärmesonden an, weshalb eine Lösung mit Aussenluft als Wärmequelle angestrebt wird. Als Wärmetauscher werden Trockenrückkühler auf dem Dach des Mitteltrakts platziert. Die Wärmeerzeugung selbst erfolgt durch eine Sole-/Wasser-Wärmepumpe, welche die Heizenergie dem bestehenden Verbrauchernetz zuführt.
