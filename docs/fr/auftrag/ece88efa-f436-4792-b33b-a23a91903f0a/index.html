Description

Gegenstand der Beschaffung ist die Lieferung von Büromobiliar für die verschiedenen Standorte der AEW Energie AG.

Die Ausschreibung umfasst Bürostühle, Bürotische, Stehlampen sowie Akustikpaneele.

Ein Teil der Beschaffung ist für die Möblierung des neuen Hauptsitzes der AEW Energie AG in Aarau vorgesehen.
