Description

L'acquisition comprend l'achat d'un exemplaire de chaque appareil. La communication entre les appareils doit s'effectuer via une interface appropriée ; les appareils doivent être compatibles entre eux. Cela vaut également pour l'appareil optionnel « analyseur de signaux et de spectre ».

- Générateur de signaux vectoriels (2 canaux)
- Générateur de signaux micro-ondes
