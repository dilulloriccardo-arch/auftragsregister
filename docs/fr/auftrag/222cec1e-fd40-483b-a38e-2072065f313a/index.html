Description

Le mandat de l’étude générale concerne l’examen d'un nouveau tracé ferroviaire du tronçon Vengeron–Nyon–Perroy de la nouvelle ligne Genève–Lausanne, en coordination avec le projet d'élargissement de l'autoroute A1.
