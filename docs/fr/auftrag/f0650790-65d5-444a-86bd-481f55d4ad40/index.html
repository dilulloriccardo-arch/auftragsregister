Description

Die commIT ist die zentrale IT-Dienstleisterin der beiden Trägergemeinden Aarau und Baden. In dieser Rolle stellt commIT den beiden Trägergemeinden eine Telefonie-Dienstleistung zur Verfügung. Die bestehenden Telefonanlagen von Aarau und Baden sollen nun durch eine Microsoft-Teams-Telefonie-Lösung ersetzt werden. Die commIT ist für diesen Ersatz verantwortlich und wird die zukünftige Lösung als Service (Telefonie-Service) anbieten, welchen die beiden Trägergemeinden von der commIT beziehen. Mit vorliegender Ausschreibung sucht commIT eine Anbieterin zur Unterstützung der initialen Implementierung der neuen Microsoft (MS) Teams-Telefonie-Lösung inkl. MS Teams zertifizierte Vermittler- und DECT-Lösung, Anbindung von diversen Umsystemen (z. B. Alarmierung, Gegensprechanlagen, etc.) sowie eine verlässliche Partnerin für den Third-Level Support dieses Telefonie-Service. Die Beschaffung besteht aus der initialen Dienstleistung der Beschaffung von Hardware, Software und Dienstleistungen für die initiale Bereitstellung (Projektplanung, Rollout, Support, Schulungsunterstützung) des MS Teams Telefonie-Services gegenüber den Trägergemeinden sowie wiederkehrenden Dienstleistungen in Form von Lizenzen, Wartungsarbeiten sowie dem Third-Level Support.
