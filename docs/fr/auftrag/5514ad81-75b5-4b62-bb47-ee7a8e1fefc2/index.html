Description

Fourniture, montage, installation et raccordement de signaux dynamiques / statiques avec capteurs de trafic dans le périmètre RN N01-52/54/55/56. Offre et réalisation du présent appel d’offres SP403 par le biais de deux projets, 1. MP-070054: N01-54/55 UPlaNS SWO, signalisation «SIG-SWO» et 2. MP-220035 N01-52/56 GHGW/HVAD-URZH. Le SP403 englobe tous les signaux et capteurs de trafic pour l’enregistrement des données de trafic (CS-EDT) de la GT Uzwil Rheineck (GT-URZH). Les signaux sont commandés, et les capteurs EDT sont analysés par le client (sep. SP401). Le périmètre du projet 1 SIG-SWO englobe environ 16 commandes locales (LOC) avec 91 SIG-QS dans les tunnels, ainsi que 81 LOC décentralisées avec 122 SIG-QS sur le tracé. Le périmètre du projet 2 GSGW/HVAD-URZH comprend environ 90 LOC avec 91 SIG-QS sur le tracé. En tout, quelque 709 signaux dynamiques sont prévus pour le SP403 dans la catégorie SIG-SWO et environ 240 dans la catégorie GHGW/HVAD (quantités incluant les signaux statiques combinés avec utilisation de Pri-WS). Le SP403 comprend également des signaux statiques de différentes tailles (environ 655 signaux dans le périmètre SIG-SWO et environ 57 dans le périmètre GHGW/HVAD). L’enregistrement des données de trafic comprend 130 capteurs EDT pour SWO, répartis sur une cinquantaine de sections de mesure dans le tunnel et sur le tracé. Pour le GHGV/HVAD, le nombre de capteurs EDT est de 157 répartis sur environ 65 sections de mesure sur le tracé (une section de mesure EDT comprend au minimum un et au maximum trois capteurs EDT).
