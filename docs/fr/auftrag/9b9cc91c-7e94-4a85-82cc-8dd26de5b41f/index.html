Description

Flügel- und Schiebetüren aus Holz, ein- bis mehrflüglig, gemäss Grundrisslayoutpläne.
Bei bestehend bleibenden Türen im Umbaubereich sind folgende
Leistungen zu gerechnet:
- Richten und gangbar machen
- Beschläge reinigen, fetten, Dichtungen erneuern etc.
- Anpassen der Türblätter an neue Bodenaufbauten
Umfang bzw. Menge: 158 neue Türen
