Motifs de l'adjudication

Der Zuschlag erhielt das insgesamt wirtschaftlich vorteilhafteste Angebot auf Basis der in der Ausschreibung festgelegten Zuschlagskriterien. Das Angebot der Zuschlagsempfängerin zeichnet sich insbesondere durch die Kriterien Angebotspreis, Qualität, Leistungsfähigkeit und Referenzen aus.

Description

Die bestehende Gasheizung der Schulanlage wird durch eine Wärmepumpenanlage ersetzt. Neu erzeugen zwei Sole/Wasser-Wärmepumpen die Energie für die Raumheizung und das Brauchwarmwasser. Die Wärmequelle ist die Fernwärme Jona (Anergie) der Energie Zürichsee Linth AG (EZL). Die heutige Brauchwarmwassererzeugung wird ersetzt. Neu werden Frischwasserstationen ab Energiespeicher das Brauchwarmwasser bereitstellen.
