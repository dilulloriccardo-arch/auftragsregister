Motivation de l'adjudicateur

Den Zuschlag erhält die Firma F24 Schweiz AG, da sich die von ihr angebotene Lösung durch Effektivität, Effizienz, Funktionsumfang und Benutzerfreundlichkeit auszeichnet und so auch die volle Punktzahl im ZK3 «Zweckmässigkeit und Benutzerfreundlichkeit» erzielen konnte.

Description

La première solution (Alerte électronique, lot 1) sert à donner une alerte efficace et, si nécessaire, à grande échelle, par de multiples canaux comme la téléphonie, les SMS, les courriels et les applications prévues à cet effet. Le mandat de base comprend la solution entièrement opérationnelle avec toutes les prestations nécessaires à son utilisation (SaaS) ainsi que les activités de formation et d’assistance.
