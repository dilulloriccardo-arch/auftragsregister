Motifs du choix

Description

Die Baudirektion Uri, vertreten durch das Amt für Betrieb Nationalstrassen, eröffnet die Konkurrenz für die Vergabe und Beschaffung eines Kanalreinigungsgerätes (Saug- und Spühlgerät) inklusive Aufbau auf ein geliefertes Trägerfahrzeug gemäss Pflichtenheft (Teil 3).
