Description

Les prestations que le bureau de coordination doit fournir peuvent être regroupées en différents modules et décrites comme suit :
• Module 0 Coordination et conseil
• Module 1 Élaboration initiale du plan général d'évacuation des eaux (PGEE)
• Module 2 Première élaboration de la structure IB avec les produits aperçu de l'installation (S1), documentation de l'objet (S2), cadastre des conduites (S4) et schéma géographique (S4P)
• Module 3 Élaboration initiale du concept d'approvisionnement et d'élimination (VEK) et analyse énergétique (EA)
• Module 4 Planification de la maintenance (planification IH)
• Module 5 Mise à jour des différents produits
• Module 6 Prestations supplémentaires selon les besoins du client
La description détaillée des prestations et les prestations par module figurent dans la partie B « Description des prestations ».
