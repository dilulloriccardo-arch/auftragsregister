Description

armasuisse Immobilier recherche des entreprises disposant d'un savoir-faire dans la gestion commerciale d'immeubles. Les prestations doivent être fournies dans le cadre des modules suivants :
- Module 1 : activités relevant du droit réel
- Module 2 : location, bail à ferme et prêt à usage
- Module 3 : location
- Module 4 : résiliation de contrats
- Module 5 : mise à jour du registre foncier
- Module 6 : achat, vente
