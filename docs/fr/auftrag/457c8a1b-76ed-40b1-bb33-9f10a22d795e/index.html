Description

armasuisse Immobilien sucht Unternehmen, die über Fachwissen in der kaufmännischen Bewirtschaftung von Immobilien verfügen. Die Leistungen sind in folgenden Modulen zu erbringen: - Modul 1: Sachenrechtliche Tätigkeiten - Modul 2: Vermietung, Verpachtung und Gebrauchsleihe - Modul 3: Anmiete - Modul 4: Auflösung Vertragsschiessplätze - Modul 5: Bereinigung Grundbuch - Modul 6: Kauf, Verkauf
