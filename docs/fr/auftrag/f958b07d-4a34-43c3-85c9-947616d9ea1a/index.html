Motivation de l'adjudicateur

Den Zuschlag als Rahmenvertragspartner erhält die Firma Puzzle ITC AG, welche über die geforderte Erfahrung in der Umsetzung komplexer Vorhaben im Geoinformatikbereich verfügt, das preisgünstigste Angebot eingereicht hat und mit den eingereichten Konzeptdokumenten überzeugen konnte.

Description

Aufbau eines neuen zentralen wissensbasierten Informationssystems mit der Bezeichnung Mont Terri Experiment Information System (MONTEIS). Für die Erbringung der benötigten Leistungen benötigt der Beschaffungsgegenstand folgende Arbeiten: · Grundauftrag: Entwicklung und Betrieb von Applikationen (MVP) gemäss Kap. 4.1. im Pflichtenheft. Der Grundauftrag umfasst die Entwicklung, die Optimierung und den Betrieb von Cloud-basierten Applikationen sowie die Bereitstellung von IT- und Geoinformatikexpertisen einschliesslich Frontend- & Backend-Entwicklungen, Screendesign und Data Processing (MVP von MONTEIS). · Option 1: Zusätzliche Funktionale Anforderungen an das System und die WebAPP gemäss Kap. 4.2. im Pflichtenheft. Diese Option umfasst die Entwicklung und Implementierung von zusätzlichen Funktionalitäten zweiter Priorität in MONTEIS. · Option 2: Zusätzliche Funktionale Anforderungen an das System und die WebAPP gemäss Kap. 4.3. im Pflichtenheft. Diese Option umfasst die Entwicklung und Implementierung von zusätzlichen Funktionalitäten dritter Priorität in MONTEIS.
