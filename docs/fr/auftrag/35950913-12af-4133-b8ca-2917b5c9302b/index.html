Description

Der Auftrag teilt sich in zwei Lose: Los 1: Review der erarbeiteten Strategie zur Auswahl eines TMS Los 2: Beratung/Coaching zur fristgerechten Erarbeitung einer Strategie zur Beschaffung eines TMS und Konzeptberatung zur Erarbeitung einer Roadmap für das Programm Bahnautomation. Es sind beide Lose anzubieten. Vorzugsweise werden beide Lose an einen Anbieter vergeben. Ergibt es sich aus der Konstellation der Anbieter, können die Lose an je einen Anbieter vergeben werden. Die Teilung eines Loses ist ausgeschlossen.
