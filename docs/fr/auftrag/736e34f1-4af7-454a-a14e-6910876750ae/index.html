Motifs de l’adjudication

Es handelt sich um das vorteilhafteste Angebot auf Basis aller Kriterien.

Description

Travaux de nettoyage et application d’un produit hydrophobe sur les murs situés le long de la chaussée autoroutière. Ces travaux se dérouleront de nuit.

L’accessibilité de certains ouvrages nécessitera l’emploi de nacelles ou autre équipement pour travail en hauteur.

Publication officielle : projet 14225 sur simap.ch – seule cette publication fait foi.
