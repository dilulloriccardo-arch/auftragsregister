Description

L’appel d’offres comprend le nettoyage du tunnel de base du Lötschberg.

Les phases suivantes sont prévues.

Nettoyage d’essai:
Le nettoyage d’essai doit permettre de s’assurer que le fournisseur peut garantir la qualité du nettoyage proposé.

Nettoyage complet:
Le nettoyage complet doit permettre de nettoyer une fois entièrement le tunnel du Lötschberg.

Paquets annuels pour les années 2026-2033:
Nettoyage des tronçons/sections du TBL selon la description détaillée dans le document 3.1 du cahier des charges.
