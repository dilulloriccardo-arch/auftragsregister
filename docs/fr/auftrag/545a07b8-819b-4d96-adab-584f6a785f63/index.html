Description

Um bei einem Störfall die langen Lieferzeiten überbrücken zu können, sollen 850m 132kV-Dreileiterkabel 3x1x630mm² Cu (in Stahlrohr 148/159 passend), als Störfallreserve, auf einer Bobine mit mechanischem Schutz zum Einlagern bei IWB beschafft werden. Gegenstand der Beschaffung ist ein 132kV Kabel 3x1x630mm² Cu (in Stahlrohr 148/159 passend).
