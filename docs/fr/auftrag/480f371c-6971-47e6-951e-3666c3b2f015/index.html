Description

Le projet « Acquisition d’un Système de traction ferroviaire à écartement métrique pour l’infrastructure de FLP » ou « Véhicule » soumis à la procédure d’appel d’offres, englobe les installations suivantes pour le Marché de base : 1 Système de traction ferroviaire pour la Voie Métrique (VM) Afin de renouveler ses équipements, ainsi qu’atteindre une meilleure performance et efficacité d’exploitation, FLP souhaitent renouveler le matériel roulant pour les besoins d’entretiens de ses infrastructures, notamment son Locotracteur ferroviaire Tm 2/2 datant de 1993. Ce véhicule roule sur la ligne à voie métrique Lugano – Ponte Tresa, exploitée par FLP.
