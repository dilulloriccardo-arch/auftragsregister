Description

ET01 Energieversorgung (EV)
Der Teilauftrag ET01 umfasst die Lieferung, Montage und Inbetriebnahme der zentralen Energieversorgungsanlagen für das Projekt ErVeL2. Dazu gehören die wesentlichen Komponenten der Mittelspannungsversorgung sowie deren Anbindung an die übergeordneten Systeme.

Dies beinhaltet unter anderem:
- Transformatoren (Trafos)
- Mittelspannungsschaltanlagen
- Mittelspannungs-/Niederpannungsverkabelung
- Netzleittechnik
- Einrichtungen zur Synchronisation der Turbogruppen (Generatoren)
