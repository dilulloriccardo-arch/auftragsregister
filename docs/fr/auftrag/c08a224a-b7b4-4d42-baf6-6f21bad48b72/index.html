Motifs de l'adjudication

Im Preisvergleich ist die Gebr. Hermann AG, Rietstrasse 5, 8890 Flums, die preisgünstigste Anbieterin. Aufgrund der Zuschlagskriterien des Gesamtpakets steht dieselbe Unternehmung im ersten Rang. Sie hat in der Kriterien-Bewertung auch die höchste Punktzahl (398 von 400 Punkten) erreicht, was im Offenen Verfahren letztlich massgebend ist für die Vergabe.

Description

Die Lindenstrasse wird umfangreich saniert. Ausbau, Sanierung, Ersatz Asphaltbelag und Planie, Teilersatz Fundation, Pflästerung, Sanierung Entwässerung, Werkleitungsbau Hauptkubaturen: - Belagsabbruch 500 to - Grabenaushub 520 m3 - Kanalisationsleitungen 180 m´ - Werkleitungen 1600 m´ - Randabschlüsse 290 m’ - Pflästerung 700 m2 - Fundation 820 m3 - Planie 2050 m2 - Belag 440 to
