Livraison, mise en service et migration de l’Oracle Database Appliance

Acheteur public
Amt für Informatik des Kantons Schwyz
23.11.2026, 23 h 59Délai de remise
Documents et publication officielle sur simap.chAjouter le délai à l’agendaSignaler une erreur

Description

L’objet du marché comprend :
- la livraison, l’installation et la mise en état de fonctionnement de 3 systèmes Oracle Database Appliance X11 HA avec Oracle Premium Support pour le système d’exploitation et le matériel ainsi que pour Oracle System Software (pour une durée de 5 ans dans chaque cas), y compris les raccordements réseau et le câblage,
- la migration des bases de données,
- les prestations d’assistance pour la sauvegarde, la restauration et la supervision.

Les prestations d’assistance à l’exploitation constituent une option du marché.
