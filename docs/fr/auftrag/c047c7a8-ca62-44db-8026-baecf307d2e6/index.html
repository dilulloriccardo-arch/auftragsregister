Description

Das Einzugsgebiet des Rotbachs hat ein grosses Schwemmholzpotential. Die Ereignisse der letzten Jahre zeigten, dass die bestehenden Bauwerke (z. B. Geschiebesammler ausgangs Rotbachtobel) ungenügend sind, um einen Einfluss auf Verklausungsszenarien ≥ HQ30 zu haben. Damit das Risiko einer Verklausung unterhalb des Rotbachtobels reduziert werden kann und ein störungsfreier Betrieb der militärischen Anlagen sichergestellt werden kann, ist die Realisierung eines Schwemmholzrückhalts zwingend notwendig.
