Description

La commessa concerne la fornitura del materiale per la segnaletica stradale su strade nazionali: - attenuatori d’urto completi sistema EURO-NEAT 2C per barriere di sicurezza; - segnali triangolari pieghevoli tipo TRIOPAN (min. R2A); - segnali e tavole complementari ad altissima riflettenza R3; - colonnette direttrici colore bianco/nero con catarifrangente tipo C; - dispositivi di guida; - segnalatori di sicurezza con basamenti; - coni riflettenti R2A; - lampade; - batterie per alimentazione lampade; - strutture portanti per segnali; - accessori diversi; - cartelli di grandi dimensioni ad altissima riflettenza R3; - strutture portanti per cartelli di grandi dimensioni (sostegni reticolari).
