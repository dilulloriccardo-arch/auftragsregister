Description

TransN désire renouveler ses licences Microsoft 365 Enterprise EAS.

Il est important de relever que l’objet porte sur un renouvellement de l’abonnement EAS Enterprise Agreement Subscription existant.

TransN souhaite donc faire appel aux fournisseurs pour l’acquisition, la modification, le renouvellement et la révocation de licences Microsoft 365 sur la base du « tenant » existant des Transports Publics Neuchâtelois SA.
