Motifs du choix

Description

Die BVZ Holding AG plant für ihre Tochtergesellschaften und der Matterhorn Gotthard Infrastruktur AG ein Security Operation Center (SOC) mit dazugehörigen Leistungen einzuführen. Im Vorfeld der Ausschreibung hat Matterhorn Gotthard Bahn ein SOC Grobkonzept erstellt, welches als Grundlage für die Einführung dienen soll.
