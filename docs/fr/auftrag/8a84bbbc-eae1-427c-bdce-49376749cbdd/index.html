Description

Für die Sicherstellung des Aus- und Weiterbildungsangebots werden ein Grossteil der organisatorischen und administrativen Tätigkeiten durch eine externe Anbieterin erbracht.

Die Leistungen werden für den Zeitraum 1.7.2027 – 30.06.2032 mit Option auf Verlängerung bis 30.06.2034 ausgeschrieben.
