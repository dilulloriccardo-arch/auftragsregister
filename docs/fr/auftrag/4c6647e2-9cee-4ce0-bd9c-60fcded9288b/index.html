Description

L’objet du présent marché consiste en la réalisation de travaux en lien avec la transformation du bâtiment administratif du Bachet. Ces travaux concernent les principaux objets listés ci-dessous :
- Installation de chantier spécifiques aux travaux de l’Entrepreneur ;
- Travaux de dépose de façade existante ;
- Travaux de façade métallique du restaurant.

Pour plus de détails sur les conditions d’organisation et le descriptif complet du chantier dans sa globalité ainsi que du marché en lui-même, merci de vous référer aux documents d’appel d’offres.
