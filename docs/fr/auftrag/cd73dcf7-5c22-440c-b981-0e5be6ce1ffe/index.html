Motivation de l'adjudicateur

Das berücksichtigte Angebot hat aufgrund seiner Merkmale und Vorteile die meisten Nutzwertpunkte (NWP) erzielt. Die Zuschlagskriterien (ZK) wurden wie folgt bewertet: ZK 1 Preis: 350 von 350 NWP ZK 2 Referenzauftrag Anbieter: 130 von 150 NWP Total: 480 von 500 NWP Die Anbietenden können sich unabhängig von einer allfälligen Beschwerde für ein informelles Debriefing bei der Kantonalen Fachstelle für öffentliche Beschaffungen melden.

Description

Bedachungsarbeiten für einen Erweiterungsbau und einen Sanierungsbau (Sanierungsbau inkl. Rückbau Dach) für das Primarschulhause Christoph Merian.
