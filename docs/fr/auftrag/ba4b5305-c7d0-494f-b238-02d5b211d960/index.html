Description

Le maître d'ouvrage souhaite s'attacher les services d'un groupement pluridisciplinaire afin de mener la première phase des études d'avant-projet pour les infrastructures de tramway tangentiel (Lancy Bachet - Aéroport) et axe ouest (Lancy Pont-Rouge - Onex). Les prestations attendues sont détaillées dans le cahier des charges (Pièce K2.1 du dossier d'appel d'offre).

Publication officielle : Voir le projet 39812 sur simap.ch — seule la publication qui y figure fait foi.
