Description

Le projet « Site Internet blw.admin.ch » a pour objet de moderniser le site Internet de l’OFAG et de le convertir au nouveau service standard de la Confédération (CMS). La refonte du site Internet actuel de l’OFAG www.blw.admin.ch est en cours de réalisation, avec une mise en ligne prévue pour fin 2024. Après la mise en ligne des contenus sur le site Internet de l’OFAG, les deux sites Internet https://rapportagricole.ch et https://www.donnees-agri-marche.ch (regroupés sous le nom de « Données agricoles ») devront également y être intégrés.

Le projet « Site Internet blw.admin.ch » devra uniformiser l’expérience utilisateur sur tout le site Internet blw.admin.ch et réunir en un même lieu toutes les informations publiées par l’OFAG, accessibles de manière conviviale.
