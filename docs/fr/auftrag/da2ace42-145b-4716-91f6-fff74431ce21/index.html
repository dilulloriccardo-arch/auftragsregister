Description

Stadtwerk Winterthur evaluiert ein partnerschaftlich agierendes Unternehmen für das Applikationsmanagement inkl. einem adäquaten betrieblichen «Managed Service», um den effizienten und kostengünstigen Betrieb sowie die Weiterentwicklung für das bestehende SAP-Umsystem «d.evelop documents» der Firma d.velop (nachstehend Softwareherstellerin genannt) sicherstellen zu können.

Stadtwerk Winterthur evaluiert ein fachlich kompetentes und von der d.velop autorisiertes Unternehmen für den Bezug und Verwaltung von Softwarelizenzen, Wartung sowie Softwareservices (Subskriptionen) und für den 3rd Level Supportprozess (Ticketing).
