Description

Lot 1

- Koordination mit Endkunden zum Umbau und Planung der Arbeiten im zugewiesenen Rolloutgebiet
- Aufnahme der Ist Situation.
- Rundsteuerempfänger demontieren und durch ein Gateway ersetzen, Steuerdrähte auf das Gateway verdrahten. Gegebenenfalls Anpassung der Steuerdraht Legende und fachgerechter Rückbau von nicht verwendeten Steuerdrähten.
- Tausch von bestehenden Stromzählern durch intelligente Messgeräte (iMG)
- LWL Verbindung G-OTO zu Gateway erstellen
- Montage Datenkabel von Gateway auf alle installierten iMG
- Konfiguration und Inbetriebnahme der Geräte
- Datenaufnahme der Installation

Lot 2

Die Arbeiten des Los 2 sollen vorgängig oder zeitgleich zu den Arbeiten des Los 1 erfolgen.
- Koordination mit Endkunden zum Umbau und Planung der Arbeiten im zugewiesenen Rolloutgebiet
- Installation der M-Bus Kabelverbindungen von Spartenzähler inklusive der Erstellung der notwendigen Leerrohranlage
