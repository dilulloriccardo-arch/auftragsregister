Description

Le présent appel d’offres public vise la conclusion par l’Hospice général (ci-après : l’Hospice ou Hg), d’un mandat avec un seul prestataire pour des prestations de recrutement, de formation, de placement et d’accompagnement des bénéficiaires dans leur formation dans le domaine des métiers de la sécurité.
