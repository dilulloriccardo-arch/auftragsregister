Motifs de l’adjudication

Das Angebot der ARGE Kreis Wasserbau AG / Tschanen AG, Weinfelden, zum Gesamtpreis von
Fr. 1'982'408.15 (inkl. MWSt) erweist sich in der Gesamtbeurteilung als das Vorteilhafteste. Es ist preislich das günstigste Angebot.
