Description

Die vorliegende Ausschreibung umfasst die Photovoltaikanlage auf den Dächern der AGZ, BW1 & BW2 in Adligenswil. Die Anlagen sollen aerodynamisch auf die bestehenden Flachdächer aufgebaut werden (Das bestehende Substrat wird bauseits abgesaugt und unter Koordination des PV-Unternehmers neues Kies aufgebracht).
