Description

Das Institut für Intensivmedizin ersetzt seine bestehenden Beatmungsgeräte. Es sollen sowohl stationäre Langzeitbeatmungsgeräte (Bedside) , sowie Notfallbeatmungsgeräte Transport, sowie Notfallbeatmungsgeräte-MR evaluiert werden. Es wird eine möglichst einheitliche Produkte- und Bedienphilosphie über den gesamten Gerätepark angestrebt.
