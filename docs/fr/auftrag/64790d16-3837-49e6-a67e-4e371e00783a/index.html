Motifs de l'adjudication

Das Angebot der Zuschlagsempfängerin erfüllte alle formellen Anforderungen und überzeugt durch seine klare Darstellung aller Leistungsmerkmale. Insgesamt ist dieses Angebot das vorteilhafteste und hat am meisten Punkte erhalten. Ausschlaggebend waren nebst dem Zuschlagskriterium "Preis" auch qualitative Kriterien.

Description

Les Chemins de fer fédéraux suisses CFF SA exploitent leurs propres réseaux de données dans toute la Suisse dont les composants sont montés dans des armoires de 19 pouces. Pour l'extension du réseau de données, les CFF auront besoin d'un plus grand nombre de ces armoires dans les années à venir.
