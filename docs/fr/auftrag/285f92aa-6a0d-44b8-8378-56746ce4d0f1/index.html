Motifs du choix

Dans le cadre de la présente mise en concurrence, plus précisément pour le lot n°2 du marché, le pouvoir adjudicateur n'a reçu qu'une seule et unique offre. Le marché est donc attribué à l'unique soumissionnaire.

Description

Le 2ème lot concerne la partie du parc injecteurs utilisés dans les services d'imageries médicales utilisant une IRM. Ce lot concerne jusqu'à 3 dispositifs, incluant les consommables associés à leurs utilisations.
