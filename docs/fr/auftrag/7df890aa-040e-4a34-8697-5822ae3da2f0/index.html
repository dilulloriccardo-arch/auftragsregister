Description

Beschaffung eines Reagenzienverwaltungssystems für den Einsatz im Laborumfeld.

Gegenstand der Ausschreibung ist die Lieferung, Implementierung und Inbetriebnahme einer Softwarelösung zur Verwaltung von Reagenzien inklusive Lizenzierung.
