Motifs de l’adjudication

Lot 1

Den Zuschlag erhält die Firma Cognizone S.A., da der Anbieter ein qualitatives Angebot zu einem wettbewerbsfähigen Preis eingereicht hat. Insbesondere die aufgezeigte Erfahrung und die Präsentation der Lösung konnte das Evaluationsteam überzeugen.

Lot 2

Den Zuschlag erhalten die Firmen Liip AG, Zazuko GmbH und Adnovum AG, da sie mit guten Konzepten, nachvollziehbarer Erfahrung, guten Lösungspräsentationen bei gleichzeitig kompetitivem Preis überzeugen konnten.
Den Zuschlag für das Teilprojekt opendata.swiss aus dem Leistungsgegenstand «Entwicklung Linked Data Applikation» erhält die Zazuko GmbH, da sie die überzeugendste Lösung bei gleichzeitig überzeugendster Erfahrung mit Open-Source präsentiert hat.

Description

Lot 1

Les prestations acquises dans le cadre de ce lot constituent la base pour l’exploitation de l’infrastructure Linked Data de la Confédération. Les prestations visent à mettre à disposition l’ensemble de l’infrastructure nécessaire pour fournir aux utilisateurs internes et externes les solutions dans le domaine des Linked Data.
Un adjudicataire est prévu pour le lot 1.
Il est attendu du mandataire du lot 1 qu’il collabore avec les partenaires de développement de la Confédération du lot 2 afin de garantir une exploitation sans anicroche.

Lot 2

Les prestations acquises dans ce lot visent le développement continu et le maintien en condition opérationnelle des applications existantes basées sur les technologies Linked Data ainsi que le développement de nouvelles applications dans le cadre de projets spécifiques.
Trois adjudicataires sont prévus pour le lot 2.
Il est attendu des mandataires du lot 2 qu’ils collaborent avec le partenaire d’exploitation de la Confédération du lot 1 afin de garantir une exploitation sans anicroche.

Pour des raisons de transparence, nous tenons à préciser que le développement d’opendata.swiss est aussi attribué dans le cadre du présent appel d’offres (lot 2). Les informations concernant l’objet des prestations peuvent être consultées dans le cahier des charges et les suppléments [B2] et [B4].
