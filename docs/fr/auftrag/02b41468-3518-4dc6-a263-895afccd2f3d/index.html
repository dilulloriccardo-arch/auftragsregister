Motifs de l'adjudication

Den Zuschlag erhält die Firma Cognizone S.A., da der Anbieter ein qualitatives Angebot zu einem wettbewerbsfähigen Preis eingereicht hat. Insbesondere die aufgezeigte Erfahrung und die Präsentation der Lösung konnte das Evaluationsteam überzeugen.

Description

Les prestations acquises dans le cadre de ce lot constituent la base pour l’exploitation de l’infrastructure Linked Data de la Confédération. Les prestations visent à mettre à disposition l’ensemble de l’infrastructure nécessaire pour fournir aux utilisateurs internes et externes les solutions dans le domaine des Linked Data. Un adjudicataire est prévu pour le lot 1. Il est attendu du mandataire du lot 1 qu’il collabore avec les partenaires de développement de la Confédération du lot 2 afin de garantir une exploitation sans anicroche.
