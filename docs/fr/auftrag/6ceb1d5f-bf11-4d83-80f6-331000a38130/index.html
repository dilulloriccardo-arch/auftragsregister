Description

Le FSR est propriétaire de 220 emplacements d’affichage (ci-après dénommés emplacements d’affichage du FSR) situés le long des routes cantonales dans toutes les régions de Suisse. Seuls les messages de prévention destinés aux automobilistes, aux motocyclistes et/ou aux cyclistes motorisés et non motorisés peuvent être placardés sur les emplacements d’affichage du FSR, ce qui les distingue des emplacements d’affichage traditionnels.

Par le présent appel d’offres, le FSR recherche un prestataire externe pour gérer les emplacements d’affichage du FSR sur la voie publique pendant trois ans dans les trois régions de Suisse. Une prolongation facultative demeure réservée. La gestion comprend notamment la pose d’affiches aux emplacements d’affichage du FSR avec le matériel de campagne correspondant, en règle générale un changement de sujet plusieurs fois par an (l’objectif est de réaliser 2 à 3 campagnes), ainsi que l’entretien, la remise en état et le nettoyage des 220 emplacements d’affichage du FSR actuels, ainsi que la création ou l’extension d’emplacements d’affichage du FSR. En outre, les sites des emplacements d’affichage du FSR doivent être sécurisés dans le cadre de discussions avec les autorités chargées de l’octroi des autorisations. Une planification de l’occupation est en outre établie en concertation avec le FSR.
