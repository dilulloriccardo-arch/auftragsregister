Description

Die Werke am Zürichsee beabsichtigen den Bau einer Fernwärmezentrale und eines Fernwärmenetzes in der Gemeinde Zollikon. Die Energiezentrale mit den Abmessungen 30.76m x 26.60m wird in Massivbauweise erstellt. Für den unterirdischen Bereich ist eine Baugrube zu erstellen.
