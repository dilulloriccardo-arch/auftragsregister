Description

In der kantonalen Verwaltung wird VMware Software in verschiedenen Ausprägungen als Plattform Software für den Infrastrukturbetrieb seit seit längerem eingesetzt. Die Software stellt in der Basisinfrastruktur auf unterschiedlichen Plattformen virtuelle Server und Kubernetes Cluster (Tanzu) zur Verfügung. Die Lizenzierung der einen Plattform (VM Server) muss per 1.1.2025 erneuert werden, Teile der Lizenzierung der anderen Plattfom (Tanzu) im April 2025, Beide für jeweils 1 Jahr. Mit dieser Ausschreibung sucht die Vergabestelle einen Partner für die Lieferung der Lizenzen VMware/Broadcom für die Periode von 1 Jahr.
