Description

Ausgangslage / Projektbeschrieb
• Die Axpo Grid AG beabsichtigt die Beschaffung von vier Regulierbare Er-

dungsdrosseln (Löschdrosseln) für die Unterwerke Löntsch (2 Stk./480 A)
und Niederurnen (2 Stk./600 A) Die technische Spezifikation ist für beide
Standorte/Produkte unterschiedlich und wird im spezifischen Dokument be-
schrieben.

Die ausgeschriebenen Leistungen umfassen folgende Hauptarbeiten:
• Auslegung, Herstellung, Prüfungen, Lieferung von Regulierbare Erdungs-

drosseln (Löschdrosseln) gemäss Spezifikationen EE02546_R0 (UW Nieder-
urnen) und EE02545_R0 (UW Löntsch).

• Lieferung

o Fertigung gemäss Termin, Auslieferungen gemäss Terminplan im
Werkvertrag
