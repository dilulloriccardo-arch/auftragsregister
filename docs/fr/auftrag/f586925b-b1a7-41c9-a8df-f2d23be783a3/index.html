Description

Das Projekt "2K5" umfasst die Erweiterung der Kehrichtverwertungsanlage Hagenholz in Zürich um eine dritte Verbrennungslinie (Details dazu siehe Teil B "Projektbeschrieb"). Die vorliegende Ausschreibung BKP 213.9 - Stahlbau 2 umfasst mehrere Teilobjekte im Stahlbau (siehe Beilagen im Teil E): Pos. 91 Ersatz Kranbahn KBU Pos. 92 Dachaufbau KBU Nord Pos. 93 Zentrallager 3 Pos. 94 Passarelle LGZ (Leitstand bis Logistikzentrum)

Publication officielle : Voir le projet 21558 sur simap.ch — seule la publication qui y figure fait foi.
