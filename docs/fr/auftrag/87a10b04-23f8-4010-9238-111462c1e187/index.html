Description

Lot 1

Pour soutenir les équipes DFF (Digital Field Force), des fonctions dans le domaine de l’électricité sont recherchées sur tous les sites de Suisse dans le cadre du lot 1. Les interventions ont lieu en journée, pendant les horaires de bureau habituels. Les fonctions recherchées sont les suivantes:

- Monteur-électricien
- Installateur-électricien
- Monteur auxiliaire
- Technicien Télécom
- Directeur des travaux
- Chef de projet Électricité
- AVOR Senior
- AVOR Junior

Lot 2

Afin de soutenir les équipes d’intervention Télécom dans le tunnel de base du Saint-Gothard (GBT) et le tunnel de base du Ceneri (CBT), le lot recherche deux fonctions dans les domaines de l’électricité et de la mécanique. Les interventions ont lieu majoritairement de nuit.

Les fonctions recherchées sont les suivantes:

- Monteur-électricien
- Installateur-électricien
- Monteur auxiliaire
- Mécanicien
- Mécanicien-électricien ou automaticien
- Polymécanicien
