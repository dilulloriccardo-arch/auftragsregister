Description

Das Kantonsstrassenprojekt sieht vor, oberhalb des «Einlenkers Hofstrasse» eine behindertengerechte Bushaltestelle als Fahrbahnhaltestelle auszubilden. Weiter soll auf der Nordseite der Gehweg bis zur Bushaltestelle verlängert werden. Auf der Südseite «Ausfahrt Brendenweg» wird die Stützmauer in Lage und Höhe angepasst, sodass sie keine Sichtbehinderung mehr darstellt. Für Fahrbahn und Strasse ist ein Vollausbau vorgesehen.
