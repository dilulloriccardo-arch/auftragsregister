Description

Als Ergänzung zu unseren Festangestellten im Bereich PRM Services, benötigt die Flughafen Zürich AG eine grössere Anzahl an Temporärmitarbeitenden für die anfallenden Tätigkeiten. Mittels dieser Ausschreibung soll ein geeignete Personaldienstleister evaluiert werden.
