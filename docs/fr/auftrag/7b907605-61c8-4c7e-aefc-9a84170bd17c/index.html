Description

1. Objektbeschrieb Im Rahmen der Sanierung der Dächer und weiterer technischer Anlagen an den Gemeindeliegenschaften der Gemeinde Mandach wurde die Installation von PV-Anlagen in verschiedenen Varianten geprüft und eine Lösung evaluiert, welche hiermit zu Ausführung ausgeschrieben wird. Neben einer vollflächigen und einer Minimal-Variante ist diese Lösung das ausgewogene Mittel. Eine allfällige Unternehmervariante muss innerhalb dieser Rahmenbedingung liegen. 2. Absicht Die Bauherrschaft Einwohnergemeinde Mandach will auf den beiden Gebäuden Schulhaus (SH) und Turnhalle/Kanzlei (TU) im eine dachintegrierte Photovoltaikanlage installieren. Die Dachflächen Schulhaus werden vollflächig belegt. Die Dachflächen Turnhalle Nord vollflächig, Turnhalle süd der obere Teil, gem Layout/Plänen. Die ganze Anlage inkl Meldewesen wird administrativ in zwei Teile aufgeteilt SH und TU. Aus diesem Grund werden sind separate Leistungsverzeichnisse auszufüllen. Gemeinsame Positionen, wie Wechselrichter und Projektleitung etc werden mit folgendem Kostenteiler aufgeschlüsselt: ● Schulhaus (SH): Faktor 0.45 ● Turnhalle/Kanzlei (TU): Faktor 0.55 Technisch wird die Anlage als eine einzige realisiert mit 1 Netzanschlusspunkt, 1 Abnahmekontrolle / Beglaubigung etc.
