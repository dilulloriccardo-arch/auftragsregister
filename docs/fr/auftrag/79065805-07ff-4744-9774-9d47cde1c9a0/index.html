Description

Für den Fernwärmeverbund in der Stadt Wil wird das Verteilnetz im Weidliquartier gebaut. Gegenstand der Ausschreibung ist die Lieferung und Montage von Fernwärmeleitungen im Bereich Weidliquartier inkl. Hausanschlüsse und Innenausbau des Kammerbauwerks. Diese Ausschreibung umfasst erdverlegte Fernwärmeleitungen mit Nennweiten von DN25 bis DN150 (Trasselänge total: 930m).
