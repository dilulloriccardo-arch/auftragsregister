Description

En trafic grandes lignes et en trafic régional, tous les tubes fluorescents sont remplacés par des tubes LED.

- Plusieurs versions différentes sont présentes. Le remplacement concerne les modèles de type T5 / T8.

- Le soumissionnaire doit également proposer les supports pour les lampes. (remplacement à 100 %)
- Les ponts de câbles ne font pas partie de ce marché.
