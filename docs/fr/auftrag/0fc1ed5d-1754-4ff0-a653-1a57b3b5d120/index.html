Description

Romande Energie exploite déjà en production la solution de base de données cloud Snowflake (version Business Critical). Le business model de cette solution se base sur une facturation à l’utilisation, via la consommation de crédits achetés à l’avance.
Le stock de crédits en possession de Romande Energie arrivera à zéro courant septembre 2025. L’objet de cet appel d’offres est de renouveler le contrat d’achat de crédits pour une période minimale de 3 ans.

Publication officielle : projet 19543 sur simap.ch – seule cette publication fait foi.
