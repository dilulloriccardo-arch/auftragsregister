Description

Le marché objet de cet appel d’offres prévoit d’optimiser le réglage des installations techniques CVCS
des gymnases propriété de l’Etat de Vaud. Ce marché consistera à analyser les consommations de 8 gymnases, identifier les potentiels et les dérives et optimiser les réglages des installations techniques CVCS pour mener à des réductions effectives des consommations de chaleur et
d’électricité.
