ewzWHH/BGH, phase 2, BKP 90 : mobilier

Elektrizitätswerk der Stadt Zürich (ewz)

Description

Dans le cadre du projet « ewz-Areal Herdern », phase 2, bâtiment BGH, le mobilier destiné aux différents espaces du bâtiment fait l'objet d'un appel d'offres. L'appel d'offres comprend trois lots :

Lot 1 : Mobilier standard pour les pièces annexes

Lot 2 : Mobilier standard pour les pièces principales

Lot 3 : mobilier fabriqué sur mesure pour l’intérieur

Ce projet prévoit l’acquisition de mobilier destiné à différents espaces tels que les bureaux, les salles de réunion et de conférence, les espaces de restauration, les espaces de détente, les vestiaires, les locaux sociaux et les pièces annexes. Outre le design et la fonctionnalité, l’appel d’offres accorde une importance particulière à la qualité, à la durabilité, à la réparabilité ainsi qu’à une conception durable et respectueuse de l’environnement.
