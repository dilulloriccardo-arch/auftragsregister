Motivation de l'adjudicateur

Die Zuschlagsempfängerin hat das preisgünstigste Angebot offeriert, bezüglich den weiteren Zuschlagskriterien «Kapazität/Termin (Fachkompetenz)» und «Qualität (Kosten)» das beste Ergebnis erreicht, bei der Ausbildung von Lernenden keine Punkte erzielt. Die Zuschlagsempfängerin erreichte damit in der Auswertung die höchste Punktzahl, weshalb ihr der Zuschlag zu erteilen ist.

Description

Liefern und Montieren von Fenstern aus Holz (Denkmalpflege), inkl. Demontage/Entsorgung (Asbestkitt) und denkmalpflegerische Sanierung (Asbestkittsanierung, Kittersatz, Malerarbeiten) von bestehenden Fenstern an EG-Nordfassade.
