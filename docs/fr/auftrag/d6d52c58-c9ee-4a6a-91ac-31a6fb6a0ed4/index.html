Motivation de l'adjudicateur

Das berücksichtigte Angebot hat aufgrund seiner Merkmale und Vorteile die meisten Nutzwertpunkte (NWP) erzielt. Die Zuschlagskriterien (ZK) wurden wie folgt bewertet: ZK 1 Preis: 200 von 200 NWP ZK 2 Prasxistest: 182.86 von 200 NWP ZK 3 Kann-Kriterien: 90 von 100 NWP Total: 472.86 von 500 NWP Die Anbietenden können sich unabhängig von einer allfälligen Beschwerde für ein informelles Debriefing bei der Kantonalen Fachstelle für öffentliche Beschaffungen melden.
