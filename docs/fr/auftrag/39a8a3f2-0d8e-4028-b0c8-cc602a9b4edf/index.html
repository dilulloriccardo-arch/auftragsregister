Description

Die vorliegende Submission umfasst die Lieferung von neuen Komponenten und Entsorgung von alten Komponenten sowie entsprechende Arbeiten für die Sanierung der Transformatorenstation (TS) Altwiesen in Würenlos. Die aktuelle TS verfügt über eine Mittelspannungsanlage (MSA) vom Typ Huser+Peyer AG (WEVA), zwei Transformatoren mit einer Leistung von 630 kVA und eine Niederspannungsverteilung (NSV) vom Typ Stationenbau. Die Trafostation soll erneuert werden. In END-Ausführung mit einer luftisolierten 4-feldrigen Mittelspannungsschaltanlage, zwei Öltransformatoren (bereits in TS vorhanden), zwei Überlagerungstransformatoren (Lieferung TBW) und einer Niederspannungsverteilung. Die zwei bestehenden Mittelspannungsnetzkabel werden an die neue Anlage angeschlossen. Die bestehenden Niederspannungskabel werden an die neue Niederspannungsverteilung angeschlossen. Die Primär- und Sekundärverkabelung der bestehenden Transformatoren wird neu erstellt. Die alten Anlagenteile werden fachgerecht demontiert und entsorgt.
