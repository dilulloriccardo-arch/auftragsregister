Description

Lieferung und Installation eines LC-HRMS Systems zum Nachweis von bekannten und unbekannten, niedermolekularen, organischen Substanzen. Das System soll in den Routinebetrieb eingebunden werden und dementsprechend robust und einfach zu bedienen sein.
