Motifs de l'adjudication

Offre représentant le meilleur rapport entre les différents critères d'adjudication.

Description

La République et Canton de Genève, pour le compte de l'Office cantonal de la détention, souhaite acquérir des téléviseurs, conformément aux exigences mentionnées dans le cahier des charges et dans le dossier d'appel d'offres. La Centrale commune d'achats est chargée de lancer et de mener la présente procédure d'appel d'offres sur invitation.

Publication officielle : Voir le projet 35077 sur simap.ch — seule la publication qui y figure fait foi.
