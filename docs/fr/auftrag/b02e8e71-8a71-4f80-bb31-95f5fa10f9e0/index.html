Description

CFF Télécom, au sein de la division Infrastructure, exploite une installation de communication pour assurer la sécurité des opérations ferroviaires. Cette infrastructure comprend des haut-parleurs sur les quais, contrôlés via des amplificateurs audios pour des annonces manuelles et automatisées. Dans le cadre de ce système de signalisation, des convertisseurs sont utilisés pour adapter les signaux aux conditions techniques (par exemple, IP en analogique).

Le service dʼannonces par haut-parleurs est essentiel dans le secteur ferroviaire pour lʼinformation aux clients ou, en cas d'incidents tels quʼune évacuation ou un accident pour diffuser des annonces spécifiques. Actuellement, environ 1'300 convertisseurs sont en service sur environ 800 sites à travers la Suisse.

Les CFF recherchent un fournisseur capable de proposer une nouvelle solution pour les convertisseurs mentionnés. Les services tels que la garantie, la réparation, le développement de logiciels/firmwares, la surveillance, la configuration, la gestion, le traitement, etc., doivent être inclus dans la solution matérielle existante pour offrir une solution complète, économique, efficace et de qualité.
