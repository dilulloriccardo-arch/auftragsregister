Description

Les prestations de transport faisant l’objet du présent appel d’offres concernent deux sites du ZSHKK dans le canton de Berne, pour la période contractuelle allant du 01.08.2027 au 31.07.2032 (5 ans).

Les prestations de transport concernent les sites suivants :
- Site de Landorf, Köniz
- Site de Schlössli, Kehrsatz

Pour ces deux sites, le ZSHKK recherche une entreprise de transport fiable pour assurer les prestations suivantes :
- Transport des élèves
- Coordination des transports et des interventions
