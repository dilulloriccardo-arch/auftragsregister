Description

Dans le cadre du projet de rénovation du Centre de Maintenance de Lugano-Noranco, une restructuration totale et un agrandissement du bâtiment administratif sont prévus.

L'objet du présent marché concerne les travaux de revêtement des façades.

Les façades complètes avec isolation se distinguent par 2 couches.

Façade 1 :
- Cassettes en tôle d'acier type Montana AG ;
- Isolation posée dans les cassettes, Swisspor LAMBDA ;
- Sous-construction ;
- Habillage en tôle d'aluminium type Montana AG Swiss Panel - SP45/150.

Façade 2 :
- Isolation appliquée au mur existant, Swisspor LAMBDA Vento Premium ;
- Substructure ;
- Type de revêtement en tôle d'aluminium, tôle trapézoïdale Montana AG Swiss Panel - SP45/150.
