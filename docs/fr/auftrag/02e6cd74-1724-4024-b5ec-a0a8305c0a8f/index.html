Mobilier EPFL 2027-2031

Acheteur public
EPFL - VPF Achats
27.11.2026, 16 h 00Délai de remise

Description

Le présent appel d’offres a pour but la fourniture de meubles et accessoires afin de couvrir l’ensemble des besoins mobiliers de l’EPFL pour les lieux cités ci-dessous :

▪ les espaces de travail ;
▪ les salles de cours :
▪ les salles de conférences ;
▪ les salles de séminaires ou événements ;
▪ les espaces d’études ;
▪ les espaces d’attente ;
▪ les espaces collaboratifs ;
▪ les cafétérias ;
▪ les terrasses extérieures.

Les contrats cadres avec les entreprises adjudicataires, qui résulteront de la procédure, permettront la continuité de service auprès des utilisatrices et utilisateurs de l’EPFL.

Les aménagements de l’EPFL sont composés en majorité de meubles et accessoires standards référencés dans un catalogue interne.

Ces éléments sont répartis en 14 lots, décrits dans le cahier des charges et détaillés dans les annexes descriptives B à O.
