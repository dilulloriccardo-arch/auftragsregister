Description

Le projet RENOFGB consiste à remplacer le groupe de production existant par deux nouveaux groupes.
Le Maître de l'ouvrage souhaite remplacer la machine existante de 40 MVA par deux nouvelles machines de 22 MVA absorbant le même débit que l'ancien groupe. Les nouveaux groupes recevront les eaux de la Dranse d'Entremont accumulées dans le barrage des Toules par la galerie d'amenée et la conduite forcée existante.
Les turbines actuellement projetées sont de type Pelton à axe horizontal à triple-jets.
Le présent appel d'offre concerne les travaux de génie civil pour les transformations dans l'usine FGB liées au remplacement du groupe existant par deux nouveaux groupes NG1 et NG2.
