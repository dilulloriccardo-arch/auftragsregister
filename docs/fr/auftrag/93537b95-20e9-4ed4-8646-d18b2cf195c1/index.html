Description

Das Kommandogebäude ist ein Stahlbeton-Skelettbau aus dem Jahre 2000 und soll um zwei Geschosse aufgestockt (ET1) und die bestehenden Geschosse (ET3) saniert werden. Das Energiekonzept wurde grundlegend überarbeitet. Für die Gebäudetechnik wird ein zusätzlicher Raum im Innenhof geschaffen. Aufgrund der zentralen Lage im Innenhof können die gebäudetechnischen Medien effizient innerhalb des Gebäudes verteilt werden. Das zurzeit unbefriedigende Raumklima kann im Zuge der Planung einer mechanischen Gebäudelüftung mit weiteren begleitenden Massnahmen verbessert werden. In dieser Submission sind sämtlichen neuen Installationen für das Gewerk Lüftung mit folgenden Kennzahlen enthalten: − Lüftungsanlage Nebenräume 1‘550 m3/h − L01 - LA Restaurant / Leseraum 5’800 m3/h − L02 - LA Speisesaal / Aufenthalt 4’500 m3/h − Zuluftanlage L07 - LA Küche + Abwaschen 6‘200 m3/h − Abluftanlage L08 - LA Küche + Abwaschen 7‘100 m3/h − Einfache Klimaanlage Büro 7‘510 m3/h − Total Luftmenge 32’660 m3/h
