Motivation de l'adjudicateur

Unter Berücksichtigung der im Vorfeld festgelegten Kriterien und deren Gewichtung hat die Firma E. Weber & Cie AG (Webstar) kumuliert bei den qualitativen und insbesondere beim preislichen Kriterium den höchsten Erfüllungsgrad erreicht.

Description

Die Logistikbasis der Armee (LBA) ist für die Belieferung von verschiedenem Einweggeschirr (Besteck: Gabel, Messer, Löffel, Kaffeelöffel / Isolierbecher / Suppenschalen / Teller) zugunsten der Schweizer Armee verantwortlich. Damit die LBA dieser Verantwortung gerecht werden kann, soll die Versorgung von Besteck zugunsten des Bedürfnisträgers sichergestellt werden.
