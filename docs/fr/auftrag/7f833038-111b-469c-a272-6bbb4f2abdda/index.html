Description

Bestehende Unterlagsböden instand stellen, teilweise neu Flüssigkunststoff beschichten. Neue Unterlagsböden ohne FBH auf Beton- und Holzdecken, teilweise mit Wärme- und Trittschalldämmung. Hartbetonböden im Verbund. Ausgleichsschichten unter Kühlzellenböden. Beton- und Unterlagsböden oleophobieren.

Umfang bzw. Menge:
Bestehende Unterlagsböden instand stellen: ca. 1'200 m2
Neue Unterlagsböden erstellen: ca. 1’550 m2
Hartbetonböden in Verbund: ca. 650 m2
Flüssigkunststoffbeschichtungen: ca. 340 m2
Oleophobierungen: ca. 1'600 m2
