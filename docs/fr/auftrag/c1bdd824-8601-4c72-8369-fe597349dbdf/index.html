Description

- Sanierung der bestehenden Fahrbahn mit Neuerstellung von Trottoiren und Strassenbeleuchtung.

- Teilweise neue Linienführung und Neubau Strassenabschnitt «Grundstückerschliessung» zur Erschliessung Parzelle 3308 und Abschnitt «Zufahrt Sportplatzareal». Rückbau Strassenabschnitt im Bereich der neuen Linienführung.

- Erstellung von Versickerungsmulden für die neue Strassenentwässerung.
