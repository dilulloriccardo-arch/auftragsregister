Description

Die Gemeinde Meilen schreibt den Rückbau der bestehenden Salzsilos sowie den Neubau von zwei Salzsilos inkl. Soleanlage im offenen Verfahren aus. Die Beschaffung ist in vier Grundleistungen und eine Option aufgeteilt: - GL01: Rückbau der bestehenden Salzsilos - GL02: Neubau der Salzsilos inkl. Soleanlage - GL03: Arbeiten für Baubewilligungsverfahren - GL04: Jährliche Zustandskontrollen - OP01: Regiearbeiten
