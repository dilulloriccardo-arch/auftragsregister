Motifs du choix

Ausschlaggebend für die höchste Gesamtpunktzahl der Erstplatzierten war das
Kriterium A (Angebotspreis) und Kriterium B (Zwei Unternehmensreferenzauskünfte).

Die erstplatzierte Anbieterin bietet das vorteilhafteste Angebot und kann durch ihre
Unternehmensreferenz überzeugen.

Description

Gegenstand der vorliegenden Ausschreibung bilden Rohrbauarbeiten der Quartiererschliessung inkl. Hausanschlüsse von ewz Fernwärme, welche im Gebiet Zürich Nord von der Stettbachstrasse bis Dübendorfstrasse anfallen werden.
