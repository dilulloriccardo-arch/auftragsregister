Description

L'appel d'offres porte sur l'élaboration du projet « Projet d'infrastructure intégrale Robert-Durrer-Strasse ». Les prestations de base définies par les normes SIA 103 / 112 (édition 2020) pour les phases 32, 33, 41, 51, 52 et 53 doivent être fournies, ainsi que les prestations spécifiques également énumérées dans le cadre des prestations de base (voir document D). L'ingénieur de projet assure notamment la coordination technique et spécialisée des autres bureaux d'études, d'ingénierie et de spécialistes mandatés par le maître d'ouvrage, en qualité de chef de projet global.
