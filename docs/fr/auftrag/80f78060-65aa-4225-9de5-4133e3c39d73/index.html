Motifs du choix

Description

Ingenieurarbeiten für die Instandsetzung der beiden verankerten Lehnenkonstruktionen Adelboden auf der Hauptstrasse Nr. 8, Schwyz - Sattel.

Objekte:
- Verankerte Bohrpfahlkonstruktion Adelboden mit Auskragung und Durchlass (Obj. 1373-8)
- Talseitig verankerte Rippenkonstruktion Adelboden (Obj. 1372-9)

Ausgeschriebene Phasen:
- Überprüfung / Massnahmenempfehlung
- 32 Massnahmenprojekt
- 41 Ausschreibung
- 51 Ausführungsprojekt
- 52 Realisierung
- 53 Inbetriebnahme und Abschluss
