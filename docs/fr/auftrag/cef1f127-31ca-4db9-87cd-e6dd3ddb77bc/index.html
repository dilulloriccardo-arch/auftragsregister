Description

Le marché mis en concurrence concerne l’accompagnement dans la transformation d’AGP. Le soumissionnaire devra mettre à disposition de l’équipe projet du Rectorat de la HES-SO une ou plusieurs ressources de type business analyst avec un profil senior pour l’accompagner dans la réalisation des projets HarmoNEED et Implémentation de la nouvelle application. Les détails concernant les prestations attendues sont décrits dans le cahier des charges.

Publication officielle : Voir le projet 6306 sur simap.ch — seule la publication qui y figure fait foi.
