Motifs du choix

Die Firma GE Grid (Switzerland) GmbH hat im Rahmen der Bewertung der eingegangenen Angebote anhand der festgelegten Zuschlagskriterien die höchste Gesamtpunktzahl erzielt.

Description

Gegenstand der Ausschreibung ist der Abschluss eines Rahmenvertrages über die Lieferung von 110-kV-GIS-Schaltanlagen dreiphasig gekapselt.

Der Rahmenvertrag umfasst:
3 Schaltanlagen, welche nach Vertragsabschluss verbindlich bestellt werden (Grundauftrag).

Option auf bis zu 3 weitere Schaltanlagen, welche während der Laufzeit des Rahmenvertrages bei Bedarf abgerufen werden können.
