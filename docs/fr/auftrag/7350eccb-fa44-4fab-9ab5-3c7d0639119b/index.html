Motivation de l'adjudicateur

Sämtliche in den Ausschreibungsunterlagen festgelegten Eignungs- und Zuschlagskriterien werden erfüllt. Die angebotenen Leistungen decken die Bedürfnisse der SVA Zürich ab.

Description

Services de sécurité pour les bâtiments de la SVA Zürich : - Surveillance des objets pendant la nuit, les week-ends et les jours fériés - Exploitation d'un centre d'alarme et d'intervention pour les incidents - Exploitation d'un serveur d'alarme pour la réception des messages techniques
