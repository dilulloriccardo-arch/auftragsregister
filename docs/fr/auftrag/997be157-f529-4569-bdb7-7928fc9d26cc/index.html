Description

Die Anfrage richtet sich an ausgewiesene Fachleute, welche für Rohrbauarbeiten für Fernwärmeanlagen (Erdverlegt) in Altstetten Nord eingesetzt werden. Die genauen Anforderungsprofile sind dem Dokument 5 «Technischer Teil» zu entnehmen.
