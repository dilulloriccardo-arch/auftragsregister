Description

L'appel d'offres comprend tous les travaux relatifs à l'exécution de fenêtres, portes et portes automatiques en métal pour le Bâtiment A, la Salle de Concerts/Répétitions, l'Aile Enseignement et Performance 2, ainsi que le Parking souterrain.

Quantités principales :
- Menuiseries vitrées : 1200 m²
- Stores extérieurs : 700 m²
- Sas d'entrée, portes, portes automatiques : 22 pces
- Lucarnes / Lanterneaux : 9 pces
