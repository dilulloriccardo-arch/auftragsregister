Motifs du choix

Description

Die FZAG sucht eine technische Projektleitung beratend zur beratenden Steuerung komplexer Projekte, IT-Infrastrukturaufbau und Einführung von Drittanbieter-Lösungen. Die Berater-Rolle umfasst technische Konzeption, Architekturentwicklung, Koordination von ICT- und Business-Abteilungen sowie technische Beratung als Lead-Engineer.
