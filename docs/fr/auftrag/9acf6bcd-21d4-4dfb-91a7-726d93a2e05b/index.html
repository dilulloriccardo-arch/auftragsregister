Description

Im Bahnhof Jenaz wird am Hausperron ein BehiG-konformer Perron von ca. 300m Nutzlänge erstellt. Dafür muss eine Rund 105m lange Stützmauer erstellt werden. Mit dem Projekt wird die Gleisgeometrie komplett angepasst und die Kreuzungsgleislänge vergrössert. Die Bahnanlage wird durch Abstellgleise ergänzt. Der Gleisunterbau wird komplett erneuert.

Für die technischen Einrichtungen wird ein neues Dienstgebäude erstellt. Die Fahrleitungs-, Niederspannungs- und Sicherungsanlagen werden komplett erneuert. Zusätzlich ist eine Leitmauer zur als Abgrenzung zur Nationalstrasse zu planen.
