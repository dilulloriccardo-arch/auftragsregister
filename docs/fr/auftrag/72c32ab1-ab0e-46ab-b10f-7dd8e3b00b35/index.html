Abgasabsauganlage Thermische Fahrzeuge Halle West

Acheteur public
Rhätische Bahn AG
13.12.2026, 23 h 59Délai de remise
Documents et publication officielle sur simap.chAjouter le délai à l’agendaSignaler une erreur

Description

Es ist geplant in der neuen Werkstatthalle in Landquart eine moderne Abgas-Absauganlage einzubauen, so dass Lokomotiven mit oben- und untenliegenden Auspuffendrohren fachgerecht abgesaugt werden können. Die neue Absauganlage soll dem heutigen Stand der Technik entsprechen und so gestaltet sein, dass eine effiziente Absaugung, aller im Fuhrpark der RhB befindlichen Lokomotiven, Dienstfahrzeuge und Diesel Aggregate auf Wagen abgesaugt werden können.
