Description

Die Bestandsliegenschaften der Sanität Basel wird entkernt und vollumfänglich saniert und umgebaut. Die Liegenschaft wird für die Zeit der Umbauarbeiten leergezogen. Bei den Arbeiten handelt es sich um die Herstellung und Montage von Wohn- und Teeküchen.
