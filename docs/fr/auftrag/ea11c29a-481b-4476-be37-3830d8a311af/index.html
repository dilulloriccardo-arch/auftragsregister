Description

Die Insel Gruppe AG führt mit dieser Publikation, eine öffentliche Submission zur Beschaffung von einem Durchleuchtungs-Röntgen Kombiegerät inklusive Installation und Abschluss eines dreijährigen Wartungsvertrages durch. Die Beschaffung ist für die Kinderklinik der Insel Gruppe AG mit Bestellhorizont Q3/2026 vorgesehen.
