Motivation de l'adjudicateur

Das Angebot der Zuschlagsempfängerin war insgesamt das Vorteilhafteste und hat am meisten Punkte erhalten. Ausschlaggebend war insbesondere das Zuschlagskriterium «ZK3 Preis», beim dem die Zuschlagsempfängerin das niedrigste Angebot eingereicht hat.

Description

Dans le nœud de Berne, plusieurs grands projets sont en cours d'exécution ou vont démarrer dans les prochaines années. Il existe un grand besoin d'analyses de laboratoire pendant l'exécution, d'une part pour la classification des déblais (matières solides) selon le droit des déchets, d'autre part pour le monitoring des eaux souterraines et des eaux usées du chantier (eau). Les projets déterminants sont les suivants : · AS25: Bern West, Leistungssteigerung · Bern, Publikumsanlagen SBB · Ostermundigen, ÖV-Knoten · AS25: Wankdorf Süd-Ostermundigen, Entfl. · AS25: Gümligen Süd, Entflechtung · AS25: Münsingen, Wendegleis Sous réserve d'autres projets dans la région de Berne.
