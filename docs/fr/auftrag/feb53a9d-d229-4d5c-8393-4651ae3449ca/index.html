Description

Gegenstand dieser Ausschreibung ist die Beschaffung einer Software mit integrierter KI- Lösung zur Analyse von Aufnahmen (Fotos), welche die Anlageverantwortlichen bei der Zustandsbewertung und dem Erstellen von Inspektionsresultaten im Bereich Anlagen unterstützt. Weitere Teile dieser Ausschreibung sind die Implementierung und der Betrieb einer solchen Lösung in der Repower Systemlandschaft, diese Schnittstelle muss ebenfalls mitbeschrieben werden, damit Repower die Schnittstelle zu seinen Systemen erstellen kann. Ein weiterer wichtiger Aspekt für die Repower ist die Skalierbarkeit auf weitere Anlagen (Unterwerke, Trafostationen und Verteilkabinen) und die Nachhaltigkeit der Software. Repower legt grossen Wert darauf, dass das Gesamtsystem weiterentwickelt und an sich verändernde Bedürfnisse angepasst werden kann. - Lieferung einer SAAS-Lösung (Lizenzen), Implementierung in die Systeme von Repower, Schulung und Support der Mitarbeiter
