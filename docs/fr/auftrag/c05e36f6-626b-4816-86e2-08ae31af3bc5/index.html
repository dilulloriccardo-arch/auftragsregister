Description

Dans le cadre du présent marché public «Interphones pour passagers et appel à l’aide via APFZ», les CFF prévoient d’attribuer les mandats de développement, fabrication et livraison d’interphones (appel d’urgence et appel à l’aide) qui seront utilisés à l’intérieur de différents véhicules du trafic voyageurs.

Les nouveaux projets portent sur l’acquisition de matériel roulant ainsi que sur la modernisation du matériel roulant existant pour couvrir les besoins en pièces détachées y relatifs.
