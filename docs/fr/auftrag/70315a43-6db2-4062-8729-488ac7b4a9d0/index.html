Description

Für die Beschaffung von Mini Unmanned Aerial Systems (MUAS), MUAS-Einzelteile/Baugruppen, ergänzendem Zubehör und Dienstleistungen werden, wenn möglich acht (8) Rahmenvertragspartner gesucht.
