Description

Les tl ont débuté en 2024 des travaux d’extension du dépôt de Perrelet à Renens. Ces travaux ont pour objectif d’augmenter significativement les surfaces et volumes actuels pour soutenir au premier semestre 2027 l’augmentation et le renouvellement de la flotte de véhicules routiers. Ces réaménagements influencent de manière importante les équipements qui y sont installés et notamment les installations de lavage qui doivent en conséquence être réhabilitées. Pour répondre à ce besoin, les tl souhaitent s’appuyer sur les compétences d’un assistant à maitrise d’ouvrage, capable de l’accompagner dans le cadre de ce projet. Les compétences de l’AMO devront couvrir les domaines CVSC-E ; IT ; CME ; GC, ENV.

Le présent appel d’offres porte donc sur les prestations d’assistance à maitrise d’ouvrage pour l'acquisition et le renouvellement d'installations de lavage des bus pour notre dépôt de Perrelet mais également celui de la Borde.

Le pouvoir adjudicateur souhaite se doter de deux nouvelles installations (une pour chacun des sites) et renouveler les installations existantes (trois pour le dépôt de Perrelet et deux pour celui la Borde).
