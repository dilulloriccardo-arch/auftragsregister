Description

Aux endroits inaccessibles (sur la bande médiane en priorité), les néophytes doivent être fauchées, aspirées et éliminées mécaniquement. Les prestations correspondantes doivent être fournies sur une période de quatre ans (de 2026 à 2029). Pour la description détaillée des prestations, voir la documentation d’appel d’offres.
