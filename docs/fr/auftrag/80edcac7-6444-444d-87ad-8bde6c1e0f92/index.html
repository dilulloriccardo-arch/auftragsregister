Description

Die Hochdruckreinigung sowie die TV-Inspektion der Abwasserkanalisation sind gemäss der aktuellen Mehrjahresplanung «Betrieblicher Kanalisationsunterhalt» für die Jahre 2026, 2027 und 2028 in verschiedenen Unterhaltszonen der Stadt Uster geplant. Die Arbeiten sollen jeweils ab Mitte Juni im jeweiligen Jahr, ohne Unterbruch, durchgeführt werden. Mengengerüst: ▪ Hochdruckreinigung der Abwasserkanäle 2026 = 769 Abwasserkanäle, 28.8 km => 48 Tage (8 h/Tag) 2027 = 976 Abwasserkanäle, 39.9 km => 67 Tage (8 h/Tag) 2028 = 824 Abwasserkanäle, 30.3 km => 51 Tage (8 h/Tag) ▪ TV-Inspektion der Abwasserkanäle 2026 = 131 Abwasserkanäle, 4.7 km => 12 Tage (8 h/Tag) 2027 = 162 Abwasserkanäle, 7.6 km => 18 Tage (8 h/Tag) 2028 = 291 Abwasserkanäle, 9.2 km => 23 Tage (8 h/Tag)
