Motifs du choix

Das vorliegende Angebot von BD-Rowa erfüllt die definierten Grundlagen und Anforderungen und kann als valides Angebot bewertet werden. Description

Ausschreibungsumfang

Innerhalb dieses Lastenhefts werden die technischen Gewerke für das Projekt “Automatisiertes Lager ZüriPharm“ ausgeschrieben. Die Ausschreibung beinhaltet insbesondere folgende Gewerke:
- Behälter Fördertechnik
- Behälter Lift
- Medi-AKL (Pick-Roboter)
- Kommissionierstationen
- Fahrerloses Transportsystem
- Automatisiertes Shuttlelager
