Description

Die Gemeinde Glarus saniert die Stützmauern auf der Sackbergstrasse, zwischen der Bärschirüti und dem Bränntloch. Es wird eine Spritzbetonwand mit Selbstbohrankern und Fahrzeugrückhaltesystem erstellt.
