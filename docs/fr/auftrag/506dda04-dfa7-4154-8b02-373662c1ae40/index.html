Description

Ces dernières années, l'état de la route entre Gamsen et Stuckiegga n'a cessé de se détériorer. Les dommages ne peuvent plus être réparés par de petits travaux d’entretien (kbU). C’est pourquoi l’ensemble du revêtement (environ 210 000 m²) doit être remplacé sur les quelques 13,3 kilomètres concernés. Les travaux principaux sont prévus pour les années 2027 et 2028.
