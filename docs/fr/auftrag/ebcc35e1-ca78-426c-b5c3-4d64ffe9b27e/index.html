Description

Le présent lot ARHE BSA-6.06 Installation d’appel d’urgence porte essentiellement sur les fournitures et les prestations suivantes :
- Ingénierie, livraison, installation et mise en service de l’équipement électrique (y. c. les interphones pour les appels d’urgence VoIP) dans les armoires d’alarme et les boîtes d’alarme encastrables existantes
- Installation, câblage et assistance à la mise en service de modules d’E/S distants pour l’installation Divers, de commutateurs de terrain pour le réseau IP EES ainsi que de prolongateurs LAN pour l’intégration de caméras vidéo dans les armoires d’alarme et les boîtes d’alarme encastrables existantes
- Ingénierie, livraison, installation et mise en service de l’équipement électrique (y. c. les interphones d’appel d’urgence avec module de téléphonie mobile) dans quatre bornes d’appel d’urgence existantes
- Installation, câblage et mise en service de commutateurs de terrain pour le réseau IP EES ainsi que de prolongateurs LAN pour l’intégration de caméras vidéo dans les bornes d’appel d’urgence existantes
- Mise à niveau des bornes d’appel d’urgence pour un fonctionnement autonome avec batterie et panneaux solaires
- Livraison, montage et mise en service d’un système de commande pour l’installation d’appel d’urgence
- Démontage de l’équipement électrique (y. c. les interphones) dans les armoires d’alarme, les boîtes d’alarme encastrables et les bornes d’appel d’urgence existantes
- Réalisation du projet conformément à la description, comprenant toutes les phases de test, les étapes de documentation et les formations
