Description

Les paquets de prestations suivants doivent être traités :
- LP-A : Préparation des plans, extension du système, soutien de l'organisation commerciale
- LP-B : Reprise des données de Swisscom, y compris les corrections des données contractuelles des contrats d'objet techniques respectifs pour les différentes lignes du système ServiceNow.

- LP-C : Réalisation de l'achèvement du projet DKN à partir d'études antérieures, PoC, concept ISDS et autres bases de planification et de projet.
