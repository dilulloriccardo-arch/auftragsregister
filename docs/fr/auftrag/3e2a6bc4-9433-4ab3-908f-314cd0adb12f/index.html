Motifs de l’adjudication

Es handelt sich um das vorteilhafteste Angebot auf Basis aller Kriterien.

Description

Les prestations de l’adjudicataire comprennent notamment les tâches suivantes (liste non exhaustive) :
• Direction et coordination de projets pour des questions spécifiques de soutien à l’OFROU dans le cadre de projets sur les dangers naturels
• Réalisation d’analyses de dangers et de risques concernant les dangers naturels pour des événements naturels précis
• Réalisation de planifications de mesures ou de génération de projets pour la protection contre les dangers naturels selon les manuels techniques de l’OFROU
• Étude de projet, suivi réalisation et gestion (auteur du projet / ingénieur) de mesures de protection contre les dangers naturels conformément aux manuels techniques de l’OFROU
• Appui pour les travaux liés à l’exploitation et à l’entretien courant dans la filiale selon les manuels techniques de l’OFROU
• Planification et surveillance des ouvrages de protection
• Gestion des données relatives aux dangers naturels via une plateforme de gestion web SIG
• Soutien technique et décisionnel lors d’événements naturels menaçant les routes nationales.
Les prestations susmentionnées sont décrites en détail dans le cahier des charges.

Remarques :
Le soumissionnaire n’a pas l’obligation de déposer une offre pour les deux lots. Il peut ainsi déposer une offre que pour un seul ou pour les deux lots s’il le souhaite.
Dans le cas où un soumissionnaire dépose des offres pour les deux lots, il doit impérativement indiquer au moment du dépôt des offres son ordre de préférence.
Le soumissionnaire pourra être adjudicataire des deux lots à condition de remplir toutes les conditions de l’appel d’offres.
