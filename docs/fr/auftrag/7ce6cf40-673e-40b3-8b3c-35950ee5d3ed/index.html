Description

L’Espérance organise le présent appel d'offres avec pour but de conclure un contrat-cadre avec une société de recrutement portant sur la mise à disposition de personnel détaillé dans le cahier des charges. La durée prévue pour le contrat-cadre de location de services est de 3 ans, renouvelable deux fois pour une durée d’une année, soit 5 années au maximum. Sous-toutes réserves, le début du contrat-cadre est envisagé pour le 1er octobre 2026.
