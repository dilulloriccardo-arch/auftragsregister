Description

Im Sinne einer kontinuierlichen Dienstleistungsverbesserung und zur Steigerung der Effizienz interner Prozesse lädt Switzerland Global Enterprise qualifizierte und geeignete Unternehmen ein, Angebote für den Betrieb, Support und die Weiterentwicklung der bestehenden Microsoft CRM Lösung unter Berücksichtigung der genannten Anforderungen einzureichen. Angestrebt wird eine fortlaufende Partnerschaft über einen Gesamtzeitraum von 5 Jahren. Der Vertrag wird zunächst für drei Jahre abgeschlossen, mit zwei Optionen auf eine Verlängerung um jeweils ein Jahr.
