Motifs de l'adjudication

Das Unternehmen erfüllt nach der Eignungsprüfung die Zuschlagskriterien am besten. Insbesondere überzeugten deren Leistungsfähigkeit (Projektreferenzen sowie eingereichte CVs), die Zufriedenheit mit der bisherigen Leistung (schriftliche Bewertung durch Referenzpersonen) sowie dem vorteilhaftesten Preis-Leistungsverhältnis.

Description

Einführung einer Softwarelösung zur Ablage der elektronischen Personalakten inkl. der optionalen Funktion Dokumentenerstellung, welche folgende Leistungen umfasst: - Bereitstellung einer Standardsoftware als SaaS-Lösung oder als On-Premise-Lösung auf Infrastruktur der Universität Zürich (Lizenzen, bzw. Subskriptionen, mit jährlicher Wartung) inkl. Integration in das ERP-System SAP S/4HANA. - Implementierung (Customizing/Parametrisierung) und Einführung der Software inkl. Hyper-care-Support - Pflege der Software (Korrektur, Weiterentwicklung und Störungsbehebung) - Betriebsoption A: Wartung der S/4HANA Integration - Betriebsoption B: Applikationsmanagement (nur bei On-Premise-Lösungen)
