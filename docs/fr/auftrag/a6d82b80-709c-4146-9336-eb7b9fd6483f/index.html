Description

Lots 1, 2

Spectromètre RMN 300 MHz comprenant une console pour spectromètre RMN 300 MHz, une tête d'échantillonnage, un système de shim, une station de travail pour le logiciel de contrôle du spectromètre, un passeur d'échantillons et une unité de refroidissement.

Vous trouverez tous les détails au point 4.1 / Lot A (lot 1) et lot B (lot 2).

Lot 3

Spectromètre RMN 400 MHz D-MATL, comprenant :
1 / Console pour spectromètre RMN 400 MHz
2 / Échantillon pour spectromètre RMN 400 MHz
3 / Système de shim pour spectromètre RMN 400 MHz
4 / Aimant RMN pour spectromètre RMN 400 MHz
5 / Station de travail pour la commande du spectromètre, logiciel inclus
6 / Changeur d'échantillons
7 / Unité de refroidissement / Cooling Unit
Pour tous les détails, voir le cahier des charges / point 4.2 (lot C)

Lot 4

Tête de sonde RMN à triple résonance pour spectromètre RMN 500 MHz (Lot D)
Sonde triple résonance de 5 mm avec gradient z pour la spectroscopie RMN.

Tous les détails selon le cahier des charges / point 4.3 et suivants.

Lot 5

Spectromètre RMN 400 MHz LOC/D-CHAB 2024 : console, sonde, système Shim et passeur d'échantillons pour spectromètre RMN 400 MHz (un lot, lot E).

Pour tous les détails, voir le cahier des charges / point 4 et suivants.
