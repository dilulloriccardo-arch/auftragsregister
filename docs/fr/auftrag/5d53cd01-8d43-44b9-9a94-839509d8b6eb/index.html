Description

Die Ausschreibung umfasst sämtliche Tief- und Strassenbauarbeiten für den Ausbau der Fernwärme-und Anergieleitung in Rorschach an der Signalstrasse. Im gleichen Zuge wird der Gehweg Signalstrasse West verbreitert und diverse Gestaltungselemente erstellt.
