Description

I lavori oggetto del presente bando consistono nell’adeguamento dell’interfaccia tra il sistema di gestione sezione esistente e gli impianti BSA soggetti a interventi presso le gallerie di Gentilino e Maroggia. Le attività principali dell’opera sono: - integrazione del nuovo impianto illuminazione nell’attuale sistema di gestione sezione; - implementazione di macrocomandi OSTRAL nell’attuale sistema di gestione sezione, incluso l’adattamento delle relative viste “oggetto”; - integrazione ed estensione dei punti-dato dell’impianto diversi nell’attuale sistema di gestione sezione.
