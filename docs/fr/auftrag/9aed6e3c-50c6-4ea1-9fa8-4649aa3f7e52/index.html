Description

Schweiz Tourismus organisiert diverse Projekte, in denen die Eventtechnik eine entscheidende Rolle spielt. Der Ausschreibungsgegenstand umfasst die gesamte angemietete Eventtechnik von Schweiz Tourismus. Diejenige Unternehmung die den Zuschlag erhält, wird während des Ausschreibungszeitraumes einziger Lieferantin für Schweiz Tourismus in der Schweiz sein.
