Description

Le lot 411 QSK ZG comprend essentiellement la construction des unités de contrôle locales (QSK) y compris la programmation associée pour un système d’harmonisation des vitesses et avertissement de danger. Les principales fournitures et prestations prévues sont les suivantes :

• Plusieurs QSK dans des cabines standard avec contrôle et exploitation locaux, incluant les interfaces d'alimentation et de données pour les signaux dynamiques et les capteurs.

• Logiciel complet pour l'interface avec le système de contrôle-commande
• Logiciel complet pour le contrôle et l'exploitation locaux avec interfaces
• Connexion au réseau IP-Netz BSA GEX
• Tous les services complémentaires nécessaires
