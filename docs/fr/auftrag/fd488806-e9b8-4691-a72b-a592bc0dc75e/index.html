Description

Pour le projet 240052 « Renouvellement de la radiodiffusion d’urgence GE X », un concepteur (planificateur) pour les installations d’exploitation et de sécurité (BSA) est recherché. L’installation actuelle de radiodiffusion en modulation de fréquence (UKW), datant de 2000, doit être entièrement remplacée par un système DAB+ pérenne. Le nouveau système d’appel d’urgence doit être intégré dans le système de conduite supérieur existant UeLS-zentras. Les installations concernent douze tunnels situés dans le périmètre de l’unité territoriale GE X, sur les routes nationales N02, N04, N08 et N14. Le mandat comprend le traitement des phases de prestations SIA 32 à 53.
