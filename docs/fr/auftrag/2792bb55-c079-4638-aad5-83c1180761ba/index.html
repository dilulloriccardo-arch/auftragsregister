Description

Le marché faisant l'objet de l'appel d'offres concerne la conclusion d’un contrat-cadre multi-adjudicataires auditeurs DGNB pour une période de cinq ans en vue de la certification des nouvelles infrastructures de Genève Aéroport.

Le but du présent appel d’offres est de sélectionner 2 bureaux d’audit pour le marché.
