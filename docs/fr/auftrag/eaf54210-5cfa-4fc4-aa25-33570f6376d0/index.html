Description

La nature du marché concerne essentiellement des prestations visant l'entretien courant ainsi que les travaux d'entretien sur le réseau routier du canton de Genève. Ces prestations concernent essentiellement les bordures de chaussée, les revêtements (enrobés bitumineux ou béton) les canalisations et l'éclairage public.
