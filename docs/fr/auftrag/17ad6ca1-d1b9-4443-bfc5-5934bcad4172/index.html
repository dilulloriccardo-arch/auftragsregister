Description

Lot 1

Dieses Los umfasst die Lizenzen aus den bestehenden Verträgen des KSW mit Microsoft:
• Select+
• Enterprise Agreement (EA)
• Cloud Solution Provider (CSP)
• Server and Cloud Enrollment (SCE)

Lot 2

Um den steigenden Kostendruck im Gesundheitswesen zu adressieren und die IT-Ausgaben in den kommenden Jahren möglichst tief zu halten, sollen bestimmte Microsoft Office-Lizenzen als geprüfte Used-Lizenzen beschafft werden.
Dieses Los umfasst die Lieferung solcher Lizenzen, die in rechtlicher und technischer Hinsicht vollumfänglich konform und einsatzfähig sind.
