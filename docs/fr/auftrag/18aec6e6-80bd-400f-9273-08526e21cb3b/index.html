Description

Afin de planifier les interventions nécessaires à la sécurité et à la durabilité des infrastructures autoroutières, il est essentiel de surveiller les chaussées pour détecter les dégradations et évaluer leur gravité. Le présent marché porte sur les prestations d’investigations de laboratoire sur chaussées bitumineuses, incluant les étapes principales suivantes :
- Auscultations de chaussées routières avec appareils à grand rendement pour mesurer les planéités longitudinales et transversales, la qualité antidérapante et la portance.
- Auscultations des marquages routiers pour mesurer la rétroréflexion et la qualité antidérapante.
- Prélèvement in situ de carottes dans les revêtements bitumineux.
- Descriptif des carottes (type de couche, épaisseur de couche, fissuration).
- Essai d’adhésion entre les couches des carottes.
- Analyse de l’enrobé bitumineux prélevé.
- Analyse de liant récupéré de l’enrobé.
- Rédaction d’un rapport de synthèse des essais et analyses effectuées, évaluation de l’état des chaussées et proposition de réfection.
Le mandat concerne les investigations sur les chaussées des routes nationales, couvrant notamment les principaux axes routiers, les jonctions (rampes d’accès, carrefours) ainsi que les routes de liaison.

Remarques : Le soumissionnaire n’a pas l’obligation de déposer une offre pour les deux lots. Il peut ainsi déposer une offre que pour un seul ou pour les deux lots s’il le souhaite.
Le soumissionnaire indiquera dans son offre pour quel lot il dépose une offre. S’il dépose une offre pour les deux lots et en cas d’adjudication des deux lots, le soumissionnaire indiquera :
- S’il a les capacités de fournir les prestations pour les deux lots.
- S’il n’a pas les capacités, pour lequel des deux lots il souhaiterait être adjudicataire.

Dans le 2ème cas, le soumissionnaire classé deuxième sera retenu pour le lot concerné. Le soumissionnaire pourra être adjudicataire des deux lots à condition de remplir toutes les conditions de l’appel d’offres.
