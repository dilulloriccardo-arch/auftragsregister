Description

Le opere in appalto prevedono la realizzazione di una nuova pista ciclabile nel Comune di Balerna. Lungo Via Motta é previsto l'allargato del marciapiede esistente mentre in corrispondenza della rotonda di Via Passeggiata verrà creata una nuova passerella sul riale Raggio (tratta 0162.101-1).

In seguito, lungo Via Commercio e il riale Raggio, la pista ciclabile verrà eseguita in terra stabilizzata (tratta 0163.101-1).

Quantitativi principali:
-taglio e rimozione siepi: 30 pz
-demolizioni pavimentazioni bituminose: 220 m3
-scavi: 4'600 m3
-esecuzione planum: 5'600 m2
-ponteggi: 125 ml
-opere in calcestruzzo armato: 461 m3
