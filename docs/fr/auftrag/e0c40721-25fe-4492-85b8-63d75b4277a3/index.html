Description

Bauvorhaben:
Im Rahmen der Spannungsumstellung im UW Beznau im Jahr 2026 werden zwei neue 40MVA 110/16kV Trafos im UW Beznau geplant. Für diese zwei neuen Trafos werden zwei neue Trafowannen sowie die Rohrblöcke zur Anbindung der bestehenden 16kV Schaltanlage im AEW UW Gebäude benötigt. Das vorliegende Bauvorhaben umfasst die zwei Trafogruben, die Brandschutzwand, die Aussenwände, die Rohrblöcke sowie die Umgebungsarbeiten.

Weitere Angaben gem. Ausschreibungsunterlagen.
