Description

Die zu beschaffenden Notebooks sollen durch den Anbieter vorbereitet und in Betrieb genommen werden. Die bereitgestellten Geräte müssen anhand eines separaten Rollout-Terminplans in den Büros der SVA BL in Binningen an dem Mitarbeitenden Arbeitsplätzen installiert werden. Zudem muss die Verkabelung der bestehenden Bildschirme angepasst werden, so dass diese im Daisy-Chain verfahren funktionieren. Allfällige Zusatzosten für den Rollout optionaler Docking Stationen anstelle der Daisy-Chain Verkabelung sind auszuweisen.
