Description

Für den Neubau Garage Rank sucht die BVB eine Unternehmung, welche die Türen aus Metall und Brandschutzvorhänge liefern und montieren kann. Mit dem Zuschlagsempfänger wird ein Werkvertrag abgeschlossen.
