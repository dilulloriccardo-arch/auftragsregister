EBP-597 AFW Schwabguet Baumeister

Acheteur public
Energie Wasser Bern

Description

Le projet comprend la pose de conduites principales et de distribution pour le réseau de chauffage à distance dans le quartier Schwabgut à Bümpliz, y compris les raccordements nécessaires. Parallèlement, des conduites d’eau, de gaz et d’électricité seront réalisées.

Selon le cahier des charges, les travaux suivants doivent être exécutés :
- Conduites de chauffage à distance : env. 2'300 m de conduites principales avec 34 raccordements de maison
- Conduites de gaz : env. 50 m de conduites avec 2 raccordements
- Conduites d’eau : env. 1'300 m de conduites avec 59 raccordements de maison

Les nouvelles conduites doivent être posées dans les rues suivantes :
Bümplizstrasse, Schwabstrasse, Normannenstrasse, Keltenstrasse ainsi que Gotenstrasse.
