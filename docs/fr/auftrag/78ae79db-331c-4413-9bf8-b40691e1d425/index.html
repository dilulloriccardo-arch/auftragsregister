Motifs du choix

Die Vergabe erfolgt aufgrund der bekannt gegebenen Zuschlagskriterien an den Anbieter mit dem vorteilhaftesten Angebot. Das berücksichtige Angebot weist insbesondere beim Kriterium “Preis” Vorteile auf.

Description

Beim Bahnhof Davos Laret werden zwei neue Perrondächer erstellt, die je an ein Gleis angeordnet sind und die Rampen sowie Treppen der Personenunterführung (PU) überdecken. Gleichzeitig gewährleisten sie den Witterungsschutz für die wartenden Passagiere.

Das Tragwerk besteht aus einer Stahlkonstruktion, auf der längsgerichtete Brettschichtholzträger aufliegen. Die erforderliche Auskragung wird durch vorgefertigte Holzelemente aus liegenden Brettschichtholzquerschnitten realisiert, welche auf die Hauptträger aufliegen.
