Description

Le BLS utilise des transformateurs aériens sur son réseau, qui sont utilisés pour l'alimentation de consommateurs fixes, en particulier pour le chauffage des aiguillages et pour l'alimentation en énergie des installations techniques de l'exploitation ferroviaire. Dans le cadre de l'acquisition, le BLS lance cet appel d'offres afin de fixer les livraisons d'isolateurs dans un contrat-cadre pour les prochaines années.

Le présent appel d'offres doit permettre de conclure un contrat-cadre entre un fournisseur de transformateurs et BLS Netz AG, pour les trois prochaines années, avec une option de prolongation de deux fois deux ans.
