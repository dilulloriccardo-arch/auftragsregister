Motifs du choix

Alle eingereichten Offerten wurden eingehend und objektiv nach den Zuschlagskriterien und deren Gewichtung bewertet. Aufgrund dieser Bewertung erreicht die erstplatzierte Firma Joker IT AG 8’684,1 Punkte und reichte damit das vorteilhafteste Angebot ein. Die zweitplatzierte Firma Sharp DX (ehemals IT Point Systems AG) erreichte 8’450 Punkte. Das Angebot der Firma Joker IT AG überzeugte dabei insbesondere mit seinen Referenzen.

Die Firma Joker IT AG hat für die Dienstleistung das vorteilhafteste Angebot im Sinne von Art. 41 der Interkantonalen Vereinbarung über das öffentliche Beschaffungswesen vom 15. November 2019 (IVöB; SRL Nr. 733b) eingereicht und bietet Gewähr für eine fach- und termingerechte Ausführung der Dienstleistung.

Description

Die Stadtverwaltung Luzern sichert ihre Microsoft 365 und Microsoft Entra Services derzeit mit einer cloudbasierten Backup Lösung. Aufgrund erhöhter Anforderungen an die Datensouveränität soll die zukünftige Backup Architektur unabhängig von Microsoft ausgestaltet werden.
