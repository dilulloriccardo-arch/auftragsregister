Description

L'objet du marché est la création et la mise à disposition d'un site web centré sur l'utilisateur, basé sur le système de gestion de contenu (CMS) Drupal et une infrastructure cloud sur Amazon Web Services. Le site web comprend un design réactif conforme aux spécifications de l’identité visuelle de la Confédération, une gestion de contenu conviviale, des modèles de page prédéfinis et les extensions fonctionnelles nécessaires via les extensions Drupal. Sont également inclus une fonction de recherche performante permettant une recherche structurée du contenu, ainsi que la connexion à des sources de données existantes (DAM/WSP) et le transfert automatique ou la migration des données de l'ancien système. Sont également compris la mise en place technique, la configuration et une formation ainsi que la documentation pour la maintenance du contenu par les futurs utilisateurs (rédacteurs).
