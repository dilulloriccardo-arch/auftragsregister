Description

Mit dieser Ausschreibung soll eine Lieferantin evaluiert werden, die der Stadtpolizei Zürich eine leistungsfähige, transportfähige und betriebssichere Netzersatzanlage inklusive Anhänger liefern kann. Es handelt sich um eine betriebsfertige Anlage ab dem «Anschlusskasten (NEA) innen» (siehe beiliegendes Prinzipschema 1085.05.001).
