Description

Beschaffungsgegenstand dieser Ausschreibung sind Elektroarbeiten gemäss BKP 23 im Bereich der Ladeinfrastruktur der Busgarage Hagenholz. Die Leistungen umfassen die Installation und Inbetrieb-nahme der Beleuchtung, Gebäudeautomation, Verbindungskabel, Montage Branddetektions-System, GIFAS-Steuerungssysteme sowie begleitende Kleinarbeiten gemäss den Ausschreibungsunterlagen.
