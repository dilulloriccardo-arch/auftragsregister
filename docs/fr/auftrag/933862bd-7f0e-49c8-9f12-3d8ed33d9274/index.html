Motifs de l’adjudication

Der Auftrag wird an die Firma counig consulting AG, Bern vergeben. Das Angebot zum Preis von Fr. 267'800.00 (exkl. MwSt.) hat sich als das vorteilhafteste erwiesen und die höchste Punktzahl gemäss den in den Ausschreibungsunterlagen festgelegten Kriterien erreicht. Das Angebot erreichte 871 von möglichen 1000 Punkten, was einem Vorsprung von 144 Punkten gegenüber dem zweitplatzierten Anbieter entspricht.

Description

Für die Neuausrichtung des Projektes zur Ablösung des BISSO KLV suchen wir eine professionelle externe Unterstützung in der Rolle als Projektleitung, welche zusätzlich selber oder unterstützt durch eine weitere Person auch das Projektmanagement-Office für das Volksschulamt im Kanton Solothurn sicherstellt.
