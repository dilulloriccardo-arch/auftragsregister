Motivation de l'adjudicateur

L'offre de l'adjudicataire a été sélectionnée pour les motifs suivants: L'expertise technique et l'expérience attestée en coaching d'équipes de développement ; la pertinence et le pragmatisme de la démarche proposée dans le contexte OCSIN ; la qualité des dispositifs de mesure d'impact (métriques DORA, KPIs qualité) ; la capacité d'intégration dans la gouvernance existante, mais également le prix compétitif.

Description

Le présent appel d'offres a pour objet de sélectionner un prestataire capable d’accompagner, sur une durée de deux ans pouvant être prolongée de trois ans, les développeurs et experts techniques des filières PHP, Java/JavaScript, et Python de l’OCSIN dans l’adoption et la généralisation des meilleures pratiques de développement.
