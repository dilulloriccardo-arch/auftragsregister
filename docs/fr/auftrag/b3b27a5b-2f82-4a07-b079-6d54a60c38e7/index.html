Description

Dans le cadre de servir l’Administration cantonale vaudoise, la DAL organise le présent appel d’offres pour acquérir les fournitures de bureau : Lot 1 : perforelieur et accessoires, Lot 2 :portes-badges pour 2 cartes de sécurité, Lot 3 : perforateurs, Lot 4 :support pour documents, Lot 5 :signataires A4, Lot 6 : accessoires pour tableaux blancs, Lot 7 : tableaux blancs, définis dans cet appel d’offres.
