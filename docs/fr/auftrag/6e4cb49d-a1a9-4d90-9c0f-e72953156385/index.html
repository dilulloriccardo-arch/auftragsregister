Description

Die Gemeinde Uetikon am See beabsichtigt, auf dem Scheug-Areal (Kat. Nr. 5053) 21 Sozialwohnungen zu realisieren. Zur Erlangung eines bewilligungsfähigen Bauprojekts und zur Umsetzung dieses Bauvorhabens veranstaltet die Gemeinde Uetikon am See eine Submission für einen Holzbau-Totalunternehmer.
