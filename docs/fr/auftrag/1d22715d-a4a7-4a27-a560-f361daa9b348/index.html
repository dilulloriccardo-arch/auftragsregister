Description

SKP 246.2 Kälteverteilung / Kälteverrohrung
Auf dem Areal des Inselspital soll im Gebäude SWAN-Haus In der Arealkältezentrale (AHV3) die Absorber-Kältemaschine ersetzt werden. Die Kältemaschine hat das Ende ihres Lebenszyklus erreicht. Die Maschine soll durch eine Kältemaschine inkl. Einbindung Wärmerückgewinnung ersetzt werden. Die bestehende Absorber Kältemaschine soll unterlaufenden Betrieb ersetzt werden. Die Rückkühleinheiten werden beibehalten. Es sind jedoch Massnahmen bezüglich Leistungsstufen zu berücksichtigen. Der Betrieb der Rückkühlereinheiten soll ohne Anpassungen an der Hydraulik gewährleistet werden. Die Kälteverteilung der neuen Kältemaschine soll in das bestehende Kaltwasser, Rückkühl- sowie Wärmerückgewinnungsnetz eingebunden werden.
