Description

In den sieben Gleichrichteranlagen von BERNMOBIL (BEMO) «Schosshalde», «Holenacker», «Brunnmatt», «Unterführung», «Wankdorf», «Depot», «Stadion» ist die Lebensdauer der Stationsautomatisierung (SAS) abgelaufen. Damit der störungsfreie Betrieb weiterhin gewährleistet ist, müssen die Stationsautomatisierungen SAS ersetzt werden.
