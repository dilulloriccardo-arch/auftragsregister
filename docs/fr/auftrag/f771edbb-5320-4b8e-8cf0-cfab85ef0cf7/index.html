Description

La présente procédure d’appel d’offres porte sur la fourniture de quatre (4) véhicules d’intervention de police de proximité pour l’association Sécurité Riviera. Les véhicules peuvent être de toute marque, mais il est attendu qu’ils soient de la même catégorie que ceux actuellement utilisés par l’Association Sécurité Riviera (voir §2.7 du cahier des charges)
