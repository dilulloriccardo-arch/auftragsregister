Description

Les pièces d’usure telles que les tuyaux flexibles pneumatiques doivent être régulièrement remplacées lors des contrôles ordinaires sur les véhicules ferroviaires. Ces tuyaux flexibles transportent de l’air comprimé dans les véhicules ferroviaires entre de nombreuses applications: p. ex. compresseur, réservoir d’air, freins, suspension pneumatique, attelage. Un marché d’adjudication portant sur les tuyaux flexibles confectionnés et prêts à l’emploi est prévu pour pouvoir couvrir les besoins induits par les révisions pour la période 2025-2028. Le marché peut faire l’objet d’une reconduction.
