Description

Für das Industriezentrum Klybeck müssen Leistungen für die Heizungs- und Lüftungsanlage beschafft werden für die Umnutzung der Industriehalle im 1. Obergeschoss in eine Bürofläche. Die BVB schliesst mit der Zuschlagsempfängerin einen KBOB-Werkvertrag ab.
