Motifs du choix

Description

Die Schulgemeinde Illnau-Effretikon beabsichtigt die Primarschulhäuser mit neuen interaktiven Wandtafeln auszustatten.

Es ist explizit eine Lösung gefordert, welche beim Displaystandort keinen LAN- oder WLAN-Anschluss benötigt. Der zur Bedienung notwendige Sofwareclient muss direkt auf der Hardware der Nutzer:innen (Laptop, Tablet etc.) installiert werden können. Die vollumfängliche Funktionsfähigkeit muss mit der nachfolgenden Verkabelungsstruktur gewährleistet und garantiert werden können.
