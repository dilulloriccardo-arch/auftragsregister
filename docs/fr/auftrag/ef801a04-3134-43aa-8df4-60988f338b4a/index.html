Description

Die bestehenden Betonbeläge auf den Pisten sowie den Standplätzen und den Rollwegen weisen infolge Alterung, Betrieb sowie der klimatischen Bedingungen Beschädigungen auf. Hauptziel der vorliegenden Ausschreibung ist die Reparatur aller Schäden auf den Flugbetriebsflächen in Beton, welche eine unmittelbare oder zukünftige Gefahr für den Flugbetrieb darstellen. Durch die Reparatur soll eine weitere interventionsfreie Betriebsdauer der reparierten Flächen von 15 Jahren gewährleistet werden.
