Description

Lors du recrutement, un examen de laboratoire volontaire des conscrits fait partie des tests de l'aptitude au service militaire dans les centres de recrutement. Nous sommes à la recherche d'un prestataire de services qui transportera les échantillons de sang, effectuera les tests de laboratoire et rapportera les résultats.
