Motivation de l'adjudicateur

Unter Berücksichtigung der in den Ausschreibungsunterlagen festgelegten Zuschlagskriterien erweist sich das Angebot der Firma G. Baumgartner AG als das vorteilhafteste Angebot. Die Zuschlagsempfängerin erreichte unter allen Anbietenden die höchste Punktzahl. Sie vermochte aufzuzeigen, dass sie die Eignungskriterien erfüllen kann und die Zuschlagskriterien besser als die Mitbewerber erfüllt.
