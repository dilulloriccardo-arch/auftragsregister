Motivation de l'adjudicateur

Unter Berücksichtigung der in den Ausschreibungsunterlagen festgelegten Eignungs- und Zuschlagskriterien erweist sich das Angebot der Firma «Brand Bedachungen AG» als das vorteilhafteste Angebot.

Description

Bedachungsarbeiten Schindeln auf geneigte Dächer (Neubau), siehe Beilagen und Pläne. Das Gebäude besteht aus sechs zusammenhängenden Pavillons in zwei Reihen, von denen jeder die Grundmasse 8 x 8 Meter hat. Jeder Teil hat ein Zeltdach mit jeweils einem «Hütchen» mit Oblicht. Das ge­samte Gebäude hat die Abmessung von 16 x 24 Meter.
