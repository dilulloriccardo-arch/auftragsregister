Description

Die Transportunternehmung «Zugerland Verkehrsbetriebe AG (ZVB)» schreibt die Beschaffung von E-Normalbussen für den Personenanhängerbetrieb aus. Dabei geht es um den Ersatz der bestehenden Flotte von Dieselnormalbussen für den Personenanhängerbetrieb bzw. um Teile davon.

Publication officielle : Voir le projet 9305 sur simap.ch — seule la publication qui y figure fait foi.
