Motivation de l'adjudicateur

Die Firma MGP Gebäudetechnik AG reichte ein vollständiges Angebot ein. Sie erfüllte die Eignungskriterien vollumfänglich und erzielte eine gute Erfüllung der qualitativen Zuschlagskriterien. Die Firma MGP Gebäudetechnik AG weist das wirtschaftlich vorteilhafteste Angebot auf.

Description

Gegenstand und Umfang dieser Ausschreibung ist der Ersatz einer bestehenden Gasheizung (Standkessel) durch eine Sole-Wasser-Wärmepumpen mit 6 Wärmegewinnungs-Erdsonden gemäss den Ausschreibungsunterlagen.
