Motifs du choix

Die Firma Ringeisen AG hat sowohl preislich das wirtschaftlich günstigste Angebot eingereicht als auch nachgewiesen, dass sie einen Lehrlingsausbildungsplatz anbietet. Damit konnte sie in beiden Kriterien überzeugen und die höchste Gesamtpunktzahl erzielen.

Description

Für das Projekt sollen Ausbaugewerke gemäss Ausschreibungsunterlagen beschafft werden.
