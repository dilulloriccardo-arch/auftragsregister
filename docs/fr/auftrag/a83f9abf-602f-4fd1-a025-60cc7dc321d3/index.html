Description

Dans le cadre du projet de rénovation et d'agrandissement du Centre de maintenance S. Bernardino Sud, l'installation de nouveaux systèmes de chauffage, de plomberie et de ventilation pour les bâtiments est prévue : • A bâtiment administratif • B Atelier mécanique • C Atelier électrique et lave-auto • D cantine • F Bâtiment de maintenance UTGR
