Motifs de l'adjudication

Description

Elektroinstallationen vorgezogene Leistungen für den Ersatz der Verbrennungslinie 2 (ErVeL2) - Bau- und Energieprovisorien - Installationen für die Containeranlage - Provisorien in verschiedenen Gebäudeteilen - Installationen in vorgezogenen Elektro-Räumen - Anschlüsse für Baukräne - Installationen in der Greiferwerkstatt und beim Flugaschesilo - Anschlüsse für Druckluftkompressoren
