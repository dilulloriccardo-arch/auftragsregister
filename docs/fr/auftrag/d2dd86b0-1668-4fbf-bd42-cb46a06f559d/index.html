Description

Le marché comprend la fourniture d’un véhicule entièrement équipé, y compris les équipements rapportés et accessoires définis dans les documents d’appel d’offres. L’étendue des prestations comprend également le transport jusqu’au lieu d’utilisation, la mise en service, l’instruction du personnel d’exploitation, la documentation technique ainsi que les prestations convenues de garantie, d’entretien et de service après-vente.

Les exigences techniques détaillées, l’étendue exacte de la livraison ainsi que les conditions contractuelles figurent dans les documents d’appel d’offres.
