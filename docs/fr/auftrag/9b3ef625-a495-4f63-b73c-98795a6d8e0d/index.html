Description

La filiale infrastructure de Thoune est responsable du relevé de l’état des revêtements et de la mise à jour des données dans l’application métier Tracé (TRA). Les prestations acquises dans le cadre de ce lot 4 peuvent être divisées en 3 parties :

Dans la partie A, la tâche consiste à tenir à jour l’application métier TRA, ce qui signifie que les revêtements posés dans le cadre des petits travaux d’entretien et des projets, doivent être mis à jour dans l’application métier TRA. C’est particulièrement important pour que le module Pavement Management System (PMS) puisse être utilisé sans problème. Par ailleurs, les erreurs dans la structure des données doivent être corrigées. Le formulaire actuel de saisie des données est compliqué et peu adapté à la pratique. Une proposition de simplification est ici souhaitée.

Dans la partie B, la tâche consiste à accompagner la campagne ZEB actuelle. Les contrôles de plausibilité et la validation des données ZEB enregistrées. Par ailleurs, les tâches principales consistent à effectuer des calculs et des évaluations à partir des données brutes du relevé et à établir un rapport annuel sur la campagne ZEB actuelle.

La partie C porte sur une prestation d’assistance pour l’application métier TRA. L’assistance comprend l’établissement de planifications pluriannuelles pour l’entretien annuel, ainsi que pour les projets planifiés. Entre autres, des analyses du coût du cycle de vie en combinaison avec le PMS doivent contribuer à trouver le meilleur moment pour rénover le revêtement. L’adjudicataire se tient à la disposition de l’OFROU en tant que prestataire de services d’assistance pour toutes les questions concernant l’application l’application métier TRA et les revêtements.
