Description

Die Ereignisbewältigung ist eine wesentliche Aufgabe der Behörden und Organisationen für Rettung und Sicherheit (BORS). Wenn Einsatzdaten zwischen deren Public Safety Answering Points (PSAP) ausgetauscht bzw. Einsätze übergeben werden müssen, erfolgt dies heute auf mündlichem Weg per Telefon oder via Funk. Mit einem Datenaustausch zwischen den PSAP auf elektronischem Weg, soll kritische Zeit eingespart und so die Sicherheit der Bevölkerung erhöht werden. PTI Schweiz will hierfür eine Datenaustauschplattform mit einer standardisierten Schnittstelle für den transportverschlüsselten Austausch von Einsatzdaten sowie Einsatzmitteldaten (Positions- und Statusdaten) zwischen zwei oder mehreren PSAP gemäss definiertem Standard beschaffen und warten lassen. Konnektivität und Hosting sind Beistellobliegenheiten von PTI.
