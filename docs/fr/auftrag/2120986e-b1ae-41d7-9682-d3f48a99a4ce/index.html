Description

- Aufarbeitung der IST-Situationen für gewisse Teilgebiete und Ausarbeitung Vor-schläge zur Optimierung

- Fachlicher Schwerpunkte sind: Connectivity, Server & Storage, Security Elemente, Management- und Log-Systeme
