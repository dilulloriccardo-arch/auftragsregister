Description

Afin de bénéficier d'une amélioration acoustique, le projet consiste à remplacer les fenêtres et à isoler les contrecœurs et les caissons de stores compris entre le 1er et le 7ème étage d'un bâtiment exposé au bruit. Pour des plus amples explications, merci de se référer aux documents qui font partie intégrante du dossier.

Publication officielle : Voir le projet 2378 sur simap.ch — seule la publication qui y figure fait foi.
