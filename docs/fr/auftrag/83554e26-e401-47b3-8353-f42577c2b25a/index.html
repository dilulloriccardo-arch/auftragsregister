Description

L'autoroute du Rhône A9 entre Sierre-Est et Loèche/Susten-Est est une route nationale de 2e classe à 2 x 2 voies (longueur d'environ 8'510 m).

L'objectif du mandat est d'assurer, sous forme d'expertises et de conseils, le suivi géologique, géotechnique et hydrogéologique des différents projets d'autoroute A9 traversant Pfyn, depuis la finalisation des projets détaillés jusqu'à leur réalisation.

Les prestations sont réparties dans 3 modules :
- Module A : Prestations en tant qu'expert et conseiller du Maître d’ouvrage
- Module B : Prestations pour l'accompagnement géologique et géotechnique

Module C : Prestations pour l'accompagnement hydrogéologique
