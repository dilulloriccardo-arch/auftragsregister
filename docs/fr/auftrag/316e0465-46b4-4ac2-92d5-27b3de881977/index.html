Description

Le mandat comprend l’entretien régulier et le nettoyage de sortie du Centre de soins Sonnenberg dans le cadre d’un appel d’offres public. Les prestations doivent être offertes conformément aux documents d’appel d’offres. Les prestations sont attribuées dans une procédure ouverte et exécutées pour une durée initiale de trois ans. Le pouvoir adjudicateur dispose d’une option unilatérale de prolongation de deux années supplémentaires.
