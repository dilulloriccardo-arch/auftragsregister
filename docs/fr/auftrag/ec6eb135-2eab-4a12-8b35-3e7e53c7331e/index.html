Description

N02/N14 Système global de contournement de Lucerne ; y compris tous les systèmes d'exploitation et de sécurité (BSA), structuré en : (TP 1) Aménagement Nord avec construction du 3ème tube dans le tunnel de Rathausen, assainissement des tubes existants et renouvellement du tronçon N02 AS Rothenburg-VZ Rotsee-N14 AS Buchrain ; (TP 2/3) Construction du Tunnel de contournement, assainissement des tunnels Reussport/Sonnenberg existants et autoroute urbaine ; (TP ÜSYS) Remplacement de tous les systèmes de niveau supérieur selon la norme SA-CH tels que ÜLS Zentras, Video Zentras (VMS, BSS, BAS) et réseau de communication IP GE X, coordination de niveau supérieur (systèmes tiers, AKS, etc.). Principales prestations du mandat : Planification du projet (PV BSA) et direction locale des travaux BSA (öBL BSA) pour les phases 41 à 53 pour la mise en œuvre de tous les systèmes BSA du projet partiel 2/3 – Tunnel de Contournement / autoroute urbaine, y compris les ponts du Grosshof Pour la description détaillée des prestations, consultez les spécifications dans les documents de soumission.
