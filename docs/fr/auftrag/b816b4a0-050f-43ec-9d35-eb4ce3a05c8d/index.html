Motifs de l'adjudication

Das Angebot der Zuschlagsempfängerin erwies sich nach sorgfältiger Evaluation der eingereichten Angebote als das Vorteilhafteste im Sinne von Art. 41 Interkantonale Vereinbarung über das öffentliche Beschaffungswesen (IVöB; SAR 150.960) vom 15. November 2019 (Stand 1. Juli 2021). Der Vorteil des berücksichtigten Angebots liegt massgeblich bei den Kriterien: Rahmenbedingungen, Betriebsleistungen Nachhaltigkeit und Preisangebot.

Description

Die FHNW sucht eine Partnerin für den Betrieb der IRF (Institutional Repository) inkl. SaaS‑Lösung. Es wird ein Dienstleistungsvertrag über vier (4) Jahre mit der Option auf Verlängerung um zwei (2) Jahre abgeschlossen. Die Dienstleistungspartnerin hat die FHNW mit spezifischen Dienstleistungen zu bedienen, wie: - Support - Aktualisierung der Software - Fixieren von Bugs - Weiterentwicklung - Bereitstellung und Betrieb der SaaS-Lösung.
