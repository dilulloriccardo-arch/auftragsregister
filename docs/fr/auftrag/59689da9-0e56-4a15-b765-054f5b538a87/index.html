Motivation de l'adjudicateur

Das Angebot der Zuschlagsempfängerin war das Einzige und auch preislich sehr vorteilhaft.

Description

Dans le cadre du programme BZU23, la gare de Müllheim-Wigoltingen et ses accès ferroviaires doivent être rendus accessibles aux personnes handicapées. Les travaux de maître d’œuvre comprennent, entre autres : l’élévation de quai, les accès ferroviaires (rampes, escaliers, cage d’ascenseur), les blocs de câbles, les fondations, les travaux de surfaçage, les travaux d’excavation, etc.
