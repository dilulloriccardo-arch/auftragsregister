Description

Ausführen der Elektroinstallationen für neue Glasfaserleitungen auf die Rack innerhalb des Gebäudes. Die vorhandenen Glasfaserleitungen entsprechen nicht mehr dem Stand der Technik. Die Glasfaserleitungen werden vom Serverraum auf die 8 Rack erneuert und die bestehenden Leitungen zurückgebaut.
