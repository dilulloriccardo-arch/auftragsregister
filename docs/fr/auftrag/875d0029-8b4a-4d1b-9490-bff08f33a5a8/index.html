Description

Lot 1

Lieferung von Ersatzteilen der Marke Geesink-Norba inkl. Transport- und Verpackungskosten

Lot 2

Lieferung von Ersatzteilen der Marke Stummer inkl. Transport- und Verpackungskosten

Lot 3

Leistungsbeschrieb Werkstattdienstleistungen
- Diagnose erstellen
- Telefonische Hilfeleistung
- Programmierung von elektronisch gesteuerten Bauteilen
- Wartungsarbeiten gemäss Herstellervorschriften
- Leistungen in der Werkstatt Hagenholz
- Schulung der Bedienung und Wartung von neuen Aufbauteilen
- Pannenhilfe auf der Tour
- Hilfe beim Eichen

Leistungsbeschrieb Schlosserarbeiten
- Reparieren und Austauschen von defekten, abgenutzten Teilen
- Einsetzen und Anschweissen von Stahlplatten
- Herstellen von gebogenen Stahlplatten zum Einschweissen
- Abgenutzte Teile mit Schutzschweissnaht versehen
- Neubüchsen von beweglichen Teilen
- Richten von verformten Teilen
- Einstell- und Justierarbeiten
- Schweissarbeit in der Anbieterwerkstatt
- Lackierarbeiten
