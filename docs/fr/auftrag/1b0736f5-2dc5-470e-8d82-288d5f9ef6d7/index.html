Description

Diese Ausschreibung hat zum Ziel, eine geeignete Anbieterin für die Erneuerung der DNS-/DHCP-Infrastruktur der Universität St.Gallen zu gewinnen. Dabei muss die Anbieterin über genügend ausgebildete und zertifizierte Techniker verfügen, um die Konzeption für die Migration und die Inbetriebnahme der neuen Infrastruktur im festgelegten Zeitrahmen bewerkstelligen zu können.

Für die neue Hard- und Software muss die Wartung von der Anbieterin übernommen werden.
