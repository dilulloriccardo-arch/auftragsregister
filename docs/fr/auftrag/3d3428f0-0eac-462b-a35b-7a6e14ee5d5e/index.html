Description

Le CDF cherche une entreprise de révision ayant de l’expérience dans la vérification des contrôles informatiques généraux (ITGC) et dans la remise de rapports selon la norme ISAE 3402 type 2 dans le secteur public. Le mandataire fournit ses services sous la forme d’une vérification annuelle auprès de l’OFIT de l’existence et de l’efficacité des ITGC d’une sélection de systèmes ayant une incidence financière.
