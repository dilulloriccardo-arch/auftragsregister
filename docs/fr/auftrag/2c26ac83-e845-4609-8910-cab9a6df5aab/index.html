Description

Lot 1

TMA pour les systèmes et modules SAP fonctionnels suivants :
- Basis / CTS
- BW / BO
- CRM, FI / CO, MM / EWM
Ce lot est basé sur un contrat de régie forfaitisée selon un volume en jours-homme disponible dans le Cahier de réponses. La consommation du nombre de jours-homme sera pilotée entre le soumissionnaire et l’adjudicateur.

Lot 2

TMA pour le module fonctionnel IS-U

Lot 3

Le lot 3 sera basé sur un référencement de plusieurs sociétés expertes, il s’agit d’un marché à bons de commande permettant d’adresser les besoins de l’adjudicateur. Les volumes exprimés en jours-homme sont également disponibles dans le Cahier de réponses.
