Das berücksichtigte Angebot hat aufgrund seiner Merkmale und Vorteile die meisten Nutzwertpunkte (NWP) erzielt. Die Zuschlagskriterien (ZK) wurden wie folgt bewertet: ZK 1 Preis: 300 von 300 NWP ZK 2 Referenzauftrag Anbieter: 176.00 von 200 NWP Total: 476.00 von 500 NWP Die Anbietenden können sich unabhängig von einer allfälligen Beschwerde für ein informelles Debriefing bei der Kantonalen Fachstelle für öffentliche Beschaffungen melden.

Description

Die Bestandsliegenschaften der Sanität Basel wird entkernt und vollumfänglich saniert und umgebaut. Die Liegenschaft wird für die Zeit der Umbauarbeiten leergezogen. Im Zuge des Umbaus wird das vorhandene ziegelgedeckte Satteldach abgedeckt und der Dachaufbau komplett erneuert. Das Dach erhält im Zuge der Umbauarbeiten eine Indach-PV-Anlage auf der gesamten Dachfläche.
