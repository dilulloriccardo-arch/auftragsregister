Description

La réalisation de divers projets ferroviaires menés par transN dans le canton de Neuchâtel inclut, entre autres activités, l’acquisition définitive ou temporaire de terrains et de droits de voisinage. Afin d’assurer la réussite de ces projets, l’adjudicataire aura à charge de soutenir l’adjudicateur dans les domaines foncier et juridique comme précisé dans le présent dossier AO.
