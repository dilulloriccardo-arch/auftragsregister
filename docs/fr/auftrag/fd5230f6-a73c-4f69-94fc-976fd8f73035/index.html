Description

Ce projet porte sur l'aménagement complet de la jonction autoroutière Schindellegi de la N03 dans le tronçon 60.
L’objet du mandat mis en soumission sont les prestations d'ingénierie dans le domaine de la trafic pour les phases de projet «projet d'exécution» (AP) jusqu’au «mise en service».
