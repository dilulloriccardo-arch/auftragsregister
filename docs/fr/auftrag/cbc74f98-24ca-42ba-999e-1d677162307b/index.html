Description

Mit dem Gebäudeautomationssystem, soll ein «intelligentes», vernetztes Gebäude realisiert werden, welches mit all seinen Komponenten und mit der Umwelt kommunizieren kann. Es soll heutigen Organisationsstrukturen ebenso Rechnung tragen, wie zukünftigen Bedürfnissen genügen. Das Gebäudeautomationssystem wird mit dezentralen, intelligenten Strukturen hierarchisch aufgebaut. Dieser Aufbau stellt sicher, dass trotz einer möglichen Störung oder einem Ausfall einer Komponente, eines Bereichs oder einer Hierarchieebene, die benachbarten Komponenten, Bereiche und Ebenen weiterarbeiten können. Der Datenfluss zwischen Management-, Automations- und Feldebene muss in beide Richtungen ohne Einschränkungen funktionieren.
