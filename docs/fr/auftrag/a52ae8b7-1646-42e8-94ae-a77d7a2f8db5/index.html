Motifs de l'adjudication

Unter Berücksichtigung der in den Ausschreibungsunterlagen festgelegten Zuschlagskriterien erweist sich das Angebot der Firma REY Metallbau AG als das vorteilhafteste Angebot. Die Zuschlagsempfängerin erreichte unter allen Anbietenden die höchste Punktzahl. Sie vermochte aufzuzeigen, dass sie die Eignungskriterien erfüllen kann und die Zuschlagskriterien besser als die Mitbewerber erfüllt.
