Description

Lot 1

Die Logistikbasis der Armee (LBA) ist für die Belieferung von Stärkebeilagen (Bandnudeln/Tagliatelle, Trockenreis, Risottoreis, Basmatireis) zugunsten der Schweizer Armee verantwortlich. Damit die LBA dieser Verantwortung gerecht werden kann, soll die Versorgung von Bandnudeln/Tagliatelle zugunsten des Bedarfträgers sichergestellt werden.
