Description

Die ausgeschriebene BKP 281.2-02 umfasst die Ausführung von Laborbodenbelägen für die bestehenden, unter Denkmalpflege stehenden Shedhallen. Die ZHAW erhält im Annexbau neue Büroräumlichkeiten und in der unteren Shedhalle neue Labore mit dazugehörigen Nebenräumen. Die obere Shedhalle wird mit Unterrichtsräumen, Arbeitsplätzen und einer Bibliothek neu belebt. Im Ökonomiegebäude (RO) werden die FM-Flächen untergebracht.
