Description

Dans le cadre du projet de rénovation et d'extension du Centre de maintenance S. Bernardino Sud, plusieurs interventions sont prévues sur des bâtiments existants, Bâtiments A-B-C-D-F. L'objet du présent marché concerne les travaux d'étanchéité des toits plates. Quantités principales : - Frein-vapeur (membranes d'étanchéité, type Buder ou similaire) : 3'670 m² - Isolation (Swisspor PIR PREMIUM Plus ou similaire) : 3'670 m² - Double couche de finition (membranes d'étanchéité) : 3'670 m² - Ligne de vie : 825 m
