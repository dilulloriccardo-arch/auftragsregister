Description

Le présent appel d'offres vise à sélectionner un prestataire performant, capable de fournir la nouvelle solution ERP (open source ou closed source) selon le modèle SaaS et, une fois la mise en production réussie, d'assurer la maintenance, l'assistance, l'exploitation ainsi que les éventuels développements ultérieurs pendant toute la durée du contrat.
