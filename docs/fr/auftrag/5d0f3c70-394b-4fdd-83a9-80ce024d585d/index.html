Description

Lieferung, Einbringung und Installation inkl. sicherheitstechnischen Komponenten einer Propan R290-Wasser/Wasser Wärmepumpe mit einer Leistung von ca. 275kW bei W5/W65. Die Wärmepumpe ist stufenlos und auf die doppelte Leistung zu einem späteren Zeitpunkt erweiterbar. Auf der Verdampferseite wird das Netz mit Ethanol befüllt (Anergie Netz). Auf der Kondensationsseite wird das Netz mit behandeltem Wasser betrieben. Die Speicherbewirtschaftung erfolgt über die Regulierung der Wärmepumpe. Die Wärmepumpe wird nach der gültigen EN378, Suva und SES Normen bzw. Richtlinien in einem Maschinenraum aufgestellt.
