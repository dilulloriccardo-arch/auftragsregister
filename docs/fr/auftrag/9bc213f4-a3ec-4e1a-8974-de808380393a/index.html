Motivation de l'adjudicateur

Das Angebot der Zuschlagsempfängerin war insgesamt das Vorteilhafteste und hat am meisten Punkte erhalten. Ausschlaggebend war insbesondere das Zuschlagskriterium «Preis», bei dem die Zuschlagsempfängerin das niedrigste Angebot eingereicht hat.

Description

Die Projektziele und Massnahmen im Einzelnen sind: - Bau Aussenperronanlage mit einer Nutzlänge von 160m, und Aufwärtskompatibilität auf eine Nutzlänge von 235m ist sichergestellt; - Perronerhöhung auf P55; - Bau neue Personenunterführung inkl. Zugänge; - Gleisanlage an die neue Aussenperronanlage (Anpassungen Längenprofil); - Fahrleitungsanlage an die neue Aussenperronanlage inkl. Sicherstellung Aufwärtskompatibilität Perronnutzlänge 235m; - Anpassungen Bahnhofumfeld wegen Neubau Personenunterführung und Abbruch Technikgebäude RL01; - Allfällige Synergienutzung für erforderliche Erhaltungsmassnahmen diverser Anlagen z.B. Ersatz Technikgebäude RL01 durch eine neue Technikkabine.
