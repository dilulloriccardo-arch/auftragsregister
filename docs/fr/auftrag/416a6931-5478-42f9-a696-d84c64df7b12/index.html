Description

Acht Fahrleitungstransformatoren 132/16kV, 21.8MVA, 16.7Hz. für die Unterwerke Gümligen, Hardwald, Weinfelden und Cornaux. Für weitere noch nicht abschliessend definierte Projekte, beabsichtigt die SBB, mit diesem Rahmenvertrag optional vier weitere Fahrleitungstransformatoren 132/16kV, 21.8MVA, 16.7Hz zu beschaffen.
