Description

Huit transformateurs de ligne de contact 132/16 kV, 21,8 MVA, 16,7 Hz pour les sous-stations Gümligen, Hardwald, Weinfelden et Cornaux. Pour d’autres projets non encore définitivement définis, les CFF envisagent d’acquérir en option quatre autres transformateurs de ligne de contact 132/16 kV, 21,8 MVA, 16,7 Hz dans le cadre du présent contrat-cadre.
