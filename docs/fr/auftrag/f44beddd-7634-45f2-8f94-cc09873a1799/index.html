Motifs du choix

Anbieterin ein gültiges Angebot eingereicht hat. Das Angebot erfüllt die Eignungskriterien
sowie die technischen Spezifikationen vollumfänglich.

Description

Die Logistikbasis der Armee (LBA) ist für die Belieferung von Apfelmus zugunsten der Schweizer Armee verantwortlich. Damit die LBA dieser Verantwortung gerecht werden kann, soll die Versorgung von Apfelmus zugunsten des Bedürfnisträgers sichergestellt werden.
