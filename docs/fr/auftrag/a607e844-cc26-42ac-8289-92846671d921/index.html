Description

L'application métier TRA est opérationnelle à l’OFROU depuis 2010, actuellement en version TRA 2.6. Ce système est un élément central de la planification de la maintenance des routes nationales.

L'application actuelle fonctionne de manière stable et efficace et est très appréciée des utilisateurs.

Dans les prochaines années, la migration vers ArcGIS Server 11 et la dernière version de .NET est prévue. De plus, la base de données Oracle sera remplacée par une base de données PostgreSQL. Ces modifications devraient être intégrées à TRA 3.0 en 2027.

Cet appel d’offre couvre la maintenance et le support du logiciel pour la période 2027-2033.
