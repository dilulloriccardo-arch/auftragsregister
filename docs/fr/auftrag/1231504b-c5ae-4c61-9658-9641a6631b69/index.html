Description

Leistungsbeschrieb – Öffentliche Ausschreibung: Beschaffung eines MRT 1. Allgemeine Informationen 1.1 Auftraggeber LUKS Spitalbetriebe AG Spitalstrasse 6000 Luzern 16 1.2 Projektbezeichnung Beschaffung eines Magnetresonanztomographen (MRT) inkl. Zubehör, Installation und Wartung, einschliesslich Raumplanung für das ausgeschriebene Gerät. Raumperimeter für die Planung liegt den Ausschreibungsunterlagen bei. 1.3 Zweck der Beschaffung Ziel ist die Erweiterung der radiologischen Bildgebungskapazitäten im Spital Nidwalden durch die Beschaffung eines hochmodernen MRT-Systems, das den klinischen und technischen Anforderungen einer universitären bzw. kantonalen Einrichtung entspricht. 2. Leistungsumfang 2.1 Lieferung Lieferung eines betriebsbereiten Magnetresonanztomographen mit folgenden Mindestspezifikationen: - Feldstärke: 3.0 Tesla - Magnettyp: supraleitend, wartungsarm - Patientendurchmesser: mindestens 70 cm (gantry bore) - Tischlast: ≥ 200 kg - Gradientensystem: Hochleistungsgradienten, mindestens 60 mT/m - Kühlungssystem: automatisiert, mit integriertem Heliumrecycling (wenn möglich) 2.2 Installation Lieferung und betriebsfertige Installation inkl.: - Systemeinbringung - HF-Kabine / Faraday-Käfig - Schallschutz- und Klimatisierungslösungen - Anschluss an bestehende IT- und RIS-/PACS-Infrastruktur - EMV- und sicherheitstechnische Prüfungen gemäss Schweizer Normen - Anschluss an das bestehende Kühlwassernetz (Grundwasserkühlung).
