Description

Haus zur Heimat beschafft einen neuen ICT Service Provider für Übernahme, Aufbau, Installation, Betrieb und Störungsbehebung der eigenen ICT-Infrastruktur. Die ICT-Infrastruktur soll zusätzlich in eine schweizerische Cloud migriert und dort betrieben werden. Die Hardware ist im Mietmodell im Sinne eines Managed Workplace zur Verfügung zu stellen.
