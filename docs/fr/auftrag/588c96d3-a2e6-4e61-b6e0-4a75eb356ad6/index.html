Motivation de l'adjudicateur

Den Zuschlag erhält die Firma ti&m AG, Buckhauserstrasse 24, 8048 Zürich, da ihr Angebot die Anforderungen der Ausschreibung am besten zu erfüllen vermag. Die Anbieterin hat sowohl mit der angebotenen Lösungsarchitektur (ZK02) als auch mit der Präsentation der drei Use Cases (ZK10.1, 10.2 und 10.3) in Kombination mit einem attraktiven Preisangebot (ZK01) überzeugt und stellt somit das vorteilhafteste Angebot dar.

Description

L’objectif du présent appel d’offres est de trouver un fournisseur capable de mettre en place, de configurer, de fournir et d’exploiter sur le long terme une solution informatique pour remplacer le logiciel actuellement utilisé. La solution doit être réalisée sur la base d’une architecture de système composée de modules de transformation numérique qui soient, dans la mesure du possible, réutilisables. De plus, elle doit pouvoir être exploitée aussi bien dans le cloud que dans l’environnement fédéral ordinaire. La solution qui sera choisie servira à la gestion et à l’analyse des données ainsi qu’à l’établissement des rapports sur les données d’émission et devra être moderne et évolutive. Les données existantes devront être transférées de la base de données SQL actuellement utilisée vers la nouvelle solution. Après la mise en production, le mandataire assurera la maintenance, le support et le développement de la solution pendant toute la durée du contrat.
