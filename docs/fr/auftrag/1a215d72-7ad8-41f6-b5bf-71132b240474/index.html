Description

Ausführung und Anpassung von Elektroinstallationen. Es ist der Neubau einer Anlage zur Elimination von Mikroverunreinigungen an der ARA Rapperswil-Jona vorgesehen. Für diesen Neubau sind im Wesentlichen folgende elektrische Ausrüstungen zu er- stellen: • Gesamte Spannungsversorgung der EMV-Stufe • Unterverteilungen für Prozess und Gebäude • Elektrischen Installation der Verfahrenstechnik • Elektrischen Installation der Haustechnik • Steuerung mittels speicherprogrammierbarer Steuerun- gen (SPS) und übergeordnetem • Einbindung in bestehendes Prozessleitsystem (PLS) • Teile der Messtechnik
