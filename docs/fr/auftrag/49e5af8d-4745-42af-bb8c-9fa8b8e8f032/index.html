Description

Objekt dieser Beschaffung ist ein Veranstaltungsmanagement-Tool (VMT) als SaaS, das von mehreren kantonalen Stellen (separat) verwendet werden kann. Es soll via «JavaScript-Embed» in den kantonalen Webauftritt eingebunden werden. Dabei sind das Designsystem des Kantons sowie die Vorgaben zur Barrierefreiheit einzuhalten («native design»).
