Description

Lot 1

Lieferung von Abfahrtsmonitoren (AFM) mit Halterung/Stele, Anbindung an das zentrale System DiLoc|Motion, Montage und Inbetriebnahme aller Anzeigen inkl. Betrieb, Wartung und Support.

Lot 2

Lieferung von Überkopfanzeigern (ÜKA) mit Haltevorrichtung und Adaptern, Anbindung an das zentrale System DiLoc|Motion, Montage und Inbetriebnahme aller Anzeigen inkl. Betrieb, Wartung und Support.
