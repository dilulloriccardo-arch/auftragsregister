Description

Die ausgeschriebene Leistung umfasst die Annahme von Papier (Deinkingware 1.11, VeVA Code 20 01 01) welche durch die Anbieter*in der stofflichen Wiederaufbereitung zugeführt werden muss, d. h. ein Downcycling ist nicht zulässig (Ziel: aus Alt mach Neu). Die Dienstleistung wird für die Dauer vom 01.01.2026 bis 31.12.2027 erbracht. Die prognostizierte Sammelmenge für Los 1 beträgt ca. 4'421 Tonnen (2026) und ca. 4'111 Tonnen (2027). Der Übernahmestandort muss sich in der Stadt Zürich befinden.
