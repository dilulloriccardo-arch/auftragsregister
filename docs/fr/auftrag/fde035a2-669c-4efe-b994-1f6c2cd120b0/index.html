Description

Für die Planung von unterirdischen Anlagen/des Zentralestandorts im Bereich Untere Trift für das KW Trift werden detailliertere Kenntnisse der Lockergesteins- und der Felsverhältnisse benötigt. Zu diesem Zweck sollen im Jahr 2025 Erkundungsbohrungen ausgeführt werden. Gleichzeitig werden die Bohrungen zur Durchführung von Bohrlochversuchen genutzt. Die Arbeiten umfassen 4 Rotationskernbohrungen mittels Seilkernrohrverfahren mit Längen zwischen 40 bis 190 m, sowie die Durchführung von hydrogeologischen und geotechnischen Bohrlochversuchen, Bohrlochscanneraufnahmen und Einbau von Piezometern und/oder Porendruckwassergebern.
