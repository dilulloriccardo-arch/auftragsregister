Afin de favoriser une répartition équitable des mandats, le Maître d'ouvrage n'attribuera qu'un seul lot par soumissionnaire, même si celui-ci obtient le meilleur classement pour plusieurs lots.

Les soumissionnaires sont donc priés de préciser l'ordre de priorité des lots pour lesquels ils déposent une offre. Cet ordre sera pris en considération au moment de l'adjudication pour déterminer le lot finalement atttribué.
