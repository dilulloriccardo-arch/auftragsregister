Die Zuschlagskriterien (ZK) wurden wie folgt bewertet: ZK 1 Preis: 300 von 300 NWP ZK 2 Referenzauftrag Anbieter: 176 von 200 NWP Total: 476.00 von 500 NWP Die Anbietenden können sich unabhängig von einer allfälligen Beschwerde für ein informelles Debriefing bei der Kantonalen Fachstelle für öffentliche Beschaffungen melden.

Description

Die Bestandsliegenschaften der Sanität Basel wird entkernt und vollumfänglich saniert und umgebaut. Die Liegenschaft wird für die Zeit der Umbauarbeiten leergezogen. Im Zuge des Umbaus wird der Innenhof mit einem Stahldach überdeckt. Auf der Innenhofüberdachung wird ein Warmdachaufbau realisiert und bauseits mit einer extensiven Begrünung versehen. Auf der Parzellenwand werden Dachrandabschlüsse hergestellt sowie verschiedene Anpassarbeiten an Dachdurchdringungen.
