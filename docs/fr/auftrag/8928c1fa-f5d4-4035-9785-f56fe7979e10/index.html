Description

Der Bezirk Nord 3 von Grün Stadt Zürich benötigt für den Unterhalt von Grünflächen einen Geräteträger, welcher den Anforderungen gem. Dokument 02a «Leistungsbeschrieb», entspricht𪡟t.

Gesucht wird eine Lieferantin, welche für den Geschäftsbereich Wald, Landwirtschaft und Pachten von Grün Stadt Zürich (GSZ) die Lieferung eines Geräteträgers mit Anbaugeräten und entsprechende Serviceleistungen für die Wartung und allfällige Instandsetzung gemäss dem Dokument 02a «Leistungsbeschrieb» und den vertraglichen Bedingungen gemäss Dokument 03a «Vertragsentwurf» erbringt.
