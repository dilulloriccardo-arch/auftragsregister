Motifs de l’adjudication

Ausschlaggebend für den Zuschlag an das Elektrizitätswerk der Stadt Zürich, Tramstrasse 35, 8050 Zürich, war die beste Erfüllung des Zuschlagskriterium «Z1 Energiepreis». Insgesamt stellt es das vorteilhafteste Angebot dar. Zum Preis von 76.605 CHF/MWh exkl. MWST. (Settlement Preis vom 02.09.2026 für das Lieferjahr 2029).
Für die Bewertung des Zuschlagskriteriums „Energiepreis - Formel“ wurde der tiefste Preis (72.454 CHF/MWh inkl. MWST) ermittelt. Die Bewertung erfolgte auf Basis der Lieferjahre 2029 - 2033 anhand der vom Anbieter abgegebenen Faktoren (α, β, γ) der unter Ziffer 3.1 genannten Preisformel.

Description

In diesem Submissionsverfahren geht es um die Strombeschaffung für das CSCS – Swiss National Supercomputing Centre der ETH Zürich am Standort Lugano für die Jahre 2029-2033. Die erwartete Strombeschaffung liegt bei etwa 60 GWh pro Jahr. Ab 2030-2031 wird vermutlich ein neuer Server in Betrieb genommen.
