Motifs de l'adjudication

Die Zuschlagsempfängerin hat gemäss den publizierten Zuschlagskriterien die höchsten Wertungen erzielt und das vorteilhafteste Angebot eingereicht (Art. 41 Interkantonale Vereinbarung über das öffentliche Beschaffungswesen, IVöB). Das Angebot überzeugt in fachlicher Hinsicht, insbesondere in Bezug auf das angebotene teilautonome System (automatische Nachbestellungen inkl. Übermittlung) sowie die damit verbundenen Dienstleistungen.

Description

BERNMOBIL führt ein C-Teilemanagement über Befestigungstechnik und Verbrauchsmaterial inkl. PSA im Self-Service. Aus diesem Grund wird diese Dienstleistung für die nächsten Jahre im offenen Verfahren ausgeschrieben. Diese Dienstleistung umfasst die Bewirtschaftung des gemeinsam definierten Sortimentes inkl. Logistik, Lagergestelle und -einrichtungen. Details sind den Ausschreibungsunterlagen zu entnehmen.
