Motivation de l'adjudicateur

Die Zuschlagsempfängerin hat das preislich günstigste Angebot eingereicht. Sodann hat sie beim Zuschlagskriterium «Erfahrung, Referenzen» eine teilweise genügende Bewertung erhalten. Bezüglich des Zuschlagskriteriums «Schlüsselpersonen» erhielt sie eine genügende bis gute Bewertung. Insgesamt hat sie daher in der Gesamtbewertung am besten abgeschnitten. Im Ergebnis hat damit die cabletron AG, 8048 Zürich mit 425 von 500 erzielbaren Punkten das vorteilhafteste Angebot eingereicht, womit ihr der Zuschlag zu erteilen ist.
