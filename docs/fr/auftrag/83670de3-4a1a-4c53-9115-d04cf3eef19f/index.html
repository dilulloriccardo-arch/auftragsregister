Acquisition de wagons de ventilateur pour le tunnel du Simplon

Acheteur public
Infrastruktur Flottenprojekte (I-ESP-FFM-FPJ)
14.12.2026, 18 h 00Délai de remise
Documents et publication officielle sur simap.chAjouter le délai à l’agendaSignaler une erreur

Description

CFF SA remplace son wagon de ventilateur pour le tunnel du Simplon qui, avec le wagon énergétique, forme une unité de ventilation, sous le nom de projet «Meroppo». Pour ce faire, les CFF mettent à disposition un wagon plat à 4 essieux et un ventilateur, à partir desquels le nouveau wagon de ventilateur, y compris l’étanchéité avec le profil du tunnel, doit être construit. Le nouveau wagon de ventilateur doit fonctionner avec le wagon énergétique existant (puissance maximale de 500 kW). Les exigences concernent le développement, la planification, la fabrication, la mise en service, la livraison, le suivi pendant la phase de garantie, ainsi que la documentation et la formation.

Quantité: un chariot de ventilateur
