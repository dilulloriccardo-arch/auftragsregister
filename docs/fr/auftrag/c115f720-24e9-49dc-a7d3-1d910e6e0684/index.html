Motifs de l’adjudication

Der Zuschlag erhielt das insgesamt wirtschaftlich vorteilhafteste Angebot auf Basis der in der Ausschreibung festgelegten Zuschlagskriterien. Das Angebot der Zuschlagsempfängerin zeichnet sich insbesondere durch die Kriterien Angebotspreis und Leistungsfähigkeit aus.

Description

Der bestehende Durchlass ist zurück bauen, das Gewässer anzupassen. Beim Gewässer Felsenhofbach wird die Sohle neu erstellt und die Böschungen angelegt. Der untere Durchlass wird ersetzt, der Asphalt dazu neu gemacht. Die Werkleitungen werden im Bereich der Brücke erneuert die Strasse wird angepasst. Die Brücke Felsenhofbach wird komplett neu erstellt. Der Verkehr ist während der ganzen Bauzeit gesperrt auf der Hombrechtikerstrasse.
