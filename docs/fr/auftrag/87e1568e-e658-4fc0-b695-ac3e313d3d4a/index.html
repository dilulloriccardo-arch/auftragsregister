Motivation de l'adjudicateur

Das Angebot der Zuschlagsempfängerin war insgesamt das Vorteilhafteste. Ausschlaggebend war insbesondere das Zuschlagskriterium «Preis», bei dem die Zuschlagsempfängerin das niedrigste Angebot eingereicht hat gegenüber den Mitbewerbern.

Description

Attribution du marché pour l’acquisition d’une veste thermique selon la norme EN 20471 pendant 5 ans. Les CFF achètent également ces articles pour les ayants droit. Les quantités sont réparties comme suit: CFF environ 80% Ayants droit (BLS, BVB, Elventino, login, RhB, Sersa, SOB, SZU, Thurbo, Transicura, Zentralbahn) envrion 20% L’objet du marché est intégralement décrit dans la documentation d’appel d’offres.
