Description

Der Bereich UID benötigt personelle Kapazitäten (Fachkräfte mit Kompetenzen im Bereich ICT Technologie) hinsichtlich Auftrags- sowie ggf. Werkleistungen für die Erbringung von Beratungs-, Konzeptions-, Entwicklungs- und Engineering-Leistungen zur Abwicklung von Aufträgen und Projekten sowie zur Anpassung und Erweiterung (Changes) von Informatiklösungen.

Folgende Rollen werden gesucht:
a) Applikation‑Entwickler Backend
b) Applikation‑Entwickler Web
c) Applikation‑Entwickler Mobile
d) M365 Engineer / Administrator
e) MS SharePoint Engineer
f) MS Azure Engineer
g) Datenbank‑Spezialist MS SQL
h) Data Engineer
i) Data Scientist
j) CI/CD‑Engineer (optional)
k) Neuron Integration Spezialist (optional)
l) IT-gestützte Automatisierung (optional)

Im Rahmen dieser Ausschreibung strebt IWB eine Auswahl von maximal fünf strategischen Partnern zur Unterstützung von UID an mit den Rahmenverträge vereinbart werden
Da IWB als Querverbundunternehmen im Markt agiert, ist Domänen-Knowhow der Anbieter in den Sparten Strom, Gas, Wasser, Fernwärme, Telekom und Energiedienstleistungen von Vorteil.

Zwecks Erfüllung des Gegenstands des Vergabeverfahrens sind die dazu notwendigen Schlüsselpersonen, mindestens der Senioritätsstufe «Professional» , in der/den jeweiligen geforderten Rolle(n), erforderlich.
