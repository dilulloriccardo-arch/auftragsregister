Description

Des travaux sur les EES doivent être effectués dans la galerie de sécurité du tunnel d’Isla Bella. Ils comprennent la production, la livraison et le montage de portes d’issues de secours, de portes intermédiaires et de portes centrales dans la nouvelle galerie de sécurité et les centrales. Quantités approximatives : - Portes d’issues de secours (5 pièces) ; - Portails avec porte d’issue de secours intégrée (2 pièces) ; - Portes intermédiaires (8 pièces) ; - Portes centrales (4 pièces) ; - Sas avec porte coulissante intégrée (4 pièces) ; - Armoires de commande pour sas (2 pièces).
