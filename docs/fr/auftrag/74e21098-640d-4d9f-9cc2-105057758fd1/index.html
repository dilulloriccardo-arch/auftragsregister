Description

Die Primarschulanlage Regelwiesen wird über einen Gasbrennwertkessel aus dem Jahre 2004 mit einer Heizleistung von 200 kW beheizt. Die Heizzentrale befindet sich im Trakt E (Turnhalle) und versorgt die übrigen Trakte über eine Fernleitung mit Wärme für die Raumheizung. Die Warmwasseraufbereitung erfolgt nur in der Turnhalle über das Heizsystem.

Die Zentralheizung wird durch ein Wärmepumpensystem ersetzt, mit welchem in den Sommermonaten auch eine Kühlung der Klassenzimmer über Kühlsegel ermöglicht wird.
Die Regulierung der Unterstationen sowie der neuen Kühlsegel wird zukunftsorientiert aktualisiert.
