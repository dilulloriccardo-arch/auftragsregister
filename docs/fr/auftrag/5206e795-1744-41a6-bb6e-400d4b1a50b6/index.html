Description

L'oggetto della presente commesse prevede la realizzazione di una nuova parete di contenimento costituita da un cavalletto di mircropali atta a proteggere il muro d'argine esistente dall'erosione dell'alveo causata dagli eventi metereologici dell'estate 2024, nel Comune di Faido, zona Gera.
