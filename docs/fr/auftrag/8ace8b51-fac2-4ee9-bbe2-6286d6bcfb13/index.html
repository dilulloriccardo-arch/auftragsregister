Description

L’appel d’offres porte sur le développement, la fabrication et la livraison de revêtements de sol de 2e classe pour la flotte RABe 514. Les revêtements existants doivent en effet être remplacés dans le cadre de la prolongation de la durée de vie de cette flotte. Pour les détails concernant la description des prestations et leur étendue, voir le dossier d'appel d'offres.
