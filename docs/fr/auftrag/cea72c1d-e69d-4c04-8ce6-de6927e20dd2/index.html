Description

Der Projektumfang umfasst das Engineering, Konstruktion, Herstellung, Montage und IBN einer Mittelspannungsanlage für ein mobiles Unterwerk. EBL (Genossenschaft Elektra Baselland), das Elektrizitätsversorgungsunternehmen im Kanton Basel-Landschaft, benötigt eine mobile Infrastruktur für den Betrieb des Netzes, das für die Versorgungssicherheit unserer Kunden von entscheidender Bedeutung ist.
