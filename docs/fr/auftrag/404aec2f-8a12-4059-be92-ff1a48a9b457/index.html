Motivation de l'adjudicateur

Den Zuschlag für Los 1 erhält, angesichts der Zuschlagsregelung, nach welcher pro Anbieter max. 2 Zuschläge vergeben werden und der Formulierung, dass der Anbieter jene Zuschläge erhält, bei welchen die Konkurrenzangebote den grössten Punkteabstand zu seinen Angeboten aufweisen, die Firma BEGASOFT AG. Ihr Angebot überzeugte angesichts der sehr guten Erfüllung der qualitativen Kriterien und des vertretbaren Preises.

Description

Le présent appel d’offres porte sur l’acquisition de prestations (présentant pour certaines le caractère d’un ouvrage) pour le support, l’entretien des logiciels, la maintenance, le développement ultérieur et le redéveloppement de plateformes web des MNA. Les rôles/fonctions ci-après sont nécessaires à cette fin : Mandat de base : - Prestation de développement logiciel et architecture système (MB) : 684 heures - Prestation de gestion de projet informatique (MB) : 171 heures - Prestation de conception / mise en page (MB) : 171 heures - Prestation de test logiciel (MB) : 172 heures - Disponibilité de base, c.-à-d. support en continu, entretien des logiciels, maintenance technique (MB) : 41 heures
