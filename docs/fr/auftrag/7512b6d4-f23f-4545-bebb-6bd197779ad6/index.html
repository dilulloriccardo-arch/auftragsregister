Motifs du choix

Nach Art. 41 der Interkantonalen Vereinbarung über das öffentliche Beschaffungswesen (IVöB) erhält das vor-teilhafteste Angebot den Zuschlag.

Die Zuschlagsempfängerin hat das preislich günstigste Angebot eingereicht. Sodann hat sie beim Zuschlags-kriterium «Referenzen» gute bis sehr gute Bewertungen erhalten. Bezüglich dem Vergabekriterium «Ausbildung von Lernenden» hat sie keine Punkte erhalten. Insgesamt hat sie bei der Gesamtbewertung am meisten Punkte erhalten.

Im Ergebnis hat damit die Ballinari AG, 8057 Zürich mit 880 von 1000 erzielbaren Punkten das vorteilhafteste Angebot eingereicht, womit ihr der Zuschlag zu erteilen ist.

Description

Strangsanierung im bewohnten Zustand (Küche+Bad) von 23 Wohnungen in 6 Etappen.

Zudem werden mit Begleitmassnahmen (Brandschutz, Absturzsicherung, PV-Anlage, Malerarbeiten Fassade usw.) vorgesehen.
