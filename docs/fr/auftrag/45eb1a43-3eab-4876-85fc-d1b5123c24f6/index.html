Description

Le marché concerne les travaux de renouvellement anticipé de la signalisation dynamique du tunnel Glion, situé sur la N09 dans le cadre du projet ANT Chexbres-Roche.
Le présent appel d’offres porte sur les prestations de direction locale des travaux pour la phase de réalisation (52 à 53).
