Description

À Gümligen Sud, un ouvrage de désenchevêtrement est en cours de construction afin d'intégrer la ligne à voie unique reliant l'Emmental à Bem. En conséquence, l'installation de caténaires doit être adaptée à la nouvelle topologie des voies. Les mesures suivantes sont nécessaires à cet effet : Mesures TP1 : remplacement du poste d'aiguillage : tous les travaux sur les caténaires dans l'ensemble du périmètre du projet pour le remplacement du poste d'aiguillage Mesures TP2.2 : voie inférieure : tous les travaux sur la caténaire nécessaires à la construction de la « voie inférieure ». Mesures TP2.3 : ouvrage de désenchevêtrement dans le tunnel Mesures TP2.4 : axes de voie, aménagement final Pour une description détaillée du projet, voir le document B1 et le rapport technique D1.2 du dossier d'appel d'offres.
