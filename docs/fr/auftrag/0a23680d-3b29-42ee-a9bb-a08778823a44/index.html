Sportanlage Moos, Kunstrasensanierung

Acheteur public
Gemeindeverwaltung Wettswil, Abteilung Präsidiales
20.11.2026, 14 h 00Délai de remise
Documents et publication officielle sur simap.chAjouter le délai à l’agendaSignaler une erreur

Description

Der bestehende Kunstrasenplatz 2 (unverfüllt) des Sportplatzes Moos, Wettswil a.A. muss
saniert werden. Aus diesem Grund wird der bestehende Kunstrasenteppich und die
bestehende Dämpfungsplatten rückgebaut und entsorgt. Eine neue Elastikschicht insitu wird
eingebaut und ein neuer Kunstrasen unverfüllt neu verlegt. Gleichzeitig werden die
Bewässerungsdüsen erneuert.
