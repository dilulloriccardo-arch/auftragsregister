Swissgrid AG

Documents et publication officielle sur simap.chAjouter le délai à l’agendaSignaler une erreur

Description

L’objectif de cet appel d’offres est de sélectionner un fournisseur (« revendeur ») pour acheter des services cloud hyperscalers publics (par exemple, Microsoft Azure, Amazon AWS, Google Cloud, etc.) pour le successeur de la plateforme cloud existante de Swissgrid. Les services cloud seront achetés selon les besoins sur une période de 5 ans (accord-cadre).
