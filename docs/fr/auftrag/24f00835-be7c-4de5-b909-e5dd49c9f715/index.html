Description

L’objet du présent appel d’offres porte sur plusieurs modules pour wagons porte-modules, qui ont déjà été commandés par la zb Zentralbahn AG. L’acquisition se déroule sur la période allant de 2025 à 2032 et englobe près de 14 wagons porte-modules avec plusieurs modules interchangeables. Des options sur d’autres quantités demeurent réservées. La zb Zentralbahn AG prévoit l’acquisition de wagons porte-modules sur la période 2026-2032. La grille quantitative peut être consultée dans les documents d’appel d’offres.

Dans le cadre de cette acquisition, l’élément de base est un wagon porte-modules comportant des fixations de conteneur escamotables et faciles à monter ainsi qu’une protection anti-soulèvement si besoin (dispositif de calage ou de vissage pour conteneur).

Les normes actuelles et les DE OCF doivent obligatoirement être respectées. Et ce, afin de garantir la sécurité du chargement sur des voies présentant une déclivité de 125‰, que les véhicules soient chargés ou non.

Les modules ci-dessous sont prévus.

- Module atelier avec plate-forme de toit
- Module de montage (p. ex. plate-forme ciseaux, grue, positionneur du fil de contact)
- Module pour le personnel (p. ex. avec sièges, kitchenette)
- Module pour wagon plat
- Module pour bobines (pour la pose de câbles de terre, touret pivotant)
- Module pour grue de chargement de rails (chargement et déchargement de coupons de rail d’une longueur de 36 m)
- Module pour transport de rails longs (108 m)
- Module pour nettoyage (1 réservoir d’eau de 7 m³ + plate-forme pour nettoyeur haute pression, 1 réservoir d’eau de 3,5 m³)
- Module pour conteneur roulant (cadre pivotant de conteneur roulant)

Les wagons porte-modules présentent idéalement une longueur d’env. 14,5 m (hors tampons), ce qui permet la prise en charge de deux conteneurs ISO de 20 pieds ou de quatre conteneurs ISO de 10 pieds.

Les véhicules ferroviaires à acquérir ainsi que leurs modules de chargement doivent attester d’une homologation délivrée par l’Office fédéral des transports (OFT) pour une durée indéterminée.
