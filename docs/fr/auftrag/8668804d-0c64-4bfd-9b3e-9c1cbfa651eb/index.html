Description

Das bestehende Microsoft Enterprise Agreement endet am 31.05.2026 und muss erneuert werden.

Im Rahmen der Ausschreibung «Erneuerung Microsoft Lizenzierung», will die SVA Basel-Landschaft die bestehenden Microsoft M365 E3 Lizenzen sowie künftige Varianten und Erweiterungen prüfen.
