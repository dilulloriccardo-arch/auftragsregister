Description

Das Projekt «2K5» ist die Erweiterung der Kehrichtverwertungsanlage Hagenholz in Zürich um eine dritte Verbrennungslinie (Details dazu siehe Teil B «Projektbeschrieb»). Die ausgeschriebenen Leistungen sind in folgendem Leistungsverzeichnis (LV) beschrieben: - BKP 225.2 Weitere Details sind den Ausschreibungsunterlagen zu entnehmen.
