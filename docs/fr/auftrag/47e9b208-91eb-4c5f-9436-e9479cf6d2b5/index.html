Serviceunterstützung Messaging und SQL

Description

Le présent appel d'offres porte sur l'acquisition de services informatiques et d'une expertise en ingénierie dans l'environnement Microsoft. Le prestataire assistera le donneur d'ordre dans l'exploitation, le développement, ainsi que dans la planification, le conseil et la mise en œuvre de projets dans l'environnement Microsoft.

Les axes prioritaires sont notamment les suivants :
- Microsoft Exchange (sur site et en ligne) : tickets d'assistance courants
- Microsoft Active Directory et EntraID : tickets d’assistance courants
- Service Faxination : assistance et maintenance du service et de l’infrastructure associée
- Tickets d’assistance courants dans des domaines connexes (MS SharePoint, MS OneDrive, MS Teams, etc.)

- Services de messagerie : application des correctifs et maintenance de l’infrastructure au quotidien, ainsi qu’assistance lors des mises à jour majeures
- Microsoft SQL et PostgreSQL : tickets d’assistance courants
- Microsoft SQL et PostgreSQL : application des correctifs et maintenance de l’infrastructure dans le cadre des opérations quotidiennes, ainsi qu’assistance lors des mises à jour majeures

Des prestations liées à d’autres produits Microsoft peuvent également être fournies, notamment Microsoft Power BI, ainsi que des prestations de collaboration dans le cadre de projets liés aux technologies et aux produits Microsoft.
