Motivation de l'adjudicateur

Es wurde ein einziges gültiges Angebot eingereicht, das alle Anforderungen erfüllte und als wirtschaftlich sowie qualitativ angemessen bewertet wurde. Der Zuschlag erfolgt daher an die Anbieterin Fehlmann AG.

Description

L'atelier du D-ITET demande de soumettre des offres pour une fraiseuse CNC simultanée à 5 axes. Le système doit être idéal pour la fabrication de pièces cubiques fraisées.
