Motifs du choix

Lot 1

Description

Lot 1

Contrat-cadre pour la fourniture de bobines de compensation régulées 5+1 48 - 120 MVA, 230 kV, rég. 60 % pour le niveau du réseau 220 kV
Le niveau d'isolement de la tension alternative (Um) des connexions est de 245 kV
La durée de fonctionnement doit être conçue pour 50 ans.

Les services sont décrits en détail dans le document C100_Lastenheft_v10.pdf.

Lot 2

Contrat-cadre pour la fourniture de bobines de compensation régulées 3+1 80 - 160 MVA, 400 kV, reg. 50 % pour le niveau du réseau 380 kV
Le niveau d'isolement de la tension alternative (Um) des connexions est de 420 kV La durée de fonctionnement doit être conçue pour 50 ans.

Les services sont décrits en détail dans le document C100_Lastenheft_v10.pdf.
