Description

Die Aargau Verkehr AG (AVA) schreibt für sich und ihre Tochtergesellschaft, die Limmat Bus AG, den Bedarf einer neuen Revisionsstelle aus. Die Bedingungen dazu sind im Pflichtenheft dargelegt. Ausgeschrieben werden Mandatsleistungen für die Jahresrechnungen/Konzernrechnungen 2026, 2027 und 2028.
