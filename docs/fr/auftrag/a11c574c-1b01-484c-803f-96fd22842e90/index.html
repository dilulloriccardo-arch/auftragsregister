Description

Les entreprises des transports publics fribourgeois, représentées par leur société holding, organisent une procédure de mise en concurrence portant sur la fourniture d’énergie électrique pour leurs infrastructures éligibles, approvisionnées via le marché libre. L’objet du marché est décrit en détail dans le cahier des charges.
