Description

Mit der vorliegenden Ausschreibung ermittelt das KSW einen Lieferanten für die Beschaffung von neuen leistungsfähigen Servern für die Bereitstellung von Compute-Ressourcen für unsere produktive VMware vSphere 8 Umgebung. Die Hardwarekonfiguration der Server soll die zum Beschaffungszeitpunkt neuste CPU-Generation beinhalten und optimal für virtuelle Serverumgebungen ausgelegt sein. Die Lösung soll auf eine Support-Laufzeit von 6 Jahren (5x9 NBD) ausgelegt sein.
