Motivation de l'adjudicateur

Es wurde ein einziges gültiges Angebot eingereicht, das alle Anforderungen erfüllte und als wirtschaftlich sowie qualitativ angemessen bewertet wurde. Der Zuschlag erfolgt daher an die Anbieterin Fehlmann AG.

Description

Le D-PHYS (atelier d'apprentissage) demande la remise d'offres pour 4 fraiseuses universelles à commande manuelle et CNC. Les systèmes doivent être utilisés dans le cadre de la formation professionnelle.
